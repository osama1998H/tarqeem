# فلسفة الكلمات المفتاحية العربية في ترقيم

هذا الملف يحدد القواعد الأساسية لاختيار وتصميم الكلمات المفتاحية في لغة ترقيم.

---

## المبدأ الأساسي

**ترقيم ليست ترجمة للغة برمجة إنجليزية - بل هي لغة برمجة عربية أصيلة.**

الهدف: أن يفهم أي عربي الكود دون الحاجة لترجمته ذهنياً إلى الإنجليزية.

---

## القواعد الأربع لاختيار الكلمات المفتاحية

### 1. الوصف لا الترجمة

❌ **خطأ**: ترجمة الكلمة الإنجليزية حرفياً
✅ **صحيح**: اختيار كلمة تصف ما تفعله في السياق العربي

| الإنجليزية | الترجمة الحرفية | المصطلح الصحيح | السبب |
|------------|----------------|----------------|-------|
| interface | واجهة | ميثاق / عقد | الواجهة تعني الوجه، لكن interface في البرمجة هو عقد يُلزم بتنفيذ دوال معينة |
| void | فراغ | منتهية | الفراغ يوحي بالفضاء، لكن المقصود أن الدالة لا تُرجع قيمة (منتهية بذاتها) |
| override | تجاوز | تعديل | الصنف الفرعي يُعدّل سلوك الدالة لا يتجاوزها |
| abstract | مجرد | قالب | الصنف القالب هو نموذج يُبنى عليه |
| static | ثابت_صنف | مشترك | العضو مشترك بين كل نسخ الصنف |
| handle | مقبض | معرّف / مرجع | المقبض هو مقبض الباب! لكن handle في البرمجة هو معرّف يُشير إلى مورد (ملف، اتصال، إلخ) |
| socket | مقبس | منفذ_اتصال | المقبس الكهربائي! لكن المقصود نقطة اتصال شبكي |
| buffer | مخزن_مؤقت | ذاكرة_وسيطة | المخزن غامض، الذاكرة الوسيطة تصف الغرض |
| callback | استدعاء_راجع | دالة_استجابة | الاستدعاء الراجع غير واضح |
| thread | خيط | مسار_تنفيذ | الخيط ترجمة حرفية لا معنى لها برمجياً |

### 2. الصحة النحوية

الجملة البرمجية يجب أن تُقرأ كجملة عربية صحيحة:

❌ **خطأ**: `منتهية دالة حساب_الدخل()`
✅ **صحيح**: `دالة منتهية حساب_الدخل()`

❌ **خطأ**: `ميثاق قابل_للطباعة`
✅ **صحيح**: `ميثاق طابع` أو `ميثاق الطباعة`

**القاعدة**: النعت يأتي بعد المنعوت في العربية.

### 3. الترتيب العربي

بعض التراكيب تحتاج ترتيباً مختلفاً عن الإنجليزية:

| الإنجليزية | الترتيب الحالي | الترتيب العربي الصحيح |
|------------|---------------|---------------------|
| `void function calc()` | `فراغ دالة حساب()` | `دالة منتهية حساب()` |
| `static int count` | `ثابت_صنف عدد عداد` | `عدد مشترك عداد` |
| `override void reset()` | `تجاوز فراغ صفّر()` | `دالة معدّلة صفّر()` |

### 4. الاكتمال الذاتي (لا اختصارات غامضة)

الكلمة يجب أن تكون مفهومة بذاتها دون شرح:

| الاختصار | المعنى المقصود | البديل الواضح |
|----------|---------------|--------------|
| جا | جيب الزاوية | جيب |
| جتا | جيب التمام | جيب_التمام |
| ظا | ظل الزاوية | ظل |
| باي | π | ط (النسبة التقريبية) |

**ملاحظة**: يمكن دعم الاختصارات كأسماء مستعارة، لكن الاسم الأساسي يجب أن يكون واضحاً.

## تصنيف الكلمات المفتاحية

### الكلمات التي تحتاج مراجعة

| الحالي | المقترح | الملاحظة |
|--------|---------|----------|
| واجهة | ميثاق | العقد/الميثاق يصف الالتزام بالتنفيذ |
| فراغ | منتهية | أو حذفها كلياً (الافتراضي أن الدالة لا تُرجع) |
| يطبق | يلتزم_بـ | الصنف يلتزم بالميثاق |
| ثابت_صنف | مشترك | العضو مشترك بين النسخ |
| أساس | أصل | الصنف الأصل أوضح من الأساس |

### الكلمات الجيدة (تحتفظ بها)

| الكلمة | السبب |
|--------|-------|
| متغير | تصف أن القيمة قابلة للتغيير |
| ثابت | تصف أن القيمة لا تتغير |
| دالة | مصطلح رياضي عربي أصيل |
| صنف | يصف القالب الذي تُنشأ منه الكائنات |
| صحيح/خطأ | قيم منطقية واضحة |
| إذا/وإلا | كلمات شرطية عربية طبيعية |
| طالما | تصف الاستمرار بشرط |
| لكل | تصف التكرار على مجموعة |

## قواعد المكتبة القياسية

### التسمية في الرياضيات

| المفهوم | الحالي | المقترح | السبب |
|---------|--------|---------|-------|
| π | باي | ط | الرمز العربي للنسبة التقريبية |
| e | هـ | هـ (صحيح) | رمز أويلر بالعربية |
| sin | جا | جيب | الاسم الكامل للوضوح |
| cos | جتا | جيب_التمام | الاسم الكامل |
| tan | ظا | ظل | الاسم الكامل |
| cot | ظتا | ظل_التمام | الاسم الكامل |
| arcsin | جا_عكسي | جيب_عكسي | |
| arccos | جتا_عكسي | جيب_تمام_عكسي | |

**ملاحظة**: يمكن دعم `جا` و`جتا` كأسماء مستعارة للتوافق.

### التسمية العامة

- استخدم الفعل المضارع للدوال التي تُنفذ فعلاً: `احسب`، `أضف`، `احذف`
- استخدم الاسم للدوال التي تُرجع قيمة: `طول`، `حجم`، `نوع`
- استخدم صيغة السؤال للدوال المنطقية: `هل_فارغ`، `هل_موجود`

## معايير التحقق

قبل إضافة أي كلمة مفتاحية أو تسمية، اسأل:

1. **هل يفهمها العربي بدون معرفة الإنجليزية؟**
2. **هل تُقرأ بشكل طبيعي في جملة عربية؟**
3. **هل تصف ما تفعله لا ما تُترجم منه؟**
4. **هل الترتيب نحوي صحيح؟**

## أمثلة تطبيقية

### مثال ١: تعريف ميثاق

```tarqeem
// ❌ قبل (ترجمة)
واجهة قابل_للطباعة {
    دالة اطبع()
}

// ✅ بعد (عربي أصيل)
ميثاق الطباعة {
    دالة اطبع()
}
```

### مثال ٢: دالة بدون إرجاع

```tarqeem
// ❌ قبل (ترتيب إنجليزي)
فراغ دالة سجّل_الخطأ(رسالة: نص) { }

// ✅ بعد (ترتيب عربي) - خيار ١
دالة منتهية سجّل_الخطأ(رسالة: نص) { }

// ✅ بعد (ترتيب عربي) - خيار ٢: حذف الكلمة (الافتراضي لا إرجاع)
دالة سجّل_الخطأ(رسالة: نص) { }
```

### مثال ٣: تطبيق ميثاق

```tarqeem
// ❌ قبل
صنف مستخدم يطبق قابل_للطباعة { }

// ✅ بعد
صنف مستخدم يلتزم_بـ الطباعة { }
```

### مثال ٤: الدوال المثلثية

```tarqeem
// ❌ قبل (اختصارات)
متغير س = جا(زاوية)
متغير ص = جتا(زاوية)

// ✅ بعد (أسماء كاملة)
متغير س = جيب(زاوية)
متغير ص = جيب_التمام(زاوية)
```
