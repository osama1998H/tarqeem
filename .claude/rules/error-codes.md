# قواعد رموز الأخطاء العربية

هذا الملف يحدد القواعد الإلزامية للوكلاء AI عند التعامل مع رموز الأخطاء في ترقيم.

---

## القواعد الأساسية

### ١. الرموز عربية بالكامل

- **الحرف**: عربي (ق، ب، د، ن، ص، و، ت، ح، م)
- **الأرقام**: عربية-هندية (٠، ١، ٢، ٣، ٤، ٥، ٦، ٧، ٨، ٩)
- **مثال**: `د٠٣٠١` وليس `E0301`

### ٢. التوثيق قبل الكود

عند إضافة رمز خطأ جديد:
1. **أولاً**: أنشئ ملف التوثيق في `docs/رموز_الأخطاء/[فئة]/[رمز].md`
2. **ثانياً**: عرّف الثابت في `src/error/codes.rs`
3. **ثالثاً**: حدّث الفهرس في `docs/رموز_الأخطاء/فهرس.md`

### ٣. استخدام الثوابت المعرفة

```rust
// ✅ صحيح - استخدام ثابت معرف
use crate::error::codes::ERR_BREAK_OUTSIDE_LOOP;
self.error_with_code(msg_en, msg_ar, span, &ERR_BREAK_OUTSIDE_LOOP.to_string());

// ❌ خطأ - ترميز صريح
self.error_with_code(msg_en, msg_ar, span, "د٠٣٠١");
```

### ٤. الفئات المتاحة

| الحرف | الفئة | الاستخدام |
|-------|-------|----------|
| ق | قراءة | أخطاء الـ Lexer |
| ب | بناء | أخطاء الـ Parser |
| د | دلالة | أخطاء دلالية (scope, context) |
| ن | نوع | أخطاء الأنواع |
| ص | صنف | أخطاء OOP |
| و | وحدة | أخطاء الاستيراد/التصدير |
| ت | توليد | أخطاء توليد الكود |
| ح | تحذير | تحذيرات |
| م | مهمل | صيغ مهملة |

## سير العمل لإضافة خطأ جديد

### الخطوة ١: تحديد الفئة والرقم

```bash
# افتح الفهرس لمعرفة آخر رقم مستخدم
cat docs/رموز_الأخطاء/فهرس.md | grep "^| د"
```

### الخطوة ٢: إنشاء التوثيق

استخدم القالب من `docs/رموز_الأخطاء/إجراء_إضافة_خطأ.md`

### الخطوة ٣: تعريف الثابت

```rust
/// [رمز]: [عنوان]
pub const ERR_[اسم]: ErrorCode = ErrorCode::new(ErrorCategory::[فئة], [رقم]);
```

### الخطوة ٤: تحديث الفهرس

أضف صفاً جديداً في `docs/رموز_الأخطاء/فهرس.md`

### الخطوة ٥: كتابة اختبار

```rust
#[test]
fn test_err_[اسم]() {
    assert_eq!(ERR_[اسم].to_string(), "[الرمز]");
}
```
