# ترقيم

**أول لغة برمجة عربية مُترجَمة للأغراض العامة**

## نظرة عامة

ترقيم هي لغة برمجة مُترجَمة للأغراض العامة مع دعم كامل للصياغة العربية. تجمع أفضل الميزات من سهولة قراءة بايثون، ومرونة PHP، وإمكانيات جافاسكربت الحديثة.

### لماذا ترقيم؟

- **دعم عربي أصيل**: اكتب الكود بالكامل بالعربية مع اتجاه النص من اليمين لليسار
- **أداء مُترجَم**: تُترجَم إلى كود آلة أصلي للحصول على أفضل أداء
- **صياغة حديثة**: تجمع أفضل ما في بايثون وPHP وجافاسكربت
- **برمجة كائنية كاملة**: أصناف، واجهات، سمات، أنماط معممة، والمزيد
- **أمان الأنماط**: كتابة ثابتة قوية مع استنتاج الأنماط

## أمثلة على الصياغة

### مرحباً بالعالم

```tarqeem
اطبع("مرحباً بالعالم!")
```

### المتغيرات والأنماط

```tarqeem
// تعريف المتغيرات
متغير اسم = "أحمد"          // متغير قابل للتعديل
ثابت عمر = 25              // ثابت غير قابل للتعديل

// تحديد الأنماط
متغير راتب: عدد_عشري = 5000.50
متغير متزوج: منطقي = صحيح

// أسماء الأنماط العربية
// عدد = عدد صحيح
// عدد_عشري = عدد عشري
// نص = سلسلة نصية
// منطقي = قيمة منطقية
// صحيح/خطأ = صواب/خطأ
```

### الدوال

```tarqeem
// تعريف دالة
دالة جمع(أ: عدد، ب: عدد) -> عدد {
    أرجع أ + ب
}

// دالة سهمية
ثابت مربع = (س: عدد) => س * س

// استدعاء الدالة
متغير نتيجة = جمع(5، 3)
اطبع(نتيجة)  // 8
```

### التحكم في التدفق

```tarqeem
// إذا-وإلا
إذا (عمر >= 18) {
    اطبع("بالغ")
} وإلا إذا (عمر >= 13) {
    اطبع("مراهق")
} وإلا {
    اطبع("طفل")
}

// تطابق
تطابق (يوم) {
    حالة "السبت"، "الأحد" => اطبع("عطلة")
    حالة "الجمعة" => اطبع("نهاية الأسبوع")
    غير_ذلك => اطبع("يوم عمل")
}
```

### الحلقات

```tarqeem
// حلقة لكل
لكل (متغير ع = 0؛ ع < 10؛ ع++) {
    اطبع(ع)
}

// حلقة لكل-في
ثابت أرقام = [1، 2، 3، 4، 5]
لكل رقم في أرقام {
    اطبع(رقم)
}

// حلقة طالما
متغير عداد = 0
طالما (عداد < 5) {
    اطبع(عداد)
    عداد++
}

// افعل-طالما
افعل {
    اطبع("مرة واحدة على الأقل")
} طالما (شرط)
```

### الأصناف والبرمجة الكائنية

```tarqeem
// واجهة
واجهة قابل_للطباعة {
    دالة اطبع_معلومات()
}

// صنف
صنف شخص يطبق قابل_للطباعة {
    // الخصائص
    خاص اسم: نص
    خاص عمر: عدد

    // المنشئ
    منشئ(اسم: نص، عمر: عدد) {
        هذا.اسم = اسم
        هذا.عمر = عمر
    }

    // دالة
    عام دالة اطبع_معلومات() {
        اطبع("الاسم: " + هذا.اسم + "، العمر: " + هذا.عمر)
    }

    // دالة الحصول
    عام دالة احصل_اسم() -> نص {
        أرجع هذا.اسم
    }
}

// الوراثة
صنف موظف يرث شخص {
    خاص راتب: عدد_عشري

    منشئ(اسم: نص، عمر: عدد، راتب: عدد_عشري) {
        أساس(اسم، عمر)
        هذا.راتب = راتب
    }
}

// الاستخدام
متغير شخص١ = جديد شخص("أحمد"، 30)
شخص١.اطبع_معلومات()
```

### الأنماط المعممة

```tarqeem
// صنف معمم
صنف قائمة<ن> {
    خاص عناصر: مصفوفة<ن>

    منشئ() {
        هذا.عناصر = []
    }

    عام دالة أضف(عنصر: ن) {
        هذا.عناصر.ألحق(عنصر)
    }

    عام دالة احصل(فهرس: عدد) -> ن {
        أرجع هذا.عناصر[فهرس]
    }
}

متغير أرقام = جديد قائمة<عدد>()
أرقام.أضف(1)
أرقام.أضف(2)
```

### معالجة الأخطاء

```tarqeem
// حاول-التقط
حاول {
    متغير نتيجة = قسمة(10، 0)
} التقط (خطأ) {
    اطبع("حدث خطأ: " + خطأ.رسالة)
} أخيراً {
    اطبع("تم الانتهاء")
}

// ارمِ
دالة قسمة(أ: عدد، ب: عدد) -> عدد {
    إذا (ب == 0) {
        ارمِ خطأ_جديد("لا يمكن القسمة على صفر")
    }
    أرجع أ / ب
}
```

### الوحدات والاستيراد

```tarqeem
// استيراد
استورد { قائمة، قاموس } من "مجموعات"
استورد * كـ رياضيات من "رياضيات"
استورد ملف_محلي من "./مساعدات"

// تصدير
صدّر دالة مساعدة() {
    // ...
}

صدّر صنف أداة {
    // ...
}
```

### التزامن

```tarqeem
// دالة غير متزامنة
غير_متزامن دالة احضر_بيانات(رابط: نص) -> نص {
    متغير استجابة = انتظر طلب_شبكة(رابط)
    أرجع استجابة.نص()
}

// الاستخدام
غير_متزامن دالة رئيسية() {
    متغير بيانات = انتظر احضر_بيانات("https://api.example.com")
    اطبع(بيانات)
}
```

## التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/osama1998H/tarqeem.git
cd tarqeem

# البناء من المصدر (يتطلب Rust)
cargo build --release

# التثبيت بشكل عام
cargo install --path .

# التحقق من التثبيت
tarqeem --version
```

## الاستخدام

```bash
# ترجمة ملف ترقيم
tarqeem compile برنامج.trq -o برنامج

# التشغيل مباشرة (ترجمة وتنفيذ)
tarqeem run برنامج.trq

# فحص الصياغة بدون ترجمة
tarqeem check برنامج.trq

# تنسيق الكود
tarqeem fmt برنامج.trq

# بدء الوضع التفاعلي
tarqeem repl
```

## امتدادات الملفات

يدعم ترقيم امتدادات الملفات التالية (كلا الامتدادين متكافئان ويعملان بنفس الطريقة):

### ملفات المصدر
| الامتداد | الوصف |
|----------|-------|
| `.trq` | امتداد ASCII للملفات المصدر |
| `.ترقيم` | امتداد عربي للملفات المصدر |

### ملفات الرؤوس
| الامتداد | الوصف |
|----------|-------|
| `.trqh` | امتداد ASCII لملفات الرؤوس والواجهات |
| `.ترقيم-ر` | امتداد عربي لملفات الرؤوس والواجهات |

### أمثلة على أسماء الملفات
```bash
# كلا الملفين صالحان ومتكافئان:
برنامج.trq
برنامج.ترقيم

# ملفات الرؤوس:
أنماط.trqh
أنماط.ترقيم-ر
```
