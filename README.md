# ترقيم

**أول لغة برمجة عربية مُترجَمة للأغراض العامة**

## نظرة عامة

ترقيم هي لغة برمجة مُترجَمة للأغراض العامة مع دعم كامل للصياغة العربية. تجمع أفضل الميزات من سهولة قراءة بايثون، ومرونة PHP، وإمكانيات جافاسكربت الحديثة.

### لماذا ترقيم؟

- **دعم عربي أصيل**: اكتب الكود بالكامل بالعربية مع اتجاه النص من اليمين لليسار
- **أداء مُترجَم**: تُترجَم إلى كود آلة أصلي للحصول على أفضل أداء
- **صياغة حديثة**: تجمع أفضل ما في بايثون وPHP وجافاسكربت
- **برمجة كائنية كاملة**: أصناف، واجهات، سمات، أنماط معممة، والمزيد
- **أمان الأنماط**: كتابة ثابتة قوية مع استنتاج الأنماط

## أمثلة على الصياغة

### مرحباً بالعالم

```tarqeem
اطبع("مرحباً بالعالم!")
```

### المتغيرات والأنماط

```tarqeem
// تعريف المتغيرات
متغير اسم = "أحمد"          // متغير قابل للتعديل
ثابت عمر = 25              // ثابت غير قابل للتعديل

// تحديد الأنماط
متغير راتب: عدد_عشري = 5000.50
متغير متزوج: منطقي = صحيح

// أسماء الأنماط العربية
// عدد = عدد صحيح
// عدد_عشري = عدد عشري
// نص = سلسلة نصية
// منطقي = قيمة منطقية
// صحيح/خطأ = صواب/خطأ
```

### الدوال

```tarqeem
// تعريف دالة
دالة جمع(أ: عدد، ب: عدد) -> عدد {
    أرجع أ + ب
}

// دالة سهمية
ثابت مربع = (س: عدد) => س * س
اطبع(مربع(5))  // 25

// الدوال قيم من الدرجة الأولى: تُمرَّر وتُرجَع
دالة طبّق(ف: (عدد) -> عدد، ق: عدد) -> عدد {
    أرجع ف(ق)
}
اطبع(طبّق((س) => س * 10، 5))  // 50

// استدعاء الدالة
متغير نتيجة = جمع(5، 3)
اطبع(نتيجة)  // 8
```

> مثال أوسع: [`examples/دوال_سهمية.ترقيم`](examples/دوال_سهمية.ترقيم) — يغطي كل
> صيغ الدوال السهمية المدعومة والقيود الحالية (لا التقاط للمتغيرات المحيطة بعد).

### التحكم في التدفق

```tarqeem
// إذا-وإلا
إذا (عمر >= 18) {
    اطبع("بالغ")
} وإلا إذا (عمر >= 13) {
    اطبع("مراهق")
} وإلا {
    اطبع("طفل")
}

// تطابق
تطابق (يوم) {
    حالة "السبت"، "الأحد" => اطبع("عطلة")
    حالة "الجمعة" => اطبع("نهاية الأسبوع")
    غير_ذلك => اطبع("يوم عمل")
}
```

### الحلقات

```tarqeem
// حلقة لكل
لكل (متغير ع = 0؛ ع < 10؛ ع++) {
    اطبع(ع)
}

// حلقة لكل-في
ثابت أرقام = [1، 2، 3، 4، 5]
لكل رقم في أرقام {
    اطبع(رقم)
}

// حلقة طالما
متغير عداد = 0
طالما (عداد < 5) {
    اطبع(عداد)
    عداد++
}

// افعل-طالما
افعل {
    اطبع("مرة واحدة على الأقل")
} طالما (شرط)
```

### الأصناف والبرمجة الكائنية

```tarqeem
// ميثاق
ميثاق قابل_للطباعة {
    دالة اطبع_معلومات()
}

// صنف
صنف شخص يلتزم قابل_للطباعة {
    // الخصائص
    خاص اسم: نص
    خاص عمر: عدد

    // المنشئ
    منشئ(اسم: نص، عمر: عدد) {
        هذا.اسم = اسم
        هذا.عمر = عمر
    }

    // دالة
    عام دالة اطبع_معلومات() {
        اطبع("الاسم: " + هذا.اسم + "، العمر: " + هذا.عمر)
    }

    // دالة الحصول
    عام دالة احصل_اسم() -> نص {
        أرجع هذا.اسم
    }
}

// الوراثة
صنف موظف يرث شخص {
    خاص راتب: عدد_عشري

    منشئ(اسم: نص، عمر: عدد، راتب: عدد_عشري) {
        الأصل(اسم، عمر)
        هذا.راتب = راتب
    }
}

// الاستخدام
متغير شخص١ = جديد شخص("أحمد"، 30)
شخص١.اطبع_معلومات()
```

### الخواص (Property Accessors)

```tarqeem
صنف نقطة {
    // خاصية تلقائية مع قيمة افتراضية
    خاصية س: عدد = 0
    خاصية ص: عدد = 0

    منشئ(س: عدد، ص: عدد) {
        هذا.س = س
        هذا.ص = ص
    }
}

صنف شخص {
    // حقول داعمة خاصة
    خاص _اسم: نص
    خاص _عمر: عدد

    منشئ(اسم: نص، عمر: عدد) {
        هذا._اسم = اسم
        هذا._عمر = عمر
    }

    // خاصية مع احصل وعيّن كاملة
    خاصية اسم: نص {
        احصل {
            أرجع هذا._اسم
        }
        عيّن(قيمة) {
            هذا._اسم = قيمة
        }
    }

    // خاصية للقراءة فقط
    خاصية عمر: عدد {
        احصل {
            أرجع هذا._عمر
        }
    }

    // خاصية محسوبة مختصرة
    خاصية وصف: نص {
        احصل => هذا._اسم + " - عمره " + هذا._عمر
    }
}

// الاستخدام
متغير ش = جديد شخص("أحمد"، 25)
اطبع(ش.اسم)        // أحمد
اطبع(ش.عمر)        // 25
ش.اسم = "محمد"     // تغيير الاسم عبر عيّن
اطبع(ش.اسم)        // محمد
```

### الأنماط المعممة

```tarqeem
// صنف معمم
صنف قائمة<ن> {
    خاص عناصر: مصفوفة<ن>

    منشئ() {
        هذا.عناصر = []
    }

    عام دالة أضف(عنصر: ن) {
        هذا.عناصر.ألحق(عنصر)
    }

    عام دالة احصل(فهرس: عدد) -> ن {
        أرجع هذا.عناصر[فهرس]
    }
}

متغير أرقام = جديد قائمة<عدد>()
أرقام.أضف(1)
أرقام.أضف(2)
```

### معالجة الأخطاء

```tarqeem
// حاول-التقط
حاول {
    متغير نتيجة = قسمة(10، 0)
} التقط (خ) {
    اطبع("حدث استثناء: " + خ.رسالة)
} أخيراً {
    اطبع("تم الانتهاء")
}

// ارمِ — صنف «استثناء» معرَّف تلقائياً، بلا تعريف ولا استيراد
دالة قسمة(أ: عدد، ب: عدد) -> عدد {
    إذا (ب == 0) {
        ارمِ جديد استثناء("لا يمكن القسمة على صفر")
    }
    أرجع أ / ب
}

// أنواع استثناءات خاصة بك: ورّث «استثناء»
صنف استثناء_قسمة يرث استثناء {
    منشئ(رسالة: نص) {
        الأصل(رسالة)
    }
}
```

> **ملاحظة**: `ارمِ` تعمل في المفسّر (`tarqeem run`) وفي الترجمة الفورية
> (`--jit`)؛ الترجمة الأصلية (`tarqeem compile`) ترفضها حالياً بالخطأ
> [ت٠٣٠٣](docs/رموز_الأخطاء/ت/ت٠٣٠٣.md). لا يمكن رمي النصوص ولا الأعداد
> ([ص٠٦٠١](docs/رموز_الأخطاء/ص/ص٠٦٠١.md)).

### الوحدات والاستيراد

```tarqeem
// استيراد
استورد { قائمة، قاموس } من "مجموعات"
استورد * كـ رياضيات من "رياضيات"
استورد ملف_محلي من "./مساعدات"

// تصدير
صدّر دالة مساعدة() {
    // ...
}

صدّر صنف أداة {
    // ...
}

// إعادة تصدير وحدة كاملة — بها تُبنى وحدات «فهرس» في المكتبة القياسية
صدّر * من "./اساسي"
صدّر { باني_نص } من "./بناء"
```

> **ملاحظة**: الاستيراد الشامل يتطلب اسماً مستعاراً (`استورد * كـ س من "…"`).
> لإعادة التصدير استخدم `صدّر * من "…"`.

### الأسطر المتعددة

تنتهي الجملة بسطر جديد، لكن السطر الجديد **داخل قوس مفتوح** لا ينهيها — فيمكن
توزيع المعاملات والعناصر والشروط الطويلة:

```tarqeem
متغير مجموع = اجمع(
    ١،
    ٢
)

إذا (مجموع > ٥ &&
     مجموع < ١٠) {
    اطبع("في النطاق")
}

// متابعة تعبير خارج الأقواس ليست مدعومة
متغير س = ١ +
          ٢          // ❌ خطأ
```

### توثيق الملف

تعليق توثيقي يلي `بسم_الله` مباشرة يوثّق الملف نفسه، ويظهر كوصف الوحدة في
`tarqeem doc`:

```tarqeem
بسم_الله

/// وحدة الرياضيات
///
/// @منذ ١.٠.٠

/// القيمة المطلقة
صدّر دالة مطلق(س: عدد) -> عدد { ... }

الحمد_لله
```

### التزامن

```tarqeem
// دالة متوازية
متوازي دالة احضر_بيانات(رابط: نص) -> نص {
    متغير استجابة = انتظر طلب_شبكة(رابط)
    أرجع استجابة.نص()
}

// الاستخدام
متوازي دالة رئيسية() {
    متغير بيانات = انتظر احضر_بيانات("https://api.example.com")
    اطبع(بيانات)
}
```

## مرجع الكلمات المفتاحية

> **ملاحظة**: ترقيم لغة برمجة عربية بالكامل. الكلمات المفتاحية والمعرفات الإنجليزية **غير مدعومة**.

| الكلمة المفتاحية | الوصف |
|------------------|-------|
| متغير | متغير قابل للتعديل |
| ثابت | ثابت غير قابل للتعديل |
| دالة | تعريف دالة |
| أرجع | جملة الإرجاع |
| إذا | شرط |
| وإلا | فرع وإلا |
| طالما | حلقة طالما |
| لكل | حلقة لكل |
| في | عامل في |
| صنف | تعريف صنف |
| ميثاق | تعريف ميثاق |
| يرث | الوراثة |
| يلتزم | الالتزام بالميثاق |
| عام | وصول عام |
| خاص | وصول خاص |
| محمي | وصول محمي |
| مشترك | عضو مشترك بين النسخ |
| منشئ | المنشئ |
| هذا | مرجع هذا |
| الأصل | مرجع الأب |
| جديد | إنشاء كائن |
| خاصية | تعريف خاصية مع وصول محكوم |
| احصل | قارئ الخاصية (getter) — كلمة سياقية: محجوزة داخل كتل «خاصية» فقط |
| عيّن | كاتب الخاصية (setter) — كلمة سياقية: محجوزة داخل كتل «خاصية» فقط |
| حاول | كتلة المحاولة |
| التقط | كتلة الالتقاط |
| أخيراً | كتلة أخيراً |
| ارمِ | رمي استثناء |
| استورد | استيراد وحدة |
| صدّر | تصدير وحدة |
| من | من |
| كـ | اسم مستعار |
| صحيح | صواب منطقي |
| خطأ | خطأ منطقي |
| لا_شيء | قيمة فارغة |
| متوازي | دالة متوازية |
| انتظر | تعبير الانتظار |
| تطابق | مطابقة الأنماط |
| حالة | فرع الحالة — كلمة سياقية: محجوزة داخل «تطابق» فقط |
| غير_ذلك | الفرع الافتراضي |

> **الكلمات المفتاحية كأسماء**: أسماء الأنماط (`عدد`، `عدد_عشري`، `نص`،
> `منطقي`، `مصفوفة`، `قاموس`، `أي`) تصلح أسماءً لدالة أو دالة عضو أو حقل أو
> خاصية أو معامل أو متغير، وبعد `.` — فـ `دالة عدد()` و`اطبع(نص: نص)`
> صحيحتان. و`صحيح`/`خطأ` تصلحان اسماً لحالة تعداد فقط، لأن الحالة لا تُقرأ
> إلا عبر `::`؛ ولا تصلحان اسماً لصنف.

## التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/osama1998H/tarqeem.git
cd tarqeem

# البناء من المصدر (يتطلب Rust)
cargo build --release

# التثبيت بشكل عام
cargo install --path .

# التحقق من التثبيت
tarqeem --version
```

## الاستخدام

```bash
# ترجمة ملف ترقيم
tarqeem compile برنامج.ترقيم -o برنامج

# التشغيل مباشرة (ترجمة وتنفيذ)
tarqeem run برنامج.ترقيم

```

## نظام رموز الأخطاء

ترقيم تستخدم نظام رموز أخطاء عربي موحد لتسهيل فهم الأخطاء وإصلاحها.

### تنسيق الرمز

كل رمز يتكون من حرف فئة متبوعاً بأربعة أرقام عربية:
- **الحرف**: يحدد فئة الخطأ
- **الأرقام**: تحدد الخطأ المحدد

مثال: `د٠٣٠١` - خطأ دلالي رقم ٣٠١

### فئات الأخطاء

| الحرف | الفئة | الوصف |
|-------|-------|-------|
| ق | قراءة | أخطاء المحلل اللغوي (Lexer) |
| ب | بناء | أخطاء المحلل النحوي (Parser) |
| د | دلالة | أخطاء دلالية (Semantic) |
| ن | نوع | أخطاء الأنواع |
| ص | صنف | أخطاء البرمجة الكائنية |
| و | وحدة | أخطاء الاستيراد والتصدير |
| ت | توليد | أخطاء توليد الكود |
| ح | تحذير | تحذيرات |
| م | مهمل | صيغ مهملة |

### الحصول على شرح الخطأ

```bash
# شرح رمز خطأ
tarqeem اشرح د٠٣٠١

# أو باستخدام الأمر الإنجليزي
tarqeem explain د٠٣٠١
```

### مثال على رسالة خطأ

```
خطأ [د٠٣٠١]: استخدام 'أوقف' خارج حلقة
  --> برنامج.ترقيم:5:5
   |
 5 |     أوقف
   |     ^^^^
   |
   = الشرح: الكلمة المفتاحية 'أوقف' يمكن استخدامها فقط داخل حلقة
```

لمزيد من التفاصيل، راجع [توثيق رموز الأخطاء](docs/رموز_الأخطاء/فهرس.md).

## امتدادات الملفات

يدعم ترقيم امتدادات الملفات التالية:

| النوع | الامتداد | الوصف |
|-------|----------|-------|
| ملفات المصدر | `.ترقيم` | ملفات الكود المصدري |
| ملفات الحزم | `.حزمة` | ملف تهيئة الحزمة |
| ملفات القفل | `.قفل` | ملف قفل الاعتماديات |

### أمثلة على أسماء الملفات
```bash
# ملفات المصدر:
برنامج.ترقيم
مرحبا.ترقيم

# ملفات الحزم:
ترقيم.حزمة    # ملف تهيئة الحزمة
ترقيم.قفل     # ملف قفل الاعتماديات
```

### صيغة ملف الحزمة (ترقيم.حزمة)

صيغة عربية بالكامل لتهيئة الحزم:

```
# ملف تهيئة حزمة ترقيم

حزمة:
    اسم: مكتبتي
    نسخة: ١.٠.٠
    وصف: "مكتبة رائعة للتعامل مع النصوص"
    مؤلفون:
        - أحمد محمد
        - فاطمة علي
    رخصة: MIT
    مدخل: مصدر/رئيسي.ترقيم

اعتماديات:
    json: ٢.٠.٠
    أدوات_نص:
        نسخة: ١.٠.٠
        اختياري: نعم
```

#### مميزات صيغة الحزمة:
- **مسافة بادئة**: بدلاً من الأقواس
- **أرقام عربية**: دعم ٠١٢٣٤٥٦٧٨٩
- **منطقيات عربية**: نعم / لا

- VS Code مع إضافات دعم العربية
- Sublime Text مع إضافات RTL
- بيئة تطوير ترقيم المخصصة (مخطط لها)
