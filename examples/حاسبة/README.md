# الحاسبة العلمية

حاسبة علمية تفاعلية مكتوبة بالكامل بلغة ترقيم، توضح استخدام المكتبة القياسية.

## الميزات

### العمليات الحسابية الأساسية
- الجمع والطرح والضرب والقسمة
- باقي القسمة

### الدوال الرياضية المتقدمة
- الجذر التربيعي
- القوى والأُس
- القيمة المطلقة
- التقريب والسقف والأرضية
- المقارنات (الأقل والأكبر)

### حساب المثلثات
- الجيب والجيب تمام والظل
- الدوال العكسية
- تحويل الدرجات والراديان

### نظرية الأعداد
- فحص الأعداد الأولية
- العاملي (ن!)
- القاسم المشترك الأكبر
- المضاعف المشترك الأصغر
- فحص الزوجي والفردي

### إدارة السجل
- حفظ تاريخ العمليات في ملف
- عرض السجل
- مسح السجل

## المكتبات المستخدمة

| المكتبة | الاستخدام |
|---------|----------|
| `طرفية/اساسي` | الإدخال والإخراج |
| `رياضيات/اساسي` | الدوال الرياضية الأساسية |
| `رياضيات/ثوابت` | الثوابت الرياضية (π، هـ) |
| `رياضيات/مثلثات` | دوال حساب المثلثات |
| `ملفات/ملف` | عمليات الملفات |

## التشغيل

```bash
# من مجلد المشروع الرئيسي
cd examples/حاسبة

# تثبيت الاعتماديات
tarqeem pkg install

# تشغيل الحاسبة
tarqeem pkg run

# أو تشغيل مباشرة
tarqeem run مصدر/رئيسي.trq
```

## الاختبارات

```bash
tarqeem pkg test
```
