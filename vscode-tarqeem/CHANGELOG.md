# Changelog | سجل التغييرات

All notable changes to the Tarqeem VS Code extension will be documented in this file.

## [0.1.0] - 2024-12-20

### Added | الإضافات
- Initial release of Tarqeem VS Code extension
- Full syntax highlighting for Arabic and English keywords
- LSP client integration with Tarqeem language server
- Auto-completion for keywords, types, and symbols
- Real-time diagnostics (errors and warnings)
- Go to Definition
- Find All References
- Symbol renaming
- Document formatting
- Code folding
- Inlay hints for types
- Semantic tokens for enhanced highlighting
- Code actions and quick fixes
- Arabic and English code snippets
- Commands for running, compiling, and formatting code
- REPL integration
- RTL text support utilities
- Bilingual UI (Arabic/English)

### Features | الميزات
- **Syntax Highlighting**: Complete TextMate grammar for Tarqeem
- **IntelliSense**: Context-aware auto-completion
- **Diagnostics**: Real-time error detection with Arabic messages
- **Navigation**: Go to definition, find references
- **Formatting**: Automatic code formatting
- **Snippets**: 30+ code snippets in Arabic and English
- **Commands**: Run, compile, format, check, REPL

### Keyboard Shortcuts | اختصارات لوحة المفاتيح
- `Ctrl+Shift+R`: Run file
- `Ctrl+Shift+B`: Compile file
- `Shift+Alt+F`: Format document
