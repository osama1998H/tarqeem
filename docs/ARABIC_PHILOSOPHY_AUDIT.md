## الفئة الأولى: الدوال المدمجة (حرجة جداً)

### المشكلة
استخدام اصطلاح `__اسم__` للدوال المدمجة - وهو اصطلاح من C/Python غير عربي.

### الحجم
**170+ دالة** موزعة على جميع وحدات المكتبة القياسية.

### أمثلة

```tarqeem
// ❌ الحالي
__جا__(س)
__اطبع__("مرحبا")
__tcp_اتصل__(عنوان، منفذ)

// ✅ المقترح (خيارات)
نظام.جيب(س)
اطبع("مرحبا")           // دالة عامة بدون بادئة
شبكة.اتصل(عنوان، منفذ)
```

### البديل المقترح

**الخيار ١**: حذف البادئة واللاحقة - الدوال تصبح عامة
```tarqeem
اطبع("مرحبا")
جيب(زاوية)
```

**الخيار ٢**: استخدام نطاقات (namespaces)
```tarqeem
نظام.اطبع("مرحبا")
رياضيات.جيب(زاوية)
شبكة.اتصل(عنوان)
```

**الخيار ٣**: بادئة عربية
```tarqeem
مدمج_اطبع("مرحبا")
مدمج_جيب(زاوية)
```

## الفئة الثانية: الكلمات المفتاحية (عالية)

### الكلمات التي تحتاج تغيير

| # | الحالي | الإنجليزي | المشكلة | المقترح | الملف |
|---|--------|-----------|---------|---------|-------|
| 1 | `واجهة` | interface | ترجمة حرفية، لا تعكس "عقد" | `ميثاق` | keywords.rs:42 |
| 2 | `فراغ` | void | الفراغ = الفضاء، ليس "بدون إرجاع" | `منتهية` أو حذف | keywords.rs:90 |
| 3 | `أساس` | super | لا تعكس العلاقة الوراثية | `الأصل` أو `الأب` | keywords.rs:51-52 |
| 4 | `عدم` | null | فلسفية جداً | `لا_شيء` | keywords.rs:75 |
| 5 | `غير_متزامن` | async | ترجمة حرفية معقدة | `متوازي` أو `غير_فوري` | keywords.rs:19 |
| 6 | `ثابت_صنف` | static | ترتيب نحوي خاطئ | `مشترك` | keywords.rs:48 |

### أمثلة التغيير

```tarqeem
// ❌ قبل
واجهة قابل_للطباعة { }
صنف مستخدم يطبق قابل_للطباعة { }
ثابت_صنف عدد عداد = 0
فراغ دالة سجّل() { }

// ✅ بعد
ميثاق الطباعة { }
صنف مستخدم يلتزم الطباعة { }
عدد مشترك عداد = 0
دالة منتهية سجّل() { }  // أو حذف "منتهية" كلياً
```

## الفئة الرابعة: رسائل الخطأ (متوسطة)

### ٤.١ استخدام "/" كفاصل

**المشكلة**: رسائل الخطأ تستخدم "/" بدلاً من هيكل منفصل.

```rust
// ❌ الحالي (في parser.rs)
"Expected variable name / متوقع اسم المتغير"

// ✅ المقترح
Diagnostic {
    message: "Expected variable name",
    message_ar: "متوقع اسم المتغير",
}
```

**عدد الحالات**: 30+ رسالة في parser.rs

### ٤.٢ ترتيب الكلمات غير عربي

| الرسالة الحالية | المشكلة | المقترحة |
|----------------|---------|----------|
| "المتغير يجب أن يحتوي على نوع" | الفعل في الوسط | "يجب أن يحتوي المتغير على نوع" |
| "الشرط يجب أن يكون منطقياً" | نفس المشكلة | "يجب أن يكون الشرط منطقياً" |
| "فهرس المصفوفة يجب أن يكون عدداً" | نفس المشكلة | "يجب أن يكون فهرس المصفوفة عدداً" |

### ٤.٣ مصطلحات غير مترجمة

| الرسالة | المشكلة | المقترحة |
|---------|---------|----------|
| "فشل في كتابة LLVM IR" | اختصار إنجليزي | "فشل في كتابة التمثيل الوسيط" |
| "ثبّت clang أو llc" | أسماء برامج | إضافة توضيح عربي |

## خطة التنفيذ المقترحة

### المرحلة ١: الدوال المدمجة (الأهم)
**الملفات**: `src/semantic/`, `src/codegen/`, `stdlib_trq/`
**المهمة**: تصميم نظام تسمية بديل للدوال المدمجة

الخيارات:
1. حذف `__` والاعتماد على النطاقات
2. استخدام بادئة عربية مثل `_مدمج_`
3. إنشاء وحدات (modules) منفصلة

### المرحلة ٢: الكلمات المفتاحية
**الملفات**: `src/lexer/keywords.rs`, `src/lexer/token.rs`, `src/parser/`
**المهمة**: تغيير الكلمات الست المحددة

الترتيب:
1. `واجهة` → `ميثاق`
2. `يطبق` → `يلتزم`
3. `فراغ` → قرار: حذف أو `منتهية`
4. `ثابت_صنف` → `مشترك`
5. `أساس` → `الأصل`
6. `عدم` → `لا_شيء`

### المرحلة ٣: المكتبة القياسية
**الملفات**: `stdlib_trq/`
**المهمة**: تحديث التسميات

الترتيب:
1. الدوال المثلثية (الأسماء الكاملة)
2. الثوابت (`ط` بدلاً من `باي`)
3. المصطلحات (`معرّف` بدلاً من `مقبض`)

### المرحلة ٤: رسائل الخطأ
**الملفات**: `src/parser/`, `src/semantic/`, `src/error/`
**المهمة**: إصلاح الهيكل والترتيب النحوي

### المرحلة ٥: التوثيق
**الملفات**: `README.md`, `LANGUAGE_SPEC.md`, `examples/`
**المهمة**: تحديث بعد المراحل السابقة

## التوافق العكسي

### استراتيجية الترحيل

```rust
// دعم الأسماء القديمة مع تحذير deprecation
"واجهة" => {
    warn_deprecation("واجهة", "ميثاق");
    TokenKind::Interface
}
"ميثاق" => TokenKind::Interface,

// في المكتبة القياسية
صدّر ثابت ط = 3.141592653589793
صدّر ثابت باي = ط  // deprecated alias
```

### فترة الترحيل
- الإصدار 0.x: دعم كلا الاسمين مع تحذيرات
- الإصدار 1.0: حذف الأسماء القديمة
