## الفئة الأولى: الدوال المدمجة (حرجة جداً)

### المشكلة
استخدام اصطلاح `__اسم__` للدوال المدمجة - وهو اصطلاح من C/Python غير عربي.

### الحجم
**170+ دالة** موزعة على جميع وحدات المكتبة القياسية.

### أمثلة

```tarqeem
// ❌ الحالي
__جا__(س)
__اطبع__("مرحبا")
__tcp_اتصل__(عنوان، منفذ)

// ✅ المقترح (خيارات)
نظام.جيب(س)
اطبع("مرحبا")           // دالة عامة بدون بادئة
شبكة.اتصل(عنوان، منفذ)
```

### البديل المقترح

**الخيار ١**: حذف البادئة واللاحقة - الدوال تصبح عامة
```tarqeem
اطبع("مرحبا")
جيب(زاوية)
```

**الخيار ٢**: استخدام نطاقات (namespaces)
```tarqeem
نظام.اطبع("مرحبا")
رياضيات.جيب(زاوية)
شبكة.اتصل(عنوان)
```

**الخيار ٣**: بادئة عربية
```tarqeem
مدمج_اطبع("مرحبا")
مدمج_جيب(زاوية)
```

## الفئة الثانية: الكلمات المفتاحية (عالية)

### الكلمات التي تحتاج تغيير

| # | الحالي | الإنجليزي | المشكلة | المقترح | الملف | الحالة |
|---|--------|-----------|---------|---------|-------|--------|
| 1 | `واجهة` | interface | ترجمة حرفية، لا تعكس "عقد" | `ميثاق` | keywords.rs:42 | ✅ مكتمل |
| 2 | `فراغ` | void | الفراغ = الفضاء، ليس "بدون إرجاع" | محذوفة | keywords.rs | ✅ تم الحذف |
| 3 | `أساس` | super | لا تعكس العلاقة الوراثية | `الأصل` | keywords.rs:51-52 | ✅ مكتمل |
| 4 | `عدم` | null | فلسفية جداً | `لا_شيء` | keywords.rs:75 | ✅ مكتمل |
| 5 | `غير_متزامن` | async | ترجمة حرفية معقدة | `متوازي` | keywords.rs:19 | ✅ مكتمل |
| 6 | `ثابت_صنف` | static | ترتيب نحوي خاطئ | `مشترك` | keywords.rs:48 | ✅ مكتمل |

### أمثلة التغيير

```tarqeem
// ❌ قبل (المرحلة الأولى)
واجهة قابل_للطباعة { }
صنف مستخدم يطبق قابل_للطباعة { }
ثابت_صنف عدد عداد = 0
فراغ دالة سجّل() { }

// ✅ بعد (تم التنفيذ - المرحلة الأولى)
ميثاق الطباعة { }
صنف مستخدم يلتزم الطباعة { }
مشترك عدد عداد = 0
دالة سجّل() { }  // فراغ محذوفة - الدوال بدون نوع إرجاع لا تُرجع قيمة

// ❌ قبل (المرحلة الثانية)
أساس(اسم)  // استدعاء منشئ الأب
متغير س = عدم  // قيمة فارغة
غير_متزامن دالة احضر() { }  // دالة متوازية

// ✅ بعد (تم التنفيذ - المرحلة الثانية)
الأصل(اسم)  // استدعاء منشئ الأب
متغير س = لا_شيء  // قيمة فارغة
متوازي دالة احضر() { }  // دالة متوازية
```

## الفئة الرابعة: رسائل الخطأ (متوسطة) ✅ مكتمل

### ٤.١ استخدام "/" كفاصل ✅ تم الإصلاح

**المشكلة الأصلية**: رسائل الخطأ في المحلل النحوي كانت تستخدم "/" بدلاً من هيكل منفصل.

**الحل المُنفَّذ**: تم تحديث جميع دوال المساعدة في `parser.rs` لاستخدام معاملات منفصلة:

```rust
// ✅ تم التنفيذ (في parser.rs)
fn expect(&mut self, kind: &TokenKind, en: &str, ar: &str) -> Result<Token, Diagnostic>
fn expect_identifier(&mut self, en: &str, ar: &str) -> Result<String, Diagnostic>
fn expect_string(&mut self, en: &str, ar: &str) -> Result<String, Diagnostic>

// مثال الاستخدام الحالي:
self.expect(&TokenKind::Function, "Expected 'function'", "متوقع 'دالة'")?;
self.expect_identifier("Expected variable name", "متوقع اسم المتغير")?;
```

**عدد الحالات المُصلَحة**: 75+ رسالة في parser.rs

### ٤.٢ ترتيب الكلمات غير عربي

| الرسالة الحالية | المشكلة | المقترحة |
|----------------|---------|----------|
| "المتغير يجب أن يحتوي على نوع" | الفعل في الوسط | "يجب أن يحتوي المتغير على نوع" |
| "الشرط يجب أن يكون منطقياً" | نفس المشكلة | "يجب أن يكون الشرط منطقياً" |
| "فهرس المصفوفة يجب أن يكون عدداً" | نفس المشكلة | "يجب أن يكون فهرس المصفوفة عدداً" |

### ٤.٣ مصطلحات غير مترجمة ✅ تم الإصلاح

| الرسالة القديمة | المشكلة | الرسالة الجديدة | الحالة |
|-----------------|---------|-----------------|--------|
| "فشل في كتابة LLVM IR" | اختصار إنجليزي | "فشل في كتابة التمثيل الوسيط" | ✅ |

## خطة التنفيذ المقترحة

### المرحلة ١: الدوال المدمجة (الأهم)
**الملفات**: `src/semantic/`, `src/codegen/`, `stdlib_trq/`
**المهمة**: تصميم نظام تسمية بديل للدوال المدمجة

الخيارات:
1. حذف `__` والاعتماد على النطاقات
2. استخدام بادئة عربية مثل `_مدمج_`
3. إنشاء وحدات (modules) منفصلة

### المرحلة ٢: الكلمات المفتاحية
**الملفات**: `src/lexer/keywords.rs`, `src/lexer/token.rs`, `src/parser/`
**المهمة**: تغيير الكلمات الست المحددة

الترتيب:
1. `واجهة` → `ميثاق`
2. `يطبق` → `يلتزم`
3. `فراغ` → قرار: حذف أو `منتهية`
4. `ثابت_صنف` → `مشترك`
5. `أساس` → `الأصل`
6. `عدم` → `لا_شيء`

### المرحلة ٣: المكتبة القياسية
**الملفات**: `stdlib_trq/`
**المهمة**: تحديث التسميات

الترتيب:
1. الدوال المثلثية (الأسماء الكاملة)
2. الثوابت (`ط` بدلاً من `باي`)
3. المصطلحات (`معرّف` بدلاً من `مقبض`)

### المرحلة ٤: رسائل الخطأ ✅ مكتمل
**الملفات**: `src/parser/`, `src/cli/commands.rs`
**المهمة**: إصلاح الهيكل والترتيب النحوي
**الإنجازات**:
- تم تحديث دوال المساعدة في parser.rs لاستخدام معاملات منفصلة للرسائل الإنجليزية والعربية
- تم ترجمة المصطلحات التقنية (LLVM IR → التمثيل الوسيط)
- تم إصلاح 75+ رسالة خطأ في المحلل النحوي

### المرحلة ٥: التوثيق
**الملفات**: `README.md`, `LANGUAGE_SPEC.md`, `examples/`
**المهمة**: تحديث بعد المراحل السابقة

4. **[قاموس المعاني](https://www.almaany.com/)**: قاموس عربي-إنجليزي شامل
5. **[ويكيبيديا العربية - قائمة مصطلحات الحاسوب](https://ar.wikipedia.org/wiki/قائمة_مصطلحات_الحاسوب)**
