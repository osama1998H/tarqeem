# المرحلة الثالثة: المكتبة القياسية
# Phase 3: Standard Library

## نظرة عامة | Overview

المرحلة الثالثة تحول ترقيم من مترجم وظيفي إلى لغة برمجة كاملة مع مكتبة قياسية غنية. تغطي هذه المرحلة:

Phase 3 transforms Tarqeem from a functional compiler into a complete programming language with a rich standard library. This phase covers:

1. **نظام الوحدات** - Import/export system (استورد/صدّر)
2. **المجموعات** - Collection types (قائمة، مجموعة، طابور، مكدس)
3. **الملفات** - File system API (ملف، مسار، مجلد)
4. **الشبكة** - Networking API (اتصال، خادم، عميل)
5. **أدوات النص** - String utilities
6. **الرياضيات** - Math library
7. **التاريخ والوقت** - Date/time utilities

## معايير النجاح | Success Criteria

### المرحلة الثالثة مكتملة عندما:

1. **نظام الوحدات يعمل**
   - `استورد X من "مكتبة"` يعمل
   - المكتبة القياسية قابلة للاستيراد
   - لا أخطاء اعتماديات دائرية

2. **المجموعات تعمل**
   - قائمة<ن> مع جميع الدوال
   - مجموعة<ن> مع عمليات المجموعات
   - قاموس<م، ق> مع التكرار

3. **أدوات النص والرياضيات**
   - دوال معالجة النص الشاملة
   - الدوال الرياضية الأساسية والمثلثية

4. **نظام الملفات**
   - قراءة وكتابة الملفات
   - معالجة المسارات
   - إدارة المجلدات

5. **الاختبارات**
   - اختبارات لكل وحدة
   - اختبارات تكامل للمكتبة كاملة
   - جميع الاختبارات الحالية تمر

## المخاطر والتخفيف | Risks and Mitigation

### التحديات المحتملة:

1. **تعقيد نظام الوحدات**
   - التخفيف: البدء بنظام بسيط بدون re-exports
   - خطة بديلة: استخدام include-style imports أولاً

2. **أداء المجموعات**
   - التخفيف: استخدام C runtime للعمليات الثقيلة
   - اختبارات أداء منتظمة

3. **توافق API العربية**
   - التخفيف: مراجعة الأسماء مع متحدثين عربيين
   - توفير aliases إنجليزية

4. **تكامل مع الكود الحالي**
   - التخفيف: الحفاظ على التوافق الخلفي
   - اختبارات انحدار منتظمة
