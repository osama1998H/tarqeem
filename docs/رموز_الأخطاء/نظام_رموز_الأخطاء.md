# نظام رموز الأخطاء في ترقيم

**الإصدار**: ١.٠.٠
**التاريخ**: ٢٠٢٥-١٢-٢٨

## المقدمة

هذا المستند يحدد نظام رموز الأخطاء الخاص بلغة ترقيم. النظام مصمم بالكامل بالعربية، متبعاً فلسفة اللغة في **الوصف لا الترجمة**.

### لماذا نظام رموز عربية؟

١. **الهوية العربية**: ترقيم لغة برمجة عربية أصيلة، ورموز أخطائها يجب أن تكون عربية
٢. **سهولة التذكر**: الحروف العربية تصف فئة الخطأ مباشرة
٣. **التوثيق الذاتي**: كل رمز يحمل معناه في بنيته
٤. **التعليم**: مناسب للمبتدئين العرب في تعلم البرمجة

## فئات الأخطاء

### الفئات الأساسية (حسب مراحل المترجم)

| الحرف | الاسم الكامل | الوصف | نطاق الأرقام |
|-------|-------------|-------|-------------|
| **ق** | قراءة | أخطاء المحلل اللغوي (Lexer) | ق٠٠٠١ - ق٠٩٩٩ |
| **ب** | بناء | أخطاء التحليل النحوي (Parser) | ب٠٠٠١ - ب٠٩٩٩ |
| **د** | دلالة | أخطاء التحليل الدلالي (Semantic) | د٠٠٠١ - د٠٩٩٩ |
| **ن** | نوع | أخطاء فحص الأنواع (Type Check) | ن٠٠٠١ - ن٠٩٩٩ |
| **ص** | صنف | أخطاء البرمجة الكائنية (OOP) | ص٠٠٠١ - ص٠٩٩٩ |
| **و** | وحدة | أخطاء الوحدات والاستيراد (Modules) | و٠٠٠١ - و٠٩٩٩ |
| **ت** | توليد | أخطاء توليد الكود (Codegen) | ت٠٠٠١ - ت٠٩٩٩ |

### فئات فرعية للتحذيرات

| الحرف | الاسم الكامل | الوصف |
|-------|-------------|-------|
| **ح** | تحذير | تحذيرات عامة |
| **م** | مهمل | استخدام صيغة مهملة |

## بنية توثيق رمز الخطأ

كل رمز خطأ يجب أن يكون له ملف توثيق في:
```
docs/رموز_الأخطاء/[حرف_الفئة]/[الرمز_الكامل].md
```

### مثال: `docs/رموز_الأخطاء/د/د٠٣٠١.md`

```markdown
# د٠٣٠١: استخدام 'أوقف' خارج حلقة

## الوصف

هذا الخطأ يحدث عند استخدام كلمة `أوقف` (break) خارج سياق حلقة تكرارية.

## سبب الخطأ

كلمة `أوقف` مخصصة لإيقاف تنفيذ الحلقات (`طالما`، `لكل`)، ولا يمكن استخدامها
خارج هذا السياق.

## مثال الخطأ

\```tarqeem
دالة اختبار() {
    أوقف    // ❌ خطأ: لا توجد حلقة
}
\```

## الحل

استخدم `أوقف` فقط داخل حلقة:

\```tarqeem
دالة اختبار() {
    لكل (متغير ع = 0؛ ع < 10؛ ع++) {
        إذا (ع == 5) {
            أوقف    // ✅ صحيح: داخل حلقة
        }
    }
}
\```

## ملاحظات إضافية

- للخروج من دالة، استخدم `أرجع`
- للانتقال للتكرار التالي، استخدم `استمر`

## انظر أيضاً

- [د٠٣٠٢](د٠٣٠٢.md) - استخدام 'استمر' خارج حلقة
- [د٠٣٠٣](د٠٣٠٣.md) - استخدام 'أرجع' خارج دالة
```

## التكامل مع المترجم

### بنية رمز الخطأ في Rust

```rust
/// رمز خطأ عربي
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub struct ErrorCode {
    /// فئة الخطأ (حرف عربي)
    pub category: ErrorCategory,
    /// رقم الخطأ (0001-9999)
    pub number: u16,
}

/// فئات الأخطاء
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum ErrorCategory {
    /// ق - قراءة (Lexer)
    Qiraa,
    /// ب - بناء (Parser)
    Binaa,
    /// د - دلالة (Semantic)
    Dalala,
    /// ن - نوع (Type)
    Naw,
    /// ص - صنف (Class)
    Sinf,
    /// و - وحدة (Module)
    Wahda,
    /// ت - توليد (Codegen)
    Tawleed,
    /// ح - تحذير (Warning)
    Tahdheer,
    /// م - مهمل (Deprecated)
    Muhmal,
}

impl ErrorCategory {
    /// الحصول على الحرف العربي للفئة
    pub fn arabic_char(&self) -> char {
        match self {
            Self::Qiraa => 'ق',
            Self::Binaa => 'ب',
            Self::Dalala => 'د',
            Self::Naw => 'ن',
            Self::Sinf => 'ص',
            Self::Wahda => 'و',
            Self::Tawleed => 'ت',
            Self::Tahdheer => 'ح',
            Self::Muhmal => 'م',
        }
    }

    /// الحصول على الاسم الكامل للفئة
    pub fn arabic_name(&self) -> &'static str {
        match self {
            Self::Qiraa => "قراءة",
            Self::Binaa => "بناء",
            Self::Dalala => "دلالة",
            Self::Naw => "نوع",
            Self::Sinf => "صنف",
            Self::Wahda => "وحدة",
            Self::Tawleed => "توليد",
            Self::Tahdheer => "تحذير",
            Self::Muhmal => "مهمل",
        }
    }
}

impl std::fmt::Display for ErrorCode {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        // تحويل الرقم إلى أرقام عربية-هندية
        let arabic_digits = to_arabic_numerals(self.number);
        write!(f, "{}{}", self.category.arabic_char(), arabic_digits)
    }
}

/// تحويل رقم إلى أرقام عربية-هندية
fn to_arabic_numerals(n: u16) -> String {
    const ARABIC_DIGITS: [char; 10] = ['٠', '١', '٢', '٣', '٤', '٥', '٦', '٧', '٨', '٩'];
    format!("{:04}", n)
        .chars()
        .map(|c| ARABIC_DIGITS[c.to_digit(10).unwrap() as usize])
        .collect()
}
```

### استخدام رمز الخطأ

```rust
// تعريف الخطأ
const ERR_BREAK_OUTSIDE_LOOP: ErrorCode = ErrorCode {
    category: ErrorCategory::Dalala,
    number: 301,
};

// استخدام في التحليل الدلالي
self.error_with_code(
    "'break' can only be used inside a loop",
    "'أوقف' يمكن استخدامها فقط داخل حلقة",
    stmt.span,
    &ERR_BREAK_OUTSIDE_LOOP.to_string(), // "د٠٣٠١"
);
```

## الخلاصة

نظام رموز الأخطاء العربي في ترقيم يتميز بـ:

١. **عربي بالكامل**: الحروف والأرقام عربية
٢. **وصفي**: الحرف يصف فئة الخطأ
٣. **موثق**: كل خطأ له توثيق تفصيلي
٤. **قابل للتوسع**: مساحة كافية لـ ٩٩٩٩ خطأ في كل فئة
٥. **سهل البحث**: الرموز قصيرة وسهلة التذكر
