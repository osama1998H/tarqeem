# إجراء إضافة رمز خطأ جديد (SOP)

**الإصدار**: ١.٠.٠
**الهدف**: توحيد عملية إضافة رموز أخطاء جديدة في ترقيم

---

## ملخص الإجراء

```
١. تحديد الفئة والرقم ← ٢. إنشاء ملف التوثيق ← ٣. تعريف الثابت في Rust ←
٤. تحديث الفهرس ← ٥. تحديث الاختبارات ← ٦. المراجعة والدمج
```

---

## الخطوات التفصيلية

### الخطوة ١: تحديد الفئة والرقم

#### ١.١ تحديد الفئة المناسبة

| إذا كان الخطأ يتعلق بـ | استخدم الفئة |
|------------------------|-------------|
| قراءة الرموز والحروف | **ق** (قراءة) |
| بناء الجمل والتركيب | **ب** (بناء) |
| معنى الكود والنطاق | **د** (دلالة) |
| الأنواع والتحويلات | **ن** (نوع) |
| الأصناف والوراثة | **ص** (صنف) |
| الاستيراد والتصدير | **و** (وحدة) |
| توليد الكود الآلي | **ت** (توليد) |

#### ١.٢ اختيار الرقم

1. افتح ملف الفهرس: `docs/رموز_الأخطاء/فهرس.md`
2. ابحث عن آخر رقم مستخدم في الفئة
3. استخدم الرقم التالي المتاح

**مثال**: آخر خطأ في فئة `د` هو `د٠٣٠٣`، الرقم التالي هو `د٠٣٠٤`

#### ١.٣ التحقق من عدم التكرار

```bash
# تأكد أن الرمز غير مستخدم
grep -r "د٠٣٠٤" docs/رموز_الأخطاء/
grep -r "د0304" src/
```

### الخطوة ٢: إنشاء ملف التوثيق

#### ٢.١ إنشاء الملف

```bash
# إنشاء المجلد إذا لم يكن موجوداً
mkdir -p docs/رموز_الأخطاء/د

# إنشاء ملف التوثيق
touch docs/رموز_الأخطاء/د/د٠٣٠٤.md
```

#### ٢.٢ استخدام القالب

انسخ القالب التالي واملأ الحقول:

```markdown

[وصف تفصيلي للخطأ - ماذا يعني هذا الخطأ؟]

## سبب الخطأ

[لماذا يحدث هذا الخطأ؟ ما القاعدة التي تم انتهاكها؟]

## مثال الخطأ

```tarqeem
// كود يسبب هذا الخطأ
[الكود هنا]
```

**الرسالة**:
```
خطأ[د٠٣٠٤]: [الرسالة التي تظهر للمستخدم]
```

## الحل

```tarqeem
// الكود الصحيح

```

## حالات شائعة

### الحالة ١: [وصف الحالة]

```tarqeem

```

### الحالة ٢: [وصف الحالة]

```tarqeem

```

## ملاحظات إضافية

- [ملاحظة ١]
- [ملاحظة ٢]

#### ٢.٣ معايير الجودة للتوثيق

- [ ] العنوان واضح ومختصر
- [ ] الوصف يشرح الخطأ للمبتدئين
- [ ] مثال الخطأ قابل للتنفيذ
- [ ] الحل يعمل فعلاً
- [ ] اللغة عربية سليمة
- [ ] لا يوجد خلط مع الإنجليزية (إلا للمصطلحات التقنية الضرورية)

### الخطوة ٣: تعريف الثابت في Rust

#### ٣.١ إضافة التعريف في `src/error/codes.rs`

```rust
/// د٠٣٠٤: [العنوان المختصر]
///
/// [وصف مختصر للخطأ]
pub const ERR_[الاسم_بالانجليزية]: ErrorCode = ErrorCode {
    category: ErrorCategory::Dalala,
    number: 304,
};
```

**قواعد التسمية**:
- استخدم `ERR_` كبادئة
- الاسم بأحرف كبيرة (SCREAMING_SNAKE_CASE)
- الاسم يصف الخطأ بالإنجليزية (للتوافق مع Rust)

**مثال**:
```rust
/// د٠٣٠٤: استخدام 'هذا' خارج دالة منشئ
pub const ERR_THIS_OUTSIDE_CONSTRUCTOR: ErrorCode = ErrorCode {
    category: ErrorCategory::Dalala,
    number: 304,
};
```

#### ٣.٢ استخدام الخطأ في الكود

```rust
use crate::error::codes::ERR_THIS_OUTSIDE_CONSTRUCTOR;

// عند اكتشاف الخطأ
self.error_with_code(
    "'this' can only be used in constructor",      // الرسالة بالإنجليزية
    "'هذا' يمكن استخدامها فقط داخل المنشئ",        // الرسالة بالعربية
    span,
    &ERR_THIS_OUTSIDE_CONSTRUCTOR.to_string(),     // "د٠٣٠٤"
);
```

#### ٤.١ تحرير `docs/رموز_الأخطاء/فهرس.md`

| د٠٣٠٢ | استخدام 'استمر' خارج حلقة | [د٠٣٠٢](د/د٠٣٠٢.md) |
| د٠٣٠٣ | استخدام 'أرجع' خارج دالة | [د٠٣٠٣](د/د٠٣٠٣.md) |
| **د٠٣٠٤** | **استخدام 'هذا' خارج منشئ** | **[د٠٣٠٤](د/د٠٣٠٤.md)** | ← جديد
```

### الخطوة ٥: تحديث الاختبارات

#### ٥.١ اختبار رمز الخطأ

أضف اختباراً في `src/error/codes_tests.rs`:

```rust
#[test]
fn test_err_this_outside_constructor() {
    let code = ERR_THIS_OUTSIDE_CONSTRUCTOR;
    assert_eq!(code.category, ErrorCategory::Dalala);
    assert_eq!(code.number, 304);
    assert_eq!(code.to_string(), "د٠٣٠٤");
}
```

#### ٥.٢ اختبار تكاملي (اختياري)

أضف ملف اختبار في `tests/errors/`:

```rust
#[test]
fn test_this_outside_constructor_error() {
    let source = r#"
        صنف اختبار {
            منشئ() { }
        }

        دالة خارجية() {
            اطبع(هذا.اسم)  // يجب أن يُنتج خطأ د٠٣٠٤
        }
    "#;

    let result = compile(source);
    assert!(result.is_err());
    assert!(result.unwrap_err().code == Some("د٠٣٠٤".to_string()));
}
```

## الأخطاء الشائعة في الإجراء

| الخطأ | التصحيح |
|-------|---------|
| استخدام أرقام غربية (0304) | استخدم أرقام عربية (٠٣٠٤) في التوثيق |
| نسيان تحديث الفهرس | الفهرس ضروري للبحث |

## أتمتة الإجراء (للوكلاء AI)

### تعليمات للوكيل

عند طلب إضافة رمز خطأ جديد:

1. **قبل البدء**: اقرأ `docs/رموز_الأخطاء/نظام_رموز_الأخطاء.md`
2. **تحقق من الفهرس**: `docs/رموز_الأخطاء/فهرس.md`
3. **اتبع الإجراء**: هذا الملف
4. **لا تخترع رموزاً**: استخدم الرقم التالي المتاح فقط

### ملف الفحص الآلي `.claude/rules/error-codes.md`

```markdown
# قواعد رموز الأخطاء

## عند إضافة رمز خطأ جديد

1. اقرأ `docs/رموز_الأخطاء/فهرس.md` لمعرفة آخر رقم
2. أنشئ ملف التوثيق أولاً
3. ثم عرّف الثابت في Rust
4. حدّث الفهرس
5. تأكد من وجود اختبار

## التحقق

- كل `error_with_code()` يجب أن يستخدم ثابتاً معرفاً
- لا ترميز صريح للأرقام (hardcoded)
- كل ثابت له توثيق
```
