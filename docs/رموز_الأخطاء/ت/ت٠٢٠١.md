# ت٠٢٠١: تعارض وضع نقطة الدخول

## الوصف

هذا الخطأ يحدث عند وجود كل من **كود تنفيذي علوي** (وضع السكربت) و**دالة رئيسية()** (وضع البرنامج) في نفس الملف.

لغة ترقيم تدعم وضعين متعارضين لتحديد نقطة دخول البرنامج. لا يمكن استخدام الوضعين معاً في نفس الملف.

## سبب الخطأ

المترجم يحتاج لتحديد نقطة دخول واحدة فقط للبرنامج:

- **وضع السكربت**: الكود التنفيذي العلوي يُعتبر نقطة الدخول
- **وضع البرنامج**: دالة `رئيسية()` تُعتبر نقطة الدخول

عند وجود كليهما، يحدث تعارض لأن البرنامج لا يعرف أيهما ينفذ أولاً.

## مثال الخطأ

```tarqeem
بسم_الله

اطبع("كود علوي")    // ← وضع السكربت

دالة رئيسية() {      // ← وضع البرنامج
    اطبع("في الرئيسية")
}

الحمد_لله
```

**الرسالة**:
```
خطأ[ت٠٢٠١]: لا يمكن وجود جمل تنفيذية عليا ودالة رئيسية() في نفس الملف
  --> ملف.ترقيم

استخدم إما وضع السكربت (كود علوي) أو وضع البرنامج (دالة رئيسية)
```

## الحل

اختر أحد الوضعين:

### الحل ١: وضع السكربت (إزالة دالة رئيسية)

مناسب للسكربتات القصيرة والبرامج البسيطة:

```tarqeem
بسم_الله

// ✅ وضع السكربت - الكود العلوي هو نقطة الدخول
اطبع("مرحباً بالعالم!")

متغير س = 5
اطبع("القيمة: " + س)

الحمد_لله
```

### الحل ٢: وضع البرنامج (نقل الكود إلى دالة رئيسية)

مناسب للبرامج الكبيرة والمنظمة:

```tarqeem
بسم_الله

// ✅ وضع البرنامج - دالة رئيسية هي نقطة الدخول

// المتغيرات العامة مسموحة
ثابت الإصدار = "1.0.0"

// الدوال المساعدة
دالة تحية() {
    اطبع("مرحباً بالعالم!")
}

// نقطة الدخول
دالة رئيسية() {
    تحية()
    اطبع("الإصدار: " + الإصدار)
}

الحمد_لله
```

## ما يُعتبر كود تنفيذي علوي

| نوع الجملة | هل يُعتبر كود تنفيذي علوي؟ |
|------------|---------------------------|
| `متغير` / `ثابت` (تعريفات عامة) | لا ✓ |
| `دالة` (تعريف دالة) | لا ✓ |
| `صنف` (تعريف صنف) | لا ✓ |
| `ميثاق` (تعريف ميثاق) | لا ✓ |
| `اطبع()` (استدعاء دالة) | نعم ✗ |
| `إذا` / `طالما` (تحكم) | نعم ✗ |
| التعبيرات والإسنادات | نعم ✗ |

## لماذا هذا التصميم؟

هذا التصميم يضمن:

1. **سلوك متوقع**: نقطة دخول واحدة فقط - لا غموض
2. **توافق مع الأدوات**: بيئات التطوير والمصححات تستطيع تحديد نقطة الدخول بسهولة
3. **قابلية التوسع**: وضع البرنامج يشجع على تنظيم الكود في برامج كبيرة
4. **بساطة**: وضع السكربت يسمح ببرامج سريعة بدون قوالب

## أمثلة إضافية

### مثال صحيح: وضع البرنامج مع متغيرات عامة

```tarqeem
بسم_الله

// المتغيرات العامة مسموحة مع دالة رئيسية
متغير عداد = 0
ثابت الحد_الأقصى = 100

دالة زيادة() {
    عداد = عداد + 1
}

دالة رئيسية() {
    طالما (عداد < الحد_الأقصى) {
        زيادة()
    }
    اطبع("العداد: " + عداد)
}

الحمد_لله
```

### مثال خطأ: لا يمكن الجمع بين الوضعين

```tarqeem
بسم_الله

// ❌ هذا يسبب خطأ ت٠٢٠١
متغير س = 5
س = س + 1        // تعبير تنفيذي علوي!

دالة رئيسية() {  // دالة رئيسية موجودة!
    اطبع(س)
}

الحمد_لله
```
