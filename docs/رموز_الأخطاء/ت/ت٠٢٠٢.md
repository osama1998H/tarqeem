# ت٠٢٠٢: لا توجد نقطة دخول للبرنامج

## الوصف

هذا الخطأ يحدث عند محاولة ترجمة أو تشغيل ملف **لا يحتوي على نقطة دخول**: لا كود
تنفيذي علوي (وضع السكربت) ولا `دالة رئيسية()` (وضع البرنامج).

الملف الذي يحتوي على تعريفات فقط — دوال، أصناف، مواثيق، تعدادات، متغيرات عامة،
أو تصديرات — هو **وحدة مكتبة** صالحة تماماً، لكنه ليس برنامجاً قابلاً للتنفيذ.
الوحدة تُستعمل بالاستيراد من ملف آخر، لا بترجمتها وحدها إلى ملف تنفيذي.

## سبب الخطأ

الملف التنفيذي يحتاج دالة بداية واحدة يبدأ التنفيذ منها. المترجم يشتقّها من
أحد شكلين:

- **وضع السكربت**: الجمل التنفيذية العليا تصبح نقطة الدخول
- **وضع البرنامج**: `دالة رئيسية()` تصبح نقطة الدخول

إن غاب الشكلان معاً، لا توجد دالة بداية تُنتَج، ولا يمكن إكمال الترجمة.

## مثال الخطأ

```tarqeem
بسم_الله

صدّر دالة مساعدة() -> عدد {
    أرجع 5
}

صدّر صنف أداة { }

الحمد_لله
```

**الرسالة**:
```
خطأ[ت٠٢٠٢]: لا يحتوي الملف على نقطة دخول: لا جمل تنفيذية عليا ولا دالة رئيسية()
```

## الحل

### الحل ١: استيراد الوحدة من برنامج (الأرجح)

الوحدة التي تحتوي تعريفات فقط لا تُترجَم وحدها؛ تُستورَد من ملف فيه نقطة دخول،
ويُترجَم ذلك الملف:

```tarqeem
// مكتبة.ترقيم — وحدة، لا تُترجَم وحدها
بسم_الله

صدّر دالة مساعدة() -> عدد {
    أرجع 5
}

الحمد_لله
```

```tarqeem
// رئيسي.ترقيم — البرنامج، هذا ما يُترجَم
بسم_الله

استورد { مساعدة } من "./مكتبة"

دالة رئيسية() {
    اطبع(مساعدة())
}

الحمد_لله
```

```bash
ترقيم ترجم رئيسي.ترقيم -o برنامج
```

### الحل ٢: إضافة دالة رئيسية (وضع البرنامج)

إن كان المقصود أن يكون الملف برنامجاً:

```tarqeem
بسم_الله

دالة مساعدة() -> عدد {
    أرجع 5
}

دالة رئيسية() {
    اطبع(مساعدة())
}

الحمد_لله
```

### الحل ٣: إضافة كود تنفيذي علوي (وضع السكربت)

مناسب للسكربتات القصيرة:

```tarqeem
بسم_الله

دالة مساعدة() -> عدد {
    أرجع 5
}

اطبع(مساعدة())

الحمد_لله
```

## ما لا يُعتبر نقطة دخول

| نوع الجملة | ينشئ نقطة دخول؟ |
|------------|------------------|
| `متغير` / `ثابت` (تعريفات عامة) | لا |
| `دالة` (تعريف دالة غير `رئيسية`) | لا |
| `صنف` / `ميثاق` / `تعداد` | لا |
| `استورد` / `صدّر` | لا |
| `دالة رئيسية()` | نعم — وضع البرنامج |
| `اطبع()` وسائر الجمل التنفيذية العليا | نعم — وضع السكربت |

## لماذا خطأ وليس ملفاً تنفيذياً فارغاً؟

ترجمة وحدة مكتبة إلى ملف تنفيذي لا معنى لها: الناتج لن ينفّذ شيئاً. إنتاج ملف
تنفيذي صامت يخفي الخطأ الحقيقي — أن المستخدم ترجم الملف الخطأ — إلى أن يشغّله
ويجده لا يفعل شيئاً. رفض الترجمة يوجّهه فوراً إلى الملف الصحيح.
