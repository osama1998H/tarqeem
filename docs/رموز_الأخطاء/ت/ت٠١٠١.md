# ت٠١٠١: فشل الربط

## الوصف

هذا الخطأ يحدث عندما يفشل الرابط (Linker) في دمج ملفات الكود المُترجَم إلى ملف تنفيذي واحد.

الربط هو المرحلة الأخيرة في عملية الترجمة، حيث يتم دمج كل الأجزاء مع المكتبات المطلوبة.

## سبب الخطأ

الأسباب الشائعة:

1. **مكتبة غير موجودة**: مكتبة مطلوبة غير مُثبّتة
2. **رمز غير معرف**: دالة أو متغير مُستخدَم لكن غير موجود
3. **رمز مكرر**: تعريف نفس الرمز في أماكن متعددة
4. **عدم توافق المنصة**: مكتبة غير متوافقة مع نظام التشغيل
5. **أدوات بناء مفقودة**: clang أو ld غير مُثبّت

## مثال الخطأ

```
خطأ[ت٠١٠١]: فشل ربط الملف التنفيذي
  --> برنامج.ترقيم
  |
  = فشل الرابط: undefined reference to `دالة_خارجية'
  |
  = تأكد من وجود جميع المكتبات المطلوبة
```

## الحل

### الحل ١: تثبيت أدوات البناء

**على macOS:**
```bash
xcode-select --install
```

**على Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install build-essential clang llvm
```

**على Fedora:**
```bash
sudo dnf install clang llvm gcc
```

**على Windows:**
```bash
# تثبيت Visual Studio Build Tools أو MinGW
```

### الحل ٢: التحقق من المكتبات

إذا كان الخطأ يذكر مكتبة معينة:

```bash
# البحث عن مكتبة
ldconfig -p | grep libname

# على macOS
brew search libname
```

### الحل ٣: تحديد مسار المكتبات

```bash
# تعيين مسار المكتبات
export LD_LIBRARY_PATH=/path/to/libs:$LD_LIBRARY_PATH

# على macOS
export DYLD_LIBRARY_PATH=/path/to/libs:$DYLD_LIBRARY_PATH
```

### الحل ٤: التحقق من الدوال الخارجية

إذا كان الخطأ يذكر "undefined reference":

```tarqeem
// تأكد من أن الدالة الخارجية معرّفة في مكتبة وقت التشغيل
// أو في ملف C مُرفق

// مثال: دالة من المكتبة القياسية
اطبع("مرحبا")  // ✅ معرّفة في runtime

// مثال: دالة مفقودة
دالة_غير_موجودة()  // ❌ غير معرّفة
```

## رسائل الخطأ الشائعة

### رمز غير معرف (Undefined Symbol)

```
undefined reference to `اسم_الدالة'
```

**السبب**: الدالة مُستدعاة لكن تعريفها غير موجود.

**الحل**: تأكد من تعريف الدالة أو استيرادها من المكتبة الصحيحة.

### رمز مكرر (Duplicate Symbol)

```
duplicate symbol `اسم_المتغير'
```

**السبب**: نفس الرمز معرّف في ملفين.

**الحل**: احذف أحد التعريفات أو استخدم `مشترك` للمتغيرات العامة.

### مكتبة غير موجودة (Library Not Found)

```
library not found for -lname
```

**السبب**: المكتبة المطلوبة غير مُثبّتة.

**الحل**: ثبّت المكتبة عبر مدير الحزم.

## مراحل الترجمة

```
┌─────────────┐
│ كود ترقيم   │
└──────┬──────┘
       ↓ (التحليل)
┌─────────────┐
│    AST      │
└──────┬──────┘
       ↓ (التوليد)
┌─────────────┐
│  LLVM IR    │
└──────┬──────┘
       ↓ (الترجمة)
┌─────────────┐
│ ملف كائن   │
│   (.o)      │
└──────┬──────┘
       ↓ (الربط) ← هنا يحدث الخطأ
┌─────────────┐
│ ملف تنفيذي │
└─────────────┘
```

## التشخيص المتقدم

### عرض تفاصيل الربط

```bash
# تشغيل المترجم مع تفاصيل الربط
RUST_LOG=debug tarqeem compile برنامج.ترقيم -v
```

### فحص ملف الكائن

```bash
# عرض الرموز في ملف الكائن
nm برنامج.o

# على macOS
otool -L برنامج
```

### التحقق من المترجم

```bash
# التحقق من وجود clang
which clang

# التحقق من إصدار clang
clang --version
```

## أفضل الممارسات

1. **حافظ على أدوات البناء محدّثة**: clang, llvm, ld
2. **استخدم المكتبة القياسية**: بدلاً من مكتبات خارجية غير معروفة
3. **تجنب التعريفات المتكررة**: كل رمز يُعرّف مرة واحدة فقط
4. **اختبر على منصات متعددة**: إذا كان البرنامج سيعمل على أنظمة مختلفة
