# ت٠٣٠١: تعذّر تحديد الأنواع للترجمة الأصلية

## الوصف

هذا الخطأ يحدث عند ترجمة دالة (سهمية أو مُعلَنة بـ`دالة`) إلى كود أصلي (`tarqeem compile`) بينما لا تكفي أنواعها الثابتة لتحديد واجهة تطبيق ثنائية (ABI). حالتان:

١. **معامل بدون نوع محدد** — لا تحديد صريح، ولا نوع مُستنتج من سياق التصريح (مثل تعليق نوع دالة على المتغير الذي يخزّنها). النوع `أي` **لا يكفي**: فهو يعني "أي نوع"، وهو ما لا يمكن للترجمة الأصلية اختيار تمثيل ثنائي له.

٢. **قيم إرجاع بأنواع غير متوافقة** في نفس الدالة السهمية (مثل `أرجع "نص"` و`أرجع ١`). المحلل الدلالي يقبل هذا ويطوي النوع إلى `أي`، والمفسّر ينفّذه اعتماداً على القيم وقت التشغيل، لكن الكود الأصلي يحتاج نوع إرجاع واحداً محدداً.

## سبب الخطأ

المفسّر (interpreter) يتعامل مع الأنواع ديناميكياً وقت التشغيل، فمعامل بدون نوع محدد (`أي`) لا يسبب له مشكلة. لكن الترجمة الأصلية عبر LLVM تحتاج نوعاً حقيقياً في كل موضع — تخصيص الذاكرة، توقيع الدالة، واستدعاء المؤشر غير المباشر. معامل بدون نوع كان سيُخفَض إلى مؤشر عام، بينما موقع الاستدعاء قد يمرر قيمة من نوع مختلف تماماً (مثل `عدد`)، مما ينتج استدعاءً بتوقيع غير متطابق — يُترجَم وينُبنى بنجاح، لكنه يُنتج سلوكاً غير معرَّف أو انهياراً وقت التشغيل.

هذا الفحص يمنع هذا الصنف من الأخطاء الصامتة بتحويله إلى خطأ ترجمة واضح.

## مثال الخطأ

```tarqeem
بسم_الله
ثابت جمع = (أ، ب) => أ + ب    // 'أ' و'ب' بدون نوع محدد
اطبع(جمع(3، 4))
الحمد_لله
```

```
tarqeem compile برنامج.ترقيم
خطأ[ت٠٣٠١]: معامل الدالة السهمية بدون نوع في الترجمة الأصلية
  = الحل: أضف نوعاً للمعامل، أو صرّح بنوع الدالة الكامل عند تخزينها في متغير
```

**ملاحظة**: نفس البرنامج يعمل بلا مشاكل مع `tarqeem run` (المفسّر) — القيد خاص بالترجمة الأصلية فقط.

## الحل

### الحل ١: أضف نوعاً لكل معامل مباشرة

```tarqeem
بسم_الله
ثابت جمع = (أ: عدد، ب: عدد) => أ + ب    // ✅ صحيح
اطبع(جمع(3، 4))
الحمد_لله
```

### الحل ٢: صرّح بنوع الدالة الكامل على المتغير

```tarqeem
بسم_الله
ثابت جمع: (عدد، عدد) -> عدد = (أ، ب) => أ + ب    // ✅ صحيح: المعاملان يستنتجان 'عدد' من التعليق
اطبع(جمع(3، 4))
الحمد_لله
```

## حالات شائعة

### الحالة ١: تشغيل بالمفسّر بدلاً من الترجمة الأصلية

إذا لم تكن الترجمة الأصلية مطلوبة، شغّل البرنامج بالمفسّر مباشرة، والذي لا يفرض هذا القيد:

```bash
tarqeem run برنامج.ترقيم
```

### الحالة ٢: دالة سهمية مُمررة كوسيط لدالة أخرى

عند تمرير دالة سهمية غير مُصرَّح بنوعها كوسيط، النوع يُستنتج من توقيع المعامل المُعلَن في الدالة المستقبِلة — لا حاجة لتصريح إضافي:

```tarqeem
دالة طبّق(ف: (عدد) -> عدد، ق: عدد) -> عدد {
    أرجع ف(ق)
}

دالة رئيسية() {
    // ✅ صحيح: نوع 'س' يُستنتج من توقيع 'طبّق' وقت التحليل الدلالي
    اطبع(طبّق((س) => س * 2، 5))
}
```
