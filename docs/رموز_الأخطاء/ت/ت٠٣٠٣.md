# ت٠٣٠٣: رمي الاستثناءات غير مدعوم في الترجمة الأصلية

## الوصف

هذا الخطأ يحدث عند ترجمة برنامج يحتوي على `ارمِ` إلى كود أصلي (`tarqeem compile`). رمي الاستثناءات مدعوم في **المفسّر** (`tarqeem run`) وفي **الترجمة الفورية** (`tarqeem run --jit`)، ولم يُنفَّذ بعد في مولّد الكود الأصلي.

القيد يخصّ `ارمِ` وحدها. كتلة `حاول`/`التقط`/`أخيراً` لا تمنع الترجمة الأصلية ما دام البرنامج لا يرمي شيئاً.

## سبب الخطأ

نقل التحكّم من موضع الرمي إلى أقرب `التقط` — عبر إطارات الاستدعاء — يحتاج آلية فكّ (unwinding) في الكود الأصلي: إمّا `invoke`/`landingpad` في LLVM، وإمّا مكدس معالجات في مكتبة وقت التشغيل. لا واحدة منهما منفَّذة بعد. التصميم والتنفيذ متعقَّبان في [#238](https://github.com/osama1998H/tarqeem/issues/238).

قبل إضافة هذا الفحص كان البرنامج يُترجَم ثم يفشل عند **الربط** برسالة عن رمز داخلي غير معرَّف (`_trq_throw`) لا تدل المستخدم على شيء. الفحص يحوّل ذلك إلى رسالة تصف السبب الحقيقي وتذكر البديل.

## مثال الخطأ

```tarqeem
بسم_الله
حاول {
    ارمِ جديد استثناء("خطأ تجريبي")
} التقط (خ) {
    اطبع("التقطت: " + خ.رسالة)
}
الحمد_لله
```

```
tarqeem compile برنامج.ترقيم
خطأ في توليد الكود [ت٠٣٠٣]: رمي الاستثناءات بـ «ارمِ» غير مدعوم في الترجمة الأصلية بعد — شغّل البرنامج بالمفسّر (tarqeem run) أو بالترجمة الفورية (tarqeem run --jit)
```

## الحل

### الحل ١: شغّل البرنامج بالمفسّر أو بالترجمة الفورية

كلاهما ينفّذ الاستثناءات تنفيذاً كاملاً، بما في ذلك انتشارها عبر الدوال:

```bash
tarqeem run برنامج.ترقيم
tarqeem run --jit برنامج.ترقيم
```

```
التقطت: خطأ تجريبي
```

### الحل ٢: استبدل الرمي بقيمة إرجاع عندما تحتاج ملفاً تنفيذياً

إذا كان إنتاج ملف تنفيذي أصلي شرطاً، عبّر عن الفشل بقيمة مُرجَعة بدلاً من رميه:

```tarqeem
بسم_الله
دالة قسمة_آمنة(أ: عدد، ب: عدد) -> عدد {
    إذا (ب == 0) {
        اطبع_خطأ("لا يمكن القسمة على صفر")
        أرجع 0
    }
    أرجع أ / ب
}

اطبع(قسمة_آمنة(10، 2))
الحمد_لله
```

## ملاحظة على الفروق بين الأوضاع

| الصيغة | `tarqeem run` | `--jit` | `tarqeem compile` |
|--------|----------------|---------|-------------------|
| `حاول`/`التقط`/`أخيراً` بلا رمي | ✅ | ✅ | ✅ |
| `ارمِ` | ✅ | ✅ | ❌ ت٠٣٠٣ |
