# ت٠٠٠١: خطأ داخلي في LLVM

## الوصف

هذا الخطأ يحدث عندما يفشل مُولّد الكود (Code Generator) في تحويل الكود الوسيط إلى كود آلة عبر LLVM.

هذا خطأ نادر يُشير عادة إلى مشكلة داخلية في المترجم أو عدم توافق مع إصدار LLVM.

## سبب الخطأ

الأسباب المحتملة:

1. **خطأ داخلي في المترجم**: مشكلة في توليد IR الوسيط
2. **عدم توافق LLVM**: إصدار LLVM غير متوافق
3. **نفاد الذاكرة**: ذاكرة غير كافية لتوليد الكود
4. **كود معقد جداً**: تعقيد يتجاوز حدود LLVM (نادر جداً)

## مثال الخطأ

```
خطأ[ت٠٠٠١]: خطأ داخلي في توليد الكود
  --> ملف.ترقيم
  |
  = فشل LLVM في معالجة الكود الوسيط
  = الرسالة: <رسالة LLVM التفصيلية>
  |
  = هذا خطأ داخلي في المترجم
  = يرجى الإبلاغ عنه: https://github.com/osama1998H/tarqeem/issues
```

## الحل

### الحل ١: تحديث المترجم

تأكد من استخدام أحدث إصدار من ترقيم:

```bash
# تحديث المترجم
cargo install --path . --force

# أو من المستودع
git pull origin main
cargo build --release
```

### الحل ٢: التحقق من إصدار LLVM

```bash
# التحقق من إصدار LLVM المُثبّت
llvm-config --version

# يجب أن يكون LLVM 14 أو أحدث
```

### الحل ٣: تبسيط الكود

إذا كان الخطأ يحدث مع كود معين، حاول تبسيطه:

```tarqeem
// بدلاً من دالة معقدة واحدة
دالة معقدة_جداً() {
    // مئات الأسطر...
}

// قسّمها إلى دوال أصغر
دالة جزء١() { ... }
دالة جزء٢() { ... }
دالة رئيسية() {
    جزء١()
    جزء٢()
}
```

### الحل ٤: الإبلاغ عن الخطأ

إذا استمر الخطأ، أبلغ عنه مع:

1. **نسخة الكود**: الكود الذي يُسبب الخطأ
2. **رسالة الخطأ الكاملة**: انسخ كل الرسالة
3. **معلومات النظام**: نظام التشغيل، إصدار LLVM
4. **إصدار المترجم**: `tarqeem --version`

## معلومات تقنية

### ما هو LLVM؟

LLVM هو إطار عمل لتوليد الكود الآلي يستخدمه ترقيم لتحويل الكود إلى ملفات تنفيذية.

```
كود ترقيم → AST → IR وسيط → LLVM IR → كود آلي → ملف تنفيذي
                              ↑
                        هنا يحدث الخطأ
```

### رموز الخطأ الداخلية

قد تظهر رسائل LLVM مثل:

- `Invalid type for argument`: نوع غير صحيح
- `Undefined value used`: قيمة غير معرفة
- `Broken function found`: دالة معطوبة

## متى يحدث هذا الخطأ؟

| السيناريو | احتمال الخطأ |
|-----------|-------------|
| كود عادي | نادر جداً |
| استخدام ميزات متقدمة | نادر |
| إصدار قديم من المترجم | متوسط |
| LLVM غير متوافق | مرتفع |

## الوقاية

1. **استخدم الإصدار الرسمي**: لا تُعدّل المترجم يدوياً
2. **تحديث منتظم**: حدّث المترجم بانتظام
3. **تجنب الكود المُفرط التعقيد**: قسّم الدوال الكبيرة
