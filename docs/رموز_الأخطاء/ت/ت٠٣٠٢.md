# ت٠٣٠٢: استدعاء قيمة دالة بدون توقيع معروف في الترجمة الأصلية

## الوصف

هذا الخطأ يحدث عند ترجمة برنامج إلى كود أصلي (`tarqeem compile`) يستدعي قيمة دالة (lambda أو دالة مخزّنة في متغير) لا يعرف المترجم توقيعها الثابت — الحالة الأشهر: قيمة دالة وصلت إلى موضع الاستدعاء عبر متغير أو معامل من النوع `أي`.

## سبب الخطأ

الاستدعاء غير المباشر في الكود الأصلي يستمد توقيعه (نوع الإرجاع وأنواع الوسائط) بالكامل من الأنواع الثابتة وقت الترجمة. عندما يكون النوع الثابت للقيمة المستدعاة `أي` (أو غير معروف)، فلا يمكن بناء توقيع صحيح — وكان الاستدعاء الناتج سيمرر ويفسّر أنماط بتات خاطئة بصمت (انهيار أو نتائج تالفة وقت التشغيل بدل خطأ واضح).

المفسّر (`tarqeem run`) يعتمد على القيم الفعلية وقت التشغيل، فلا يتأثر بهذا القيد.

## مثال الخطأ

```tarqeem
بسم_الله
دالة طبق(ف: أي، س: عدد) {
    اطبع(ف(س))    // 'ف' من النوع 'أي' — لا توقيع معروف
}
طبق((س: عدد) => س * س، 3)
الحمد_لله
```

```
tarqeem compile برنامج.ترقيم
خطأ[ت٠٣٠٢]: الترجمة الأصلية لا تدعم استدعاء قيمة دالة بدون توقيع معروف
```

**ملاحظة**: نفس البرنامج يعمل مع `tarqeem run` (المفسّر) — القيد خاص بالترجمة الأصلية فقط.

## الحل

### الحل ١: صرّح بنوع الدالة في المعامل

```tarqeem
بسم_الله
دالة طبق(ف: (عدد) -> عدد، س: عدد) {
    اطبع(ف(س))    // ✅ صحيح: التوقيع معروف
}
طبق((س: عدد) => س * س، 3)
الحمد_لله
```

### الحل ٢: شغّل البرنامج بالمفسّر

```bash
tarqeem run برنامج.ترقيم
```
