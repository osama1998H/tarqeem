# د٠٠٠٣: صنف غير معرف

## الوصف

هذا الخطأ يحدث عند محاولة استخدام صنف لم يتم تعريفه أو استيراده في النطاق الحالي.

في ترقيم، يجب تعريف الصنف باستخدام `صنف` أو استيراده من وحدة خارجية قبل استخدامه لإنشاء كائنات أو تحديد أنواع.

## سبب الخطأ

المترجم لا يستطيع إيجاد تعريف للصنف المستخدم. قد يكون السبب:

1. الصنف لم يُعرَّف أصلاً
2. خطأ إملائي في اسم الصنف
3. الصنف موجود في وحدة لم يتم استيرادها
4. محاولة الوراثة من صنف غير موجود

## مثال الخطأ

```tarqeem
دالة رئيسية() {
    متغير ش = جديد شخص("أحمد")    // ❌ خطأ: الصنف 'شخص' غير معرف
}
```

**الرسالة**:
```
خطأ[د٠٠٠٣]: الصنف 'شخص' غير معرّف
  --> ملف.ترقيم:٢:١٩
   |
 ٢ |     متغير ش = جديد شخص("أحمد")
   |                   ^^^^
   |
مساعدة: هل تقصد تعريف الصنف أو استيراده؟
```

## الحل

عرّف الصنف قبل استخدامه:

```tarqeem
// ✅ تعريف الصنف أولاً
صنف شخص {
    خاص اسم: نص

    منشئ(اسم: نص) {
        هذا.اسم = اسم
    }

    عام دالة تحية() {
        اطبع("مرحباً، أنا " + هذا.اسم)
    }
}

دالة رئيسية() {
    متغير ش = جديد شخص("أحمد")    // ✅ الآن يعمل
    ش.تحية()
}
```

## حالات شائعة

### الحالة ١: خطأ إملائي في اسم الصنف

```tarqeem
صنف المستخدم {
    // ...
}

// ❌ خطأ إملائي
متغير م = جديد مستخدم()    // خطأ: 'مستخدم' (بدون 'ال')

// ✅ الصحيح
متغير م = جديد المستخدم()
```

### الحالة ٢: وراثة من صنف غير معرف

```tarqeem
// ❌ الصنف الأب غير موجود
صنف موظف يرث شخص {    // خطأ: 'شخص' غير معرف
    // ...
}

// ✅ الصحيح - تعريف الصنف الأب أولاً
صنف شخص {
    خاص اسم: نص
    منشئ(اسم: نص) {
        هذا.اسم = اسم
    }
}

صنف موظف يرث شخص {
    خاص راتب: عدد
    منشئ(اسم: نص، راتب: عدد) {
        الأصل(اسم)
        هذا.راتب = راتب
    }
}
```

### الحالة ٣: استخدام صنف كنوع قبل تعريفه

```tarqeem
// ❌ استخدام كنوع قبل التعريف
دالة معالجة(عنصر: منتج) {    // خطأ: 'منتج' غير معرف
    // ...
}

// ✅ الصحيح - تعريف الصنف أولاً
صنف منتج {
    عام اسم: نص
    عام سعر: عدد_عشري
}

دالة معالجة(عنصر: منتج) {
    اطبع(عنصر.اسم)
}
```

### الحالة ٤: صنف من وحدة غير مستوردة

```tarqeem
// ❌ نسيان الاستيراد
دالة رئيسية() {
    متغير ق = جديد قائمة<عدد>()    // خطأ إذا لم يُستورد
}

// ✅ الصحيح - استيراد من المكتبة القياسية
استورد { قائمة } من "مجموعات"

دالة رئيسية() {
    متغير ق = جديد قائمة<عدد>()
}
```

### الحالة ٥: التزام بميثاق غير معرف

```tarqeem
// ❌ الميثاق غير موجود
صنف طابعة يلتزم قابل_للطباعة {    // خطأ: 'قابل_للطباعة' غير معرف
    // ...
}

// ✅ الصحيح - تعريف الميثاق أولاً
ميثاق قابل_للطباعة {
    دالة اطبع()
}

صنف طابعة يلتزم قابل_للطباعة {
    عام دالة اطبع() {
        // التنفيذ
    }
}
```

## ملاحظات إضافية

- الأصناف المدمجة مثل `مصفوفة` و `قاموس` متاحة دائماً
- تحقق من ترتيب تعريف الأصناف عند وجود علاقات وراثة
- الأصناف المعممة تحتاج تحديد معاملات النوع: `صنف<نوع>`

```tarqeem
// الأصناف المدمجة
متغير أرقام: مصفوفة<عدد> = [1، 2، 3]     // ✅ مدمج
متغير خريطة: قاموس<نص، عدد> = {}        // ✅ مدمج

// أصناف المكتبة القياسية
استورد { مجموعة } من "مجموعات"
متغير م = جديد مجموعة<نص>()             // ✅ بعد الاستيراد
```
