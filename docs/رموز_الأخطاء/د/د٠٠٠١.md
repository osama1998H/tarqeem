# د٠٠٠١: متغير غير معرف

## الوصف

هذا الخطأ يحدث عند محاولة استخدام متغير لم يتم تعريفه مسبقاً في النطاق الحالي أو النطاقات الأعلى.

في ترقيم، يجب تعريف كل متغير باستخدام `متغير` أو `ثابت` قبل استخدامه.

## سبب الخطأ

المترجم لا يستطيع إيجاد تعريف للمتغير المستخدم. قد يكون السبب:

1. المتغير لم يُعرَّف أصلاً
2. خطأ إملائي في اسم المتغير
3. المتغير معرّف في نطاق مختلف (داخل دالة أخرى مثلاً)
4. استخدام المتغير قبل تعريفه

## مثال الخطأ

```tarqeem
دالة رئيسية() {
    اطبع(س)    // ❌ خطأ: المتغير 'س' غير معرف
}
```

**الرسالة**:
```
خطأ[د٠٠٠١]: المتغير 'س' غير معرّف
  --> ملف.ترقيم:٢:١١
   |
 ٢ |     اطبع(س)
   |           ^
   |
مساعدة: هل تقصد تعريف المتغير أولاً؟
```

## الحل

عرّف المتغير قبل استخدامه:

```tarqeem
دالة رئيسية() {
    متغير س = 10    // ✅ تعريف المتغير أولاً
    اطبع(س)         // ✅ الآن يمكن استخدامه
}
```

## حالات شائعة

### الحالة ١: خطأ إملائي

```tarqeem
// ❌ خطأ إملائي
متغير العداد = 0
اطبع(العدد)    // خطأ: 'العدد' غير معرف (المقصود 'العداد')

// ✅ الصحيح
متغير العداد = 0
اطبع(العداد)
```

### الحالة ٢: نطاق مختلف

```tarqeem
// ❌ المتغير معرف داخل الكتلة فقط
إذا (صحيح) {
    متغير محلي = 5
}
اطبع(محلي)    // خطأ: 'محلي' غير معرف خارج الكتلة

// ✅ الصحيح - تعريف في النطاق الخارجي
متغير محلي = 0
إذا (صحيح) {
    محلي = 5
}
اطبع(محلي)
```

### الحالة ٣: استخدام قبل التعريف

```tarqeem
// ❌ الاستخدام قبل التعريف
دالة حساب() {
    متغير نتيجة = قيمة * 2    // خطأ: 'قيمة' غير معرف
    متغير قيمة = 10
}

// ✅ الصحيح - التعريف أولاً
دالة حساب() {
    متغير قيمة = 10
    متغير نتيجة = قيمة * 2
}
```

### الحالة ٤: استخدام معامل دالة غير موجود

```tarqeem
// ❌ خطأ في اسم المعامل
دالة جمع(أ: عدد، ب: عدد) -> عدد {
    أرجع س + ص    // خطأ: 'س' و 'ص' غير معرفين
}

// ✅ الصحيح
دالة جمع(أ: عدد، ب: عدد) -> عدد {
    أرجع أ + ب
}
```

## ملاحظات إضافية

- ترقيم حساسة لحالة الأحرف العربية والتشكيل
- تأكد من تطابق الأسماء بالضبط
- المتغيرات المعرفة في حلقة `لكل` متاحة فقط داخل الحلقة

```tarqeem
// المتغير 'ع' متاح فقط داخل الحلقة
لكل (متغير ع = 0؛ ع < 10؛ ع++) {
    اطبع(ع)    // ✅ صحيح
}
اطبع(ع)    // ❌ خطأ: 'ع' غير معرف خارج الحلقة
```
