# د٠١٠٢: تعيين قيمة لثابت

## الوصف

هذا الخطأ يحدث عند محاولة تغيير قيمة متغير معرّف بـ `ثابت`.

في ترقيم، المتغيرات المعرفة باستخدام `ثابت` لا يمكن تغيير قيمتها بعد التعريف الأولي. هذا يضمن ثبات القيم المهمة في البرنامج.

## سبب الخطأ

المترجم اكتشف محاولة تعيين قيمة جديدة لمتغير ثابت. قد يكون السبب:

1. محاولة تعديل ثابت مباشرة
2. استخدام `ثابت` عن طريق الخطأ بدلاً من `متغير`
3. عدم إدراك أن المتغير معرّف كثابت

## مثال الخطأ

```tarqeem
دالة رئيسية() {
    ثابت PI = 3.14159
    PI = 3.14    // ❌ خطأ: لا يمكن تعيين قيمة لثابت
}
```

**الرسالة**:
```
خطأ[د٠١٠٢]: لا يمكن تعيين قيمة لثابت 'PI'
  --> ملف.ترقيم:٣:٥
   |
 ٢ |     ثابت PI = 3.14159
   |           -- معرّف كثابت هنا
 ٣ |     PI = 3.14
   |     ^^^^^^^^^ محاولة تعيين غير مسموحة
   |
مساعدة: الثوابت لا يمكن تغييرها. استخدم 'متغير' إذا كنت تريد تغيير القيمة لاحقاً
```

## الحل

إذا كنت تحتاج لتغيير القيمة، استخدم `متغير` بدلاً من `ثابت`:

```tarqeem
دالة رئيسية() {
    متغير قيمة = 3.14159    // ✅ متغير يمكن تعديله
    قيمة = 3.14             // ✅ صحيح
    اطبع(قيمة)
}
```

أو استخدم متغيراً جديداً:

```tarqeem
دالة رئيسية() {
    ثابت PI_FULL = 3.14159
    ثابت PI_SHORT = 3.14    // ✅ ثابت جديد بقيمة مختلفة
}
```

## حالات شائعة

### الحالة ١: عمليات الزيادة والنقصان

```tarqeem
// ❌ خطأ: محاولة زيادة ثابت
ثابت عداد = 0
عداد++    // خطأ: لا يمكن تعيين قيمة لثابت
عداد += 1  // خطأ أيضاً

// ✅ الصحيح
متغير عداد = 0
عداد++    // مسموح
```

### الحالة ٢: التعديل في حلقة

```tarqeem
// ❌ خطأ
ثابت مجموع = 0
لكل رقم في [1، 2، 3، 4، 5] {
    مجموع = مجموع + رقم    // خطأ: لا يمكن تعيين قيمة لثابت
}

// ✅ الصحيح
متغير مجموع = 0
لكل رقم في [1، 2، 3، 4، 5] {
    مجموع = مجموع + رقم    // مسموح
}
```

### الحالة ٣: خصائص الصنف الثابتة

```tarqeem
صنف تهيئة {
    ثابت الإصدار: نص = "1.0.0"
}

// ❌ خطأ
تهيئة.الإصدار = "2.0.0"    // لا يمكن تعديل ثابت

// ✅ الصحيح - إذا كان يجب أن يتغير، عرّفه كمتغير
صنف تهيئة {
    مشترك متغير الإصدار: نص = "1.0.0"
}
```

### الحالة ٤: المصفوفات والكائنات الثابتة

```tarqeem
// الثابت يشير إلى عدم تغيير المرجع، لا المحتوى
ثابت أرقام = [1، 2، 3]

// ❌ خطأ: تغيير المرجع
أرقام = [4، 5، 6]    // لا يمكن تعيين قيمة جديدة

// ⚠️ ملاحظة: تعديل المحتوى قد يكون مسموحاً
أرقام.ألحق(4)    // هذا يعدل المصفوفة، لا يعيد تعيينها
```

### الحالة ٥: معاملات الدالة

```tarqeem
// المعاملات ثابتة افتراضياً
دالة ضعّف(س: عدد) -> عدد {
    س = س * 2    // ❌ خطأ: المعامل ثابت
    أرجع س
}

// ✅ الصحيح
دالة ضعّف(س: عدد) -> عدد {
    متغير نتيجة = س * 2
    أرجع نتيجة
}
```

## ملاحظات إضافية

- استخدم `ثابت` للقيم التي يجب ألا تتغير (مثل الثوابت الرياضية)
- استخدم `متغير` للقيم التي تحتاج للتعديل
- الثوابت أفضل للأداء والأمان عند عدم الحاجة للتعديل

```tarqeem
// أمثلة على الاستخدام الصحيح للثوابت
ثابت PI = 3.14159
ثابت MAX_SIZE = 100
ثابت اسم_التطبيق = "تطبيقي"

// أمثلة على الاستخدام الصحيح للمتغيرات
متغير عداد = 0
متغير مجموع = 0.0
متغير نتائج: مصفوفة<عدد> = []
```
