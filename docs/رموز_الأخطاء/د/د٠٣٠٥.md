# د٠٣٠٥: استخدام 'الأصل' خارج صنف

## الوصف

هذا الخطأ يحدث عند استخدام كلمة `الأصل` (super) خارج سياق صنف يرث من صنف آخر.

كلمة `الأصل` تُستخدم للوصول إلى دوال وخصائص الصنف الأب (الصنف الذي يرث منه الصنف الحالي).

## سبب الخطأ

`الأصل` تتطلب:
1. أن تكون داخل صنف
2. أن يكون هذا الصنف يرث من صنف آخر

خارج هذا السياق، لا يوجد "صنف أصل" للإشارة إليه.

## مثال الخطأ

```tarqeem
// دالة عادية خارج أي صنف
دالة اختبار() {
    الأصل.دالة()    // ❌ خطأ: لا يوجد صنف ولا وراثة
}
```

**الرسالة**:
```
خطأ[د٠٣٠٥]: 'الأصل' يمكن استخدامها فقط داخل صنف
  --> ملف.ترقيم:٣:٥
   |
 ٣ |     الأصل.دالة()
   |     ^^^^^
```

## الحل

استخدم `الأصل` فقط داخل صنف يرث من صنف آخر:

```tarqeem
صنف كائن_حي {
    عام دالة تنفس() {
        اطبع("يتنفس")
    }
}

صنف حيوان يرث كائن_حي {
    عام دالة تنفس() {
        الأصل.تنفس()    // ✅ صحيح: استدعاء دالة الصنف الأب
        اطبع("بطريقة حيوانية")
    }
}
```

## حالات شائعة

### الحالة ١: صنف بدون وراثة

```tarqeem
// ❌ خطأ - الصنف لا يرث من أي صنف
صنف مستقل {
    دالة اختبار() {
        الأصل.شيء()    // لا يوجد صنف أصل!
    }
}

// ✅ الصحيح - يجب أن يرث أولاً
صنف فرعي يرث أساسي {
    دالة اختبار() {
        الأصل.شيء()    // الآن صحيح
    }
}
```

### الحالة ٢: استدعاء منشئ الأصل

```tarqeem
صنف شكل {
    خاص لون: نص

    منشئ(لون: نص) {
        هذا.لون = لون
    }
}

صنف مربع يرث شكل {
    خاص طول: عدد

    منشئ(لون: نص، طول: عدد) {
        الأصل(لون)    // ✅ استدعاء منشئ الصنف الأب
        هذا.طول = طول
    }
}
```

### الحالة ٣: الأصل في دالة مشتركة

```tarqeem
صنف أساسي {
    مشترك دالة ثابتة() {
        اطبع("أساسي")
    }
}

صنف فرعي يرث أساسي {
    // ❌ الأصل لا تعمل في الدوال المشتركة بشكل مباشر
    مشترك دالة ثابتة() {
        الأصل.ثابتة()    // قد لا يعمل
    }

    // ✅ استخدم اسم الصنف مباشرة
    مشترك دالة ثابتة() {
        أساسي.ثابتة()
    }
}
```

## ملاحظات إضافية

- `الأصل` تعمل فقط عندما:
  - تكون داخل صنف
  - الصنف يستخدم `يرث` للوراثة من صنف آخر
- استخدامات `الأصل`:
  - `الأصل(معاملات)` - استدعاء منشئ الصنف الأب
  - `الأصل.دالة()` - استدعاء دالة من الصنف الأب
  - `الأصل.خاصية` - الوصول لخاصية من الصنف الأب

```tarqeem
صنف أب {
    محمي اسم: نص = "أب"

    عام دالة عرّف() {
        اطبع("أنا " + هذا.اسم)
    }
}

صنف ابن يرث أب {
    منشئ() {
        هذا.اسم = "ابن"
    }

    عام دالة عرّف() {
        اطبع("قبل الأصل")
        الأصل.عرّف()    // يستدعي دالة الأب
        اطبع("بعد الأصل")
    }
}
```
