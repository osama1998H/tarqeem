# د٠٣٠٤: استخدام 'هذا' خارج صنف

## الوصف

هذا الخطأ يحدث عند استخدام كلمة `هذا` (this) خارج سياق صنف.

كلمة `هذا` تُشير إلى الكائن الحالي (النسخة الحالية من الصنف)، ولا يمكن استخدامها إلا داخل دوال الصنف أو المنشئ.

## سبب الخطأ

`هذا` تحتاج كائناً للإشارة إليه. خارج الصنف، لا يوجد "كائن حالي" يمكن الإشارة إليه.

## مثال الخطأ

```tarqeem
// دالة عادية خارج أي صنف
دالة اختبار() {
    اطبع(هذا.اسم)    // ❌ خطأ: لا يوجد صنف
}
```

**الرسالة**:
```
خطأ[د٠٣٠٤]: 'هذا' يمكن استخدامها فقط داخل صنف
  --> ملف.ترقيم:٣:١١
   |
 ٣ |     اطبع(هذا.اسم)
   |          ^^^^
```

## الحل

استخدم `هذا` فقط داخل دوال الصنف:

```tarqeem
صنف شخص {
    خاص اسم: نص

    منشئ(اسم: نص) {
        هذا.اسم = اسم    // ✅ صحيح: داخل منشئ الصنف
    }

    عام دالة تحية() {
        اطبع("مرحباً، أنا " + هذا.اسم)    // ✅ صحيح: داخل دالة الصنف
    }
}
```

## حالات شائعة

### الحالة ١: نسيان أن الدالة خارج الصنف

```tarqeem
صنف حساب {
    خاص رصيد: عدد_عشري
}

// ❌ خطأ - هذه الدالة خارج الصنف!
دالة اعرض_رصيد() {
    اطبع(هذا.رصيد)
}

// ✅ الصحيح - الدالة داخل الصنف
صنف حساب {
    خاص رصيد: عدد_عشري

    عام دالة اعرض_رصيد() {
        اطبع(هذا.رصيد)
    }
}
```

### الحالة ٢: استخدام هذا في دالة مشتركة

```tarqeem
صنف عداد {
    مشترك قيمة: عدد = 0

    // ❌ خطأ - الدوال المشتركة لا تحتوي على 'هذا'
    مشترك دالة زِد() {
        هذا.قيمة++    // لا يوجد كائن في الدالة المشتركة
    }

    // ✅ الصحيح
    مشترك دالة زِد() {
        عداد.قيمة++    // استخدم اسم الصنف للوصول للمتغير المشترك
    }
}
```

### الحالة ٣: هذا في lambda خارج صنف

```tarqeem
// ❌ خطأ
ثابت دالة_خارجية = () => {
    اطبع(هذا.شيء)
}

// ✅ الصحيح - تمرير الكائن كمعامل
صنف مثال {
    عام دالة انشئ_معالج() {
        ثابت ذات = هذا
        أرجع () => {
            اطبع(ذات.شيء)    // استخدم متغير محلي يحمل مرجع هذا
        }
    }
}
```

## ملاحظات إضافية

- `هذا` تعمل فقط في:
  - دوال الصنف (methods)
  - المنشئ (constructor)
  - الخصائص (properties)
- `هذا` لا تعمل في:
  - الدوال المشتركة (`مشترك دالة`)
  - الدوال العادية خارج الصنف
  - المستوى الأعلى للملف

```tarqeem
صنف مثال {
    خاص _قيمة: عدد

    // ✅ هذا تعمل هنا
    منشئ() {
        هذا._قيمة = 0
    }

    // ✅ هذا تعمل هنا
    عام دالة احصل() -> عدد {
        أرجع هذا._قيمة
    }

    // ❌ هذا لا تعمل في الدوال المشتركة
    مشترك دالة ثابتة() {
        // لا يمكن استخدام هذا هنا
    }
}
```
