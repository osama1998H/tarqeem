# د٠٣٠٦: التقاط متغير خارجي داخل دالة سهمية

## الوصف

هذا الخطأ يحدث عند إشارة دالة سهمية (lambda) إلى متغير أو معامل من نطاق دالة أو كتلة محيطة بها (خارج جسمها الخاص).

الدوال السهمية في ترقيم لا تلتقط (capture) متغيرات النطاق المحيط بعد — يمكنها فقط الوصول إلى:

- معاملاتها الخاصة
- المتغيرات المحلية المُعرَّفة داخل جسمها
- المتغيرات والثوابت العامة على مستوى الوحدة
- الدوال والأصناف المُعرَّفة بالاسم

## سبب الخطأ

الالتقاط (closures) ميزة لم تُنفَّذ بعد في مولّد الشيفرة الوسيطة (IR). دون هذا الفحص، الإشارة إلى متغير خارجي داخل دالة سهمية كانت ستؤدي إلى خطأ غامض أو سلوك غير معرَّف في مراحل لاحقة من الترجمة، بدل تشخيص واضح في مرحلة التحليل الدلالي.

## مثال الخطأ

```tarqeem
دالة رئيسية() {
    متغير ع = 10
    ثابت أضف = (س: عدد) => س + ع    // ❌ خطأ: التقاط المتغير الخارجي 'ع'
    اطبع(أضف(5))
}
```

**الرسالة**:
```
خطأ[د٠٣٠٦]: لا يمكن التقاط المتغير الخارجي 'ع' داخل دالة سهمية (غير مدعوم بعد)
  --> ملف.ترقيم:٣:٢٦
   |
 ٣ |     ثابت أضف = (س: عدد) => س + ع
   |                          ^
```

## الحل

مرّر المتغير الخارجي كمعامل إضافي للدالة السهمية بدلاً من الاعتماد على الالتقاط:

```tarqeem
دالة رئيسية() {
    متغير ع = 10
    ثابت أضف = (س: عدد، ع: عدد) => س + ع    // ✅ صحيح: 'ع' معامل صريح
    اطبع(أضف(5، ع))
}
```

## حالات شائعة

### الحالة ١: الإشارة إلى متغير عام (مسموح)

المتغيرات والثوابت المُعرَّفة على مستوى الوحدة ليست التقاطاً - يمكن للدالة السهمية الوصول إليها مباشرة:

```tarqeem
ثابت ثابت_عام = 10

دالة رئيسية() {
    // ✅ صحيح: ثابت_عام متغير عام، وليس محلياً لدالة محيطة
    ثابت ف = (س: عدد) => س + ثابت_عام
    اطبع(ف(5))
}
```

### الحالة ٢: استدعاء دالة مُعرَّفة (مسموح)

استدعاء دالة أو صنف مُعرَّف بالاسم ليس التقاطاً:

```tarqeem
دالة ضاعف(س: عدد) -> عدد {
    أرجع س * 2
}

دالة رئيسية() {
    // ✅ صحيح: ضاعف دالة معرَّفة، وليست متغيراً محلياً محيطاً
    ثابت ف = (س: عدد) => ضاعف(س)
    اطبع(ف(5))
}
```

### الحالة ٣: متغير محلي داخل جسم الدالة السهمية نفسها (مسموح)

```tarqeem
// ✅ صحيح: 'ن' معرَّف داخل جسم الدالة السهمية نفسها
ثابت ف = (س: عدد) => {
    متغير ن = س * 2
    أرجع ن
}
```

### الحالة ٤: استخدام 'هذا' أو 'الأصل' داخل دالة سهمية (مرفوض)

الدالة السهمية تُرفَع إلى دالة مستقلة بلا كائن مستقبِل، لذا `هذا` بداخلها التقاط مقنَّع ويُرفَض بنفس الرمز:

```tarqeem
صنف عداد {
    عام قيمة: عدد

    عام دالة اصنع() {
        // ❌ خطأ د٠٣٠٦: 'هذا' داخل دالة سهمية
        ثابت ف = (س: عدد) => هذا.قيمة + س
    }
}
```

الحل: خزّن القيمة المطلوبة في معامل أو مرّرها صراحةً:

```tarqeem
عام دالة اصنع() {
    // ✅ صحيح: القيمة مُمرَّرة كمعامل
    ثابت ف = (س: عدد، ق: عدد) => ق + س
    اطبع(ف(5، هذا.قيمة))
}
```
