# د٠١٠١: إعادة تعريف متغير

## الوصف

هذا الخطأ يحدث عند محاولة تعريف متغير باسم موجود مسبقاً في نفس النطاق.

في ترقيم، كل متغير يجب أن يكون له اسم فريد داخل نطاقه. لا يُسمح بإعادة تعريف متغير بنفس الاسم في نفس النطاق.

## سبب الخطأ

المترجم وجد تعريفاً سابقاً لمتغير بنفس الاسم في النطاق الحالي. قد يكون السبب:

1. تعريف متغير مرتين بنفس الاسم
2. محاولة تغيير نوع متغير بإعادة تعريفه
3. نسيان أن المتغير معرّف مسبقاً
4. نسخ/لصق كود بدون تعديل أسماء المتغيرات

## مثال الخطأ

```tarqeem
دالة رئيسية() {
    متغير س = 5
    متغير س = 10    // ❌ خطأ: المتغير 'س' معرّف مسبقاً
}
```

**الرسالة**:
```
خطأ[د٠١٠١]: المتغير 'س' معرّف مسبقاً
  --> ملف.ترقيم:٣:٥
   |
 ٢ |     متغير س = 5
   |            - التعريف الأول هنا
 ٣ |     متغير س = 10
   |            ^ إعادة تعريف غير مسموحة
   |
مساعدة: استخدم اسماً مختلفاً أو عيّن قيمة جديدة للمتغير الموجود
```

## الحل

إذا أردت تغيير قيمة المتغير، عيّن القيمة مباشرة:

```tarqeem
دالة رئيسية() {
    متغير س = 5
    س = 10    // ✅ صحيح - تعيين قيمة جديدة
    اطبع(س)   // يطبع: 10
}
```

أو استخدم اسماً مختلفاً:

```tarqeem
دالة رئيسية() {
    متغير س_قديم = 5
    متغير س_جديد = 10    // ✅ صحيح - اسم مختلف
}
```

## حالات شائعة

### الحالة ١: تعريف في حلقة

```tarqeem
// ❌ خطأ: تعريف متكرر داخل الحلقة
لكل (متغير ع = 0؛ ع < 5؛ ع++) {
    متغير نتيجة = ع * 2
    متغير نتيجة = ع + 1    // خطأ: 'نتيجة' معرّف مسبقاً
}

// ✅ الصحيح
لكل (متغير ع = 0؛ ع < 5؛ ع++) {
    متغير نتيجة = ع * 2
    نتيجة = ع + 1    // تعيين قيمة جديدة
}
```

### الحالة ٢: تعريف في كتل شرطية متتالية

```tarqeem
// ❌ خطأ
دالة معالجة(قيمة: عدد) {
    متغير نتيجة = 0
    إذا (قيمة > 0) {
        متغير نتيجة = قيمة * 2    // تظليل - غير مسموح في نفس الدالة
    }
}

// ✅ الصحيح
دالة معالجة(قيمة: عدد) {
    متغير نتيجة = 0
    إذا (قيمة > 0) {
        نتيجة = قيمة * 2    // تعيين
    }
}
```

### الحالة ٣: معاملات الدالة

```tarqeem
// ❌ خطأ: إعادة تعريف معامل
دالة حساب(س: عدد) {
    متغير س = س * 2    // خطأ: 'س' معرّف كمعامل
}

// ✅ الصحيح
دالة حساب(س: عدد) {
    متغير نتيجة = س * 2
    أرجع نتيجة
}
```

### الحالة ٤: التقاط الاستثناءات

```tarqeem
// ❌ خطأ
دالة معالجة() {
    متغير خ = "متغير موجود"
    حاول {
        // ...
    } التقط (خ) {    // خطأ: 'خ' معرّف مسبقاً
        // ...
    }
}

// ✅ الصحيح
دالة معالجة() {
    متغير رسالة = "متغير موجود"
    حاول {
        // ...
    } التقط (خ) {    // اسم مختلف
        اطبع(خ.رسالة)
    }
}
```

## ملاحظات إضافية

- النطاقات المتداخلة (داخل كتل `{}`) قد تسمح بالتظليل في بعض الحالات
- المتغيرات المعرفة في حلقة `لكل` محدودة النطاق داخل الحلقة
- الثوابت (`ثابت`) تخضع لنفس القواعد

```tarqeem
// النطاقات المختلفة
متغير س = 5

دالة أخرى() {
    متغير س = 10    // ✅ مسموح - نطاق مختلف (داخل دالة)
}

{
    متغير ص = 20    // نطاق داخلي
}
متغير ص = 30    // ✅ مسموح - النطاق السابق انتهى
```
