# د٠٣٠٣: استخدام 'أرجع' خارج دالة

## الوصف

هذا الخطأ يحدث عند استخدام كلمة `أرجع` (return) خارج سياق دالة.

كلمة `أرجع` مخصصة لإنهاء تنفيذ الدالة وإرجاع قيمة اختيارية للمستدعي.

## سبب الخطأ

`أرجع` تعمل فقط داخل الدوال لأنها تنهي تنفيذ الدالة وتعيد التحكم للكود الذي استدعاها. خارج الدالة (في المستوى الأعلى للملف)، لا يوجد سياق للإرجاع منه.

## مثال الخطأ

```tarqeem
// في المستوى الأعلى للملف
متغير س = 5
أرجع س    // ❌ خطأ: ليس داخل دالة
```

**الرسالة**:
```
خطأ[د٠٣٠٣]: 'أرجع' يمكن استخدامها فقط داخل دالة
  --> ملف.ترقيم:٣:١
   |
 ٣ | أرجع س
   | ^^^^^^
```

## الحل

ضع `أرجع` داخل دالة:

```tarqeem
دالة احسب() -> عدد {
    متغير س = 5
    أرجع س    // ✅ صحيح: داخل دالة
}
```

```tarqeem
// للدوال التي لا تُرجع قيمة
دالة طباعة_رسالة(رسالة: نص) {
    إذا (رسالة == "") {
        أرجع    // ✅ صحيح: خروج مبكر بدون قيمة
    }
    اطبع(رسالة)
}
```

## حالات شائعة

### الحالة ١: أرجع في جسم صنف

```tarqeem
// ❌ خطأ
صنف مثال {
    أرجع 5    // لا يمكن استخدام أرجع هنا
}

// ✅ الصحيح - داخل دالة الصنف
صنف مثال {
    دالة احصل_قيمة() -> عدد {
        أرجع 5
    }
}
```

### الحالة ٢: أرجع داخل lambda

```tarqeem
// ✅ صحيح - lambda تحتوي دالة ضمنياً
ثابت مربع = (س: عدد) => س * س    // أرجع ضمني

// ✅ صحيح - أرجع صريح في lambda
ثابت حساب = (س: عدد) => {
    متغير نتيجة = س * 2
    أرجع نتيجة
}
```

## ملاحظات إضافية

- الدوال التي لا تُرجع قيمة لا تحتاج `أرجع` في نهايتها
- `أرجع` بدون قيمة تُستخدم للخروج المبكر من الدالة
- تأكد أن نوع القيمة المُرجعة يطابق نوع الإرجاع المُعلن في الدالة

```tarqeem
// خروج مبكر
دالة معالجة(قيمة: عدد?) {
    إذا (قيمة == لا_شيء) {
        اطبع("لا توجد قيمة")
        أرجع    // خروج مبكر
    }
    // معالجة القيمة
    اطبع(قيمة)
}
```
