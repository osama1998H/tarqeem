# د٠٣٠٢: استخدام 'استمر' خارج حلقة

## الوصف

هذا الخطأ يحدث عند استخدام كلمة `استمر` (continue) خارج سياق حلقة تكرارية (`طالما` أو `لكل`).

كلمة `استمر` مخصصة للانتقال مباشرة إلى التكرار التالي في الحلقة، متخطية بقية الكود في التكرار الحالي.

## سبب الخطأ

المترجم يتوقع وجود حلقة تكرارية لأن `استمر` تعمل فقط ضمن سياق الحلقات. خارج الحلقة، لا يوجد "تكرار تالي" للانتقال إليه.

## مثال الخطأ

```tarqeem
دالة معالجة() {
    استمر    // ❌ خطأ: لا توجد حلقة للاستمرار فيها
}
```

**الرسالة**:
```
خطأ[د٠٣٠٢]: 'استمر' يمكن استخدامها فقط داخل حلقة
  --> ملف.ترقيم:٢:٥
   |
 ٢ |     استمر
   |     ^^^^^
```

## الحل

استخدم `استمر` فقط داخل حلقات `طالما` أو `لكل`:

```tarqeem
// تخطي الأعداد السالبة
لكل (متغير ع = -5؛ ع <= 5؛ ع++) {
    إذا (ع < 0) {
        استمر    // ✅ صحيح: تخطي هذا التكرار
    }
    اطبع(ع)    // تطبع فقط 0، 1، 2، 3، 4، 5
}
```

```tarqeem
// تخطي العناصر الفارغة
لكل عنصر في قائمة {
    إذا (عنصر == "") {
        استمر    // ✅ صحيح: تخطي العناصر الفارغة
    }
    عالج(عنصر)
}
```

## حالات شائعة

### الحالة ١: استمر في شرط خارج حلقة

```tarqeem
// ❌ خطأ
دالة تصفية(قيمة: عدد) {
    إذا (قيمة < 0) {
        استمر    // لا يوجد حلقة!
    }
    اطبع(قيمة)
}

// ✅ الصحيح - استخدم شرط عكسي
دالة تصفية(قيمة: عدد) {
    إذا (قيمة >= 0) {
        اطبع(قيمة)
    }
}
```

### الحالة ٢: الفرق بين استمر وأوقف

```tarqeem
لكل (متغير ع = 0؛ ع < 10؛ ع++) {
    إذا (ع == 5) {
        استمر    // يتخطى 5 ويستمر 6، 7، 8، 9
        // أوقف    // كان سيوقف عند 5 تماماً
    }
    اطبع(ع)
}
// الناتج: 0، 1، 2، 3، 4، 6، 7، 8، 9 (بدون 5)
```

## ملاحظات إضافية

- `استمر` تنتقل مباشرة إلى **بداية التكرار التالي**
- في حلقة `لكل` التقليدية، تُنفذ عبارة التحديث قبل التكرار التالي
- في الحلقات المتداخلة، `استمر` تؤثر على **أقرب حلقة** فقط

```tarqeem
لكل (متغير ع = 0؛ ع < 3؛ ع++) {
    لكل (متغير ص = 0؛ ص < 3؛ ص++) {
        إذا (ص == 1) {
            استمر    // تتخطى ص=1 في الحلقة الداخلية فقط
        }
        اطبع("(" + ع + "," + ص + ")")
    }
}
// الناتج: (0,0) (0,2) (1,0) (1,2) (2,0) (2,2)
```
