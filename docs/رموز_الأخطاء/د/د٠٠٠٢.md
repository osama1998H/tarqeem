# د٠٠٠٢: دالة غير معرفة

## الوصف

هذا الخطأ يحدث عند محاولة استدعاء دالة لم يتم تعريفها أو استيرادها في النطاق الحالي.

في ترقيم، يجب أن تكون الدالة معرفة باستخدام `دالة` أو مستوردة من وحدة خارجية قبل استدعائها.

## سبب الخطأ

المترجم لا يستطيع إيجاد تعريف للدالة المستدعاة. قد يكون السبب:

1. الدالة لم تُعرَّف أصلاً
2. خطأ إملائي في اسم الدالة
3. الدالة موجودة في وحدة لم يتم استيرادها
4. استدعاء الدالة قبل تعريفها (في بعض الحالات)

## مثال الخطأ

```tarqeem
دالة رئيسية() {
    متغير نتيجة = حساب(5)    // ❌ خطأ: الدالة 'حساب' غير معرفة
}
```

**الرسالة**:
```
خطأ[د٠٠٠٢]: الدالة 'حساب' غير معرّفة
  --> ملف.ترقيم:٢:٢٠
   |
 ٢ |     متغير نتيجة = حساب(5)
   |                    ^^^^^
   |
مساعدة: هل تقصد تعريف الدالة أو استيرادها؟
```

## الحل

عرّف الدالة قبل استدعائها:

```tarqeem
// ✅ تعريف الدالة أولاً
دالة حساب(س: عدد) -> عدد {
    أرجع س * 2
}

دالة رئيسية() {
    متغير نتيجة = حساب(5)    // ✅ الآن يعمل
    اطبع(نتيجة)              // يطبع: 10
}
```

## حالات شائعة

### الحالة ١: خطأ إملائي في اسم الدالة

```tarqeem
// ❌ خطأ إملائي
دالة احسب_المجموع(أ: عدد، ب: عدد) -> عدد {
    أرجع أ + ب
}

متغير س = احسب_مجموع(3، 4)    // خطأ: 'احسب_مجموع' (بدون 'ال')

// ✅ الصحيح
متغير س = احسب_المجموع(3، 4)
```

### الحالة ٢: دالة من وحدة غير مستوردة

```tarqeem
// ❌ نسيان الاستيراد
دالة رئيسية() {
    متغير س = جذر(16)    // خطأ: 'جذر' غير معرفة
}

// ✅ الصحيح - استيراد الوحدة
استورد { جذر } من "رياضيات"

دالة رئيسية() {
    متغير س = جذر(16)    // ✅ يعمل الآن
}
```

### الحالة ٣: استدعاء دالة من صنف بدون كائن

```tarqeem
صنف حاسبة {
    دالة جمع(أ: عدد، ب: عدد) -> عدد {
        أرجع أ + ب
    }
}

// ❌ خطأ: استدعاء بدون كائن
متغير نتيجة = جمع(1، 2)

// ✅ الصحيح
متغير ح = جديد حاسبة()
متغير نتيجة = ح.جمع(1، 2)
```

### الحالة ٤: الخلط بين الدوال والمتغيرات

```tarqeem
// ❌ خطأ: محاولة استدعاء متغير كدالة
متغير حساب = 10
متغير نتيجة = حساب(5)    // خطأ: 'حساب' ليست دالة

// ✅ الصحيح
دالة حساب(س: عدد) -> عدد {
    أرجع س * 2
}
متغير نتيجة = حساب(5)
```

## ملاحظات إضافية

- الدوال المدمجة مثل `اطبع` و `طول` متاحة دائماً بدون استيراد
- دوال المكتبة القياسية تحتاج استيراداً صريحاً
- تأكد من مطابقة عدد المعاملات عند الاستدعاء

```tarqeem
// الدوال المدمجة متاحة مباشرة
اطبع("مرحباً")           // ✅ دالة مدمجة
متغير ط = طول([1، 2، 3]) // ✅ دالة مدمجة

// دوال المكتبة تحتاج استيراداً
استورد { جيب، جيب_التمام } من "رياضيات"
متغير س = جيب(0)         // ✅ بعد الاستيراد
```
