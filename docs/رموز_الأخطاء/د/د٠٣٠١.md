# د٠٣٠١: استخدام 'أوقف' خارج حلقة

## الوصف

هذا الخطأ يحدث عند استخدام كلمة `أوقف` (break) خارج سياق حلقة تكرارية (`طالما` أو `لكل`).

كلمة `أوقف` مخصصة لإنهاء تنفيذ الحلقة والخروج منها مباشرة. لا يمكن استخدامها في سياقات أخرى مثل الدوال العادية أو الشروط.

## سبب الخطأ

المترجم يتوقع وجود حلقة تكرارية تحيط بـ `أوقف` لأن هذه الكلمة المفتاحية تعمل فقط على الحلقات. عند استخدامها خارج حلقة، لا يوجد سياق لإيقافه.

## مثال الخطأ

```tarqeem
دالة معالجة() {
    أوقف    // ❌ خطأ: لا توجد حلقة لإيقافها
}
```

**الرسالة**:
```
خطأ[د٠٣٠١]: 'أوقف' يمكن استخدامها فقط داخل حلقة
  --> ملف.ترقيم:٢:٥
   |
 ٢ |     أوقف
   |     ^^^^
```

## الحل

استخدم `أوقف` فقط داخل حلقات `طالما` أو `لكل`:

```tarqeem
دالة معالجة() {
    لكل (متغير ع = 0؛ ع < 100؛ ع++) {
        إذا (ع == 50) {
            أوقف    // ✅ صحيح: داخل حلقة لكل
        }
    }
}
```

```tarqeem
دالة بحث(قائمة: مصفوفة<عدد>، هدف: عدد) -> عدد {
    متغير فهرس = -1
    متغير ع = 0
    طالما (ع < قائمة.طول) {
        إذا (قائمة[ع] == هدف) {
            فهرس = ع
            أوقف    // ✅ صحيح: داخل حلقة طالما
        }
        ع++
    }
    أرجع فهرس
}
```

## حالات شائعة

### الحالة ١: الخلط بين أوقف وأرجع

```tarqeem
// ❌ خطأ شائع
دالة تحقق(قيمة: عدد) {
    إذا (قيمة < 0) {
        أوقف    // يجب استخدام أرجع للخروج من الدالة
    }
}

// ✅ الصحيح
دالة تحقق(قيمة: عدد) {
    إذا (قيمة < 0) {
        أرجع    // للخروج من الدالة
    }
}
```

### الحالة ٢: أوقف في شرط بدون حلقة

```tarqeem
// ❌ خطأ
دالة اختبار(س: عدد) {
    إذا (س > 10) {
        أوقف
    }
}

// ✅ الصحيح - أوقف داخل حلقة والشرط داخل الحلقة
دالة اختبار() {
    لكل عنصر في مجموعة {
        إذا (عنصر > 10) {
            أوقف    // هنا صحيح لأن الشرط داخل الحلقة
        }
    }
}
```

## ملاحظات إضافية

- للخروج من **دالة**، استخدم `أرجع`
- للانتقال إلى **التكرار التالي** في حلقة، استخدم `استمر`
- `أوقف` تخرج من **أقرب** حلقة فقط، وليس من كل الحلقات المتداخلة

```tarqeem
// مثال على الحلقات المتداخلة
لكل (متغير ع = 0؛ ع < 10؛ ع++) {
    لكل (متغير ص = 0؛ ص < 10؛ ص++) {
        إذا (ص == 5) {
            أوقف    // يخرج من الحلقة الداخلية فقط
        }
    }
    // التنفيذ يستمر هنا بعد أوقف
}
```
