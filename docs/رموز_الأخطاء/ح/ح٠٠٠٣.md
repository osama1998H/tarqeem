# ح٠٠٠٣: استيراد غير مستخدم

## الوصف

هذا التحذير يظهر عند استيراد وحدة أو عنصر دون استخدامه في الكود.

الاستيرادات غير المستخدمة تُبطئ وقت الترجمة وتزيد من تعقيد الملف دون فائدة. قد تكون الاستيرادات قد أُضيفت أثناء التطوير ثم لم تُستخدم، أو قد يكون الكود الذي يستخدمها قد حُذف.

## مستوى الخطورة

**تحذير** - لن يمنع الترجمة لكنه يشير إلى كود زائد.

## سبب التحذير

المترجم يتتبع جميع الاستيرادات ويتحقق من استخدام العناصر المستوردة. عندما يجد استيراداً لم يُستخدم أي عنصر منه، يُصدر هذا التحذير.

## مثال التحذير

```tarqeem
استورد { قائمة، قاموس } من "مجموعات"    // ⚠️ تحذير: قاموس غير مستخدم
استورد * كـ رياضيات من "رياضيات"         // ⚠️ تحذير: رياضيات غير مستخدم

دالة رئيسية() {
    متغير أرقام = جديد قائمة<عدد>()
    أرقام.أضف(1)
    أرقام.أضف(2)
    // قاموس ورياضيات لم يُستخدما
}
```

**الرسالة**:
```
تحذير[ح٠٠٠٣]: الاستيراد 'قاموس' غير مستخدم
  --> ملف.ترقيم:١:١٨
   |
 ١ | استورد { قائمة، قاموس } من "مجموعات"
   |                  ^^^^^

تحذير[ح٠٠٠٣]: الاستيراد 'رياضيات' غير مستخدم
  --> ملف.ترقيم:٢:١٤
   |
 ٢ | استورد * كـ رياضيات من "رياضيات"
   |             ^^^^^^^
```

## الحل

### الحل ١: إزالة الاستيراد غير المستخدم

```tarqeem
استورد { قائمة } من "مجموعات"    // ✅ فقط ما نحتاجه

دالة رئيسية() {
    متغير أرقام = جديد قائمة<عدد>()
    أرقام.أضف(1)
    أرقام.أضف(2)
}
```

### الحل ٢: استخدام العنصر المستورد

```tarqeem
استورد { قائمة، قاموس } من "مجموعات"
استورد * كـ رياضيات من "رياضيات"

دالة رئيسية() {
    متغير أرقام = جديد قائمة<عدد>()
    متغير خريطة = جديد قاموس<نص، عدد>()    // ✅ الآن قاموس مستخدم

    متغير جذر = رياضيات.جذر_تربيعي(16.0)   // ✅ الآن رياضيات مستخدم
}
```

### الحل ٣: استخدام بادئة الشرطة السفلية للاسم المستعار

```tarqeem
استورد * كـ _رياضيات من "رياضيات"    // ✅ لا تحذير - للاستخدام المستقبلي
```

## حالات شائعة

### الحالة ١: استيراد أثناء التطوير

```tarqeem
// ⚠️ غالباً ما تحدث أثناء التجربة
استورد { معالج_ملفات } من "ملفات"
استورد { معالج_شبكة } من "شبكة"    // جُرِّب ثم لم يُستخدم

دالة رئيسية() {
    متغير ملف = معالج_ملفات.افتح("بيانات.نص")
    // ...
}
```

### الحالة ٢: استيراد نجمي غير مستخدم

```tarqeem
// ⚠️ استيراد كل شيء لكن لم نستخدم شيئاً
استورد * من "أدوات"

// ✅ أفضل - استورد فقط ما تحتاج
استورد { الأداة_المحددة } من "أدوات"
```

### الحالة ٣: استيراد لأغراض الأنماط فقط

```tarqeem
// بعض الاستيرادات تكون لأغراض التحقق من الأنماط فقط
استورد { نوع_البيانات } من "أنماط"    // قد لا يُستخدم مباشرة

// في هذه الحالة، قد تحتاج لإعادة التصدير أو استخدام صريح
```

## نصائح لإدارة الاستيرادات

1. **استورد فقط ما تحتاج** - تجنب الاستيراد النجمي `*` قدر الإمكان
2. **نظّف الاستيرادات دورياً** - بعد حذف كود، تحقق من الاستيرادات
3. **استخدم أدوات التنسيق** - `tarqeem fmt` يمكنه ترتيب الاستيرادات
4. **جمّع الاستيرادات** - ضع كل الاستيرادات في بداية الملف

## استثناءات من التحذير

التحذير **لا** يُصدر للاستيرادات التالية:
- **الاستيرادات المُعاد تصديرها** - جزء من الواجهة العامة
- **الاستيرادات التي تبدأ بـ `_`** - إشارة للتجاهل المقصود
- **استيراد الأنماط للتحقق** - في بعض الحالات الخاصة

## ملاحظات إضافية

- الاستيرادات غير المستخدمة قد تُبطئ الترجمة
- إزالتها تُحسّن وضوح الكود وتُسهّل الصيانة
- بعض بيئات التطوير تحذف الاستيرادات غير المستخدمة تلقائياً
