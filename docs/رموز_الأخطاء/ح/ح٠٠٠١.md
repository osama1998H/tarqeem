# ح٠٠٠١: متغير غير مستخدم

## الوصف

هذا التحذير يظهر عند تعريف متغير دون استخدامه في أي مكان من الكود.

المتغيرات غير المستخدمة تشير عادةً إلى كود منسي أو خطأ في المنطق البرمجي. قد يكون المتغير قد أُنشئ لغرض ما ثم نُسي، أو قد يكون هناك خطأ إملائي عند محاولة استخدامه.

## مستوى الخطورة

**تحذير** - لن يمنع الترجمة لكنه يشير إلى مشكلة محتملة.

## سبب التحذير

المترجم يتتبع جميع المتغيرات المُعرَّفة ويتحقق من استخدامها. عندما يجد متغيراً لم يُقرأ أو يُستخدم في أي تعبير، يُصدر هذا التحذير.

## مثال التحذير

```tarqeem
دالة حساب() {
    متغير س = 10    // ⚠️ تحذير: المتغير 'س' معرَّف لكن غير مستخدم
    متغير ص = 20
    أرجع ص * 2
}
```

**الرسالة**:
```
تحذير[ح٠٠٠١]: المتغير 'س' مُعرَّف لكن غير مستخدم
  --> ملف.ترقيم:٢:٥
   |
 ٢ |     متغير س = 10
   |            ^
```

## الحل

### الحل ١: استخدام المتغير

```tarqeem
دالة حساب() {
    متغير س = 10
    متغير ص = 20
    أرجع س + ص * 2    // ✅ الآن 'س' مستخدم
}
```

### الحل ٢: إزالة المتغير غير المستخدم

```tarqeem
دالة حساب() {
    متغير ص = 20
    أرجع ص * 2    // ✅ أنظف - بدون متغيرات غير مستخدمة
}
```

### الحل ٣: استخدام بادئة الشرطة السفلية

إذا كنت تريد الاحتفاظ بالمتغير لسبب ما (مثل التوثيق أو للاستخدام المستقبلي)، استخدم بادئة `_`:

```tarqeem
دالة حساب() {
    متغير _س = 10    // ✅ لا تحذير - البادئة تُعلم المترجم بالتجاهل
    متغير ص = 20
    أرجع ص * 2
}
```

## حالات شائعة

### الحالة ١: متغير مُعدّ للاستخدام المستقبلي

```tarqeem
// ⚠️ تحذير
دالة معالجة() {
    متغير إعدادات = تحميل_الإعدادات()    // لم يُستخدم بعد
    // ... كود آخر
}

// ✅ الصحيح - استخدام بادئة _
دالة معالجة() {
    متغير _إعدادات = تحميل_الإعدادات()    // محفوظ للاستخدام لاحقاً
    // ... كود آخر
}
```

### الحالة ٢: نتيجة دالة غير مستخدمة

```tarqeem
// ⚠️ تحذير
دالة اختبار() {
    متغير نتيجة = احسب()
    // نسينا استخدام النتيجة
}

// ✅ الصحيح - استخدام النتيجة
دالة اختبار() {
    متغير نتيجة = احسب()
    اطبع(نتيجة)
}
```

### الحالة ٣: معامل في حلقة لكل

```tarqeem
// ⚠️ تحذير - الفهرس غير مستخدم
لكل (متغير ع = 0؛ ع < 10؛ ع++) {
    متغير _قيمة = قائمة[ع]
    // نحتاج فقط لعدد التكرارات
}

// ✅ أفضل - استخدام حلقة مناسبة
متغير عداد = 0
طالما (عداد < 10) {
    // ...
    عداد++
}
```

## متى يجب تجاهل هذا التحذير؟

في بعض الحالات النادرة، قد تحتاج لمتغير غير مستخدم:
- لأغراض التوثيق والوضوح
- للحفاظ على توافق API
- عند استخدام أنماط معينة مثل RAII

في هذه الحالات، استخدم بادئة `_` للإشارة للمترجم بأن عدم الاستخدام مقصود.

## ملاحظات إضافية

- هذا تحذير وليس خطأ - الكود سيترجم بنجاح
- المتغيرات التي تبدأ بـ `_` لا تُصدر تحذيرات
- التحذير يساعد في اكتشاف الأخطاء الإملائية في أسماء المتغيرات
