# ح٠٠٠٢: دالة غير مستخدمة

## الوصف

هذا التحذير يظهر عند تعريف دالة دون استدعائها في أي مكان من الكود.

الدوال غير المستخدمة تزيد من حجم الكود وتجعل الصيانة أصعب. قد تكون الدالة قد كُتبت لغرض ما ثم لم تُستخدم، أو قد تكون هناك دالة بديلة أُضيفت ونُسيت الأصلية.

## مستوى الخطورة

**تحذير** - لن يمنع الترجمة لكنه يشير إلى كود زائد.

## سبب التحذير

المترجم يتتبع جميع الدوال المُعرَّفة ويتحقق من استدعائها. عندما يجد دالة لم تُستدعَ من أي مكان، يُصدر هذا التحذير.

## مثال التحذير

```tarqeem
دالة حساب_المجموع(أ: عدد، ب: عدد) -> عدد {    // ⚠️ تحذير
    أرجع أ + ب
}

دالة حساب_الفرق(أ: عدد، ب: عدد) -> عدد {
    أرجع أ - ب
}

دالة رئيسية() {
    متغير نتيجة = حساب_الفرق(10، 5)
    اطبع(نتيجة)
    // حساب_المجموع لم تُستدعَ أبداً
}
```

**الرسالة**:
```
تحذير[ح٠٠٠٢]: الدالة 'حساب_المجموع' مُعرَّفة لكن غير مستدعاة
  --> ملف.ترقيم:١:١
   |
 ١ | دالة حساب_المجموع(أ: عدد، ب: عدد) -> عدد {
   |      ^^^^^^^^^^^^^
```

## الحل

### الحل ١: استخدام الدالة

```tarqeem
دالة حساب_المجموع(أ: عدد، ب: عدد) -> عدد {
    أرجع أ + ب
}

دالة رئيسية() {
    متغير مجموع = حساب_المجموع(10، 5)    // ✅ الآن الدالة مستخدمة
    اطبع(مجموع)
}
```

### الحل ٢: إزالة الدالة غير المستخدمة

```tarqeem
// إذا لم تكن بحاجة للدالة، احذفها لتنظيف الكود
دالة رئيسية() {
    متغير نتيجة = 10 - 5    // ✅ كود أبسط
    اطبع(نتيجة)
}
```

### الحل ٣: استخدام بادئة الشرطة السفلية

إذا كانت الدالة للاستخدام الخارجي (API) أو للاستخدام المستقبلي:

```tarqeem
دالة _حساب_المجموع(أ: عدد، ب: عدد) -> عدد {    // ✅ لا تحذير
    أرجع أ + ب
}
```

## حالات شائعة

### الحالة ١: دالة مساعدة منسية

```tarqeem
// ⚠️ تحذير - دالة مساعدة لم تُستخدم
دالة تنسيق_الاسم(اسم: نص) -> نص {
    أرجع "السيد " + اسم
}

دالة طباعة_ترحيب(اسم: نص) {
    اطبع("مرحباً " + اسم)    // نسينا استخدام تنسيق_الاسم
}
```

### الحالة ٢: دالة مُعدة للتصدير

```tarqeem
// إذا كانت الدالة للتصدير كجزء من مكتبة
صدّر دالة أداة_عامة() {    // ✅ لا تحذير - مُصدَّرة
    // ...
}

// أو استخدم بادئة _ للدوال الداخلية المُعدة للاستخدام لاحقاً
دالة _أداة_مستقبلية() {    // ✅ لا تحذير
    // ...
}
```

### الحالة ٣: دالة اختبار

```tarqeem
// دوال الاختبار قد لا تُستدعى في الكود الرئيسي
#[اختبار]
دالة اختبار_الجمع() {    // ✅ لا تحذير - دالة اختبار
    // ...
}
```

## استثناءات من التحذير

التحذير **لا** يُصدر للدوال التالية:
- **الدالة الرئيسية** (`رئيسية` / `__main__`) - نقطة الدخول
- **الدوال المُصدَّرة** - جزء من الواجهة العامة
- **دوال المنشئ** (`منشئ`) - تُستدعى ضمنياً عند إنشاء الكائنات
- **الدوال التي تبدأ بـ `_`** - إشارة للتجاهل المقصود
- **الدوال المدمجة** - دوال النظام

## ملاحظات إضافية

- الدوال غير المستخدمة تزيد من حجم الملف التنفيذي
- إزالة الكود غير المستخدم تُحسّن قابلية القراءة والصيانة
- بعض أدوات التحسين قد تحذف الدوال غير المستخدمة تلقائياً
