# ن٠٠٠٢: لا يمكن استنتاج النوع

## الوصف

هذا الخطأ يحدث عندما لا يستطيع المترجم تحديد نوع متغير أو تعبير تلقائياً. يحدث هذا عادةً عندما:

- يُعلن متغير بدون نوع وبدون قيمة ابتدائية
- التعبير غامض ولا يمكن تحديد نوعه
- المصفوفة فارغة بدون تحديد نوع العناصر

## سبب الخطأ

ترقيم تدعم استنتاج الأنواع (Type Inference)، لكنها تحتاج معلومات كافية لتحديد النوع. عندما لا تتوفر هذه المعلومات، يجب تحديد النوع صراحةً.

## مثال الخطأ

```tarqeem
متغير س    // ❌ خطأ: لا يمكن استنتاج النوع بدون قيمة ابتدائية
```

**الرسالة**:
```
خطأ[ن٠٠٠٢]: لا يمكن استنتاج النوع
  --> ملف.ترقيم:١:١
   |
 ١ | متغير س
   |        ^
   |
   = يرجى تحديد النوع صراحةً أو إعطاء قيمة ابتدائية
```

## الحل

حدد النوع صراحةً أو أعطِ قيمة ابتدائية:

```tarqeem
// ✅ الحل ١: تحديد النوع صراحةً
متغير س: عدد

// ✅ الحل ٢: إعطاء قيمة ابتدائية
متغير س = 0

// ✅ الحل ٣: كلاهما
متغير س: عدد = 0
```

## حالات شائعة

### الحالة ١: مصفوفة فارغة

```tarqeem
// ❌ خطأ: لا يمكن معرفة نوع عناصر المصفوفة
متغير قائمة = []

// ✅ الصحيح: تحديد نوع المصفوفة
متغير قائمة: مصفوفة<عدد> = []
```

### الحالة ٢: قاموس فارغ

```tarqeem
// ❌ خطأ
متغير بيانات = {}

// ✅ الصحيح
متغير بيانات: قاموس<نص، عدد> = {}
```

### الحالة ٣: معامل دالة سهمية

```tarqeem
// ❌ خطأ في بعض السياقات
ثابت دالة = (س) => س * 2

// ✅ الصحيح: تحديد نوع المعامل
ثابت دالة = (س: عدد) => س * 2
```

### الحالة ٤: متغير سيُعيَّن لاحقاً

```tarqeem
// ❌ خطأ
متغير نتيجة
إذا (شرط) {
    نتيجة = 10
} وإلا {
    نتيجة = 20
}

// ✅ الصحيح: تحديد النوع
متغير نتيجة: عدد
إذا (شرط) {
    نتيجة = 10
} وإلا {
    نتيجة = 20
}
```

## ملاحظات إضافية

- استنتاج الأنواع يعمل جيداً مع القيم الابتدائية الواضحة
- المصفوفات والقواميس الفارغة تحتاج دائماً تحديد النوع
- في الدوال السهمية، قد يُستنتج النوع من السياق
