# ن٠٢٠١: معامل نوع معمم غير محدد

## الوصف

هذا الخطأ يحدث عند استخدام صنف أو دالة معممة (Generic) بدون تحديد معاملات النوع المطلوبة. الأنواع المعممة تحتاج تحديد النوع الفعلي عند الاستخدام.

## سبب الخطأ

الأصناف والدوال المعممة تُعرَّف بمعاملات نوع (Type Parameters) مثل `<ن>` أو `<م، ق>`. عند إنشاء نسخة أو استدعاء الدالة، يجب تحديد الأنواع الفعلية لهذه المعاملات.

## مثال الخطأ

```tarqeem
صنف قائمة<ن> {
    // ...
}

متغير ق = جديد قائمة()    // ❌ خطأ: لم يُحدد نوع العناصر <ن>
```

**الرسالة**:
```
خطأ[ن٠٢٠١]: معامل نوع معمم غير محدد
  --> ملف.ترقيم:٥:١٤
   |
 ٥ | متغير ق = جديد قائمة()
   |              ^^^^^^^^
   |
   = الصنف 'قائمة' يتطلب معامل نوع واحد
   = مثال: قائمة<عدد> أو قائمة<نص>
```

## الحل

حدد معاملات النوع عند استخدام الأنواع المعممة:

```tarqeem
// ✅ صحيح: تحديد نوع العناصر
متغير أرقام = جديد قائمة<عدد>()
متغير أسماء = جديد قائمة<نص>()

// ✅ صحيح: قاموس بنوعين
متغير بيانات = جديد قاموس<نص، عدد>()
```

## حالات شائعة

### الحالة ١: قائمة بدون نوع

```tarqeem
// ❌ خطأ
متغير قائمة = جديد قائمة()

// ✅ الصحيح
متغير قائمة = جديد قائمة<عدد>()
```

### الحالة ٢: قاموس بدون أنواع

```tarqeem
// ❌ خطأ: القاموس يحتاج نوع المفتاح والقيمة
متغير خريطة = جديد قاموس()

// ✅ الصحيح
متغير خريطة = جديد قاموس<نص، عدد>()
```

### الحالة ٣: صنف معمم مخصص

```tarqeem
صنف صندوق<ن> {
    محتوى: ن

    منشئ(قيمة: ن) {
        هذا.محتوى = قيمة
    }
}

// ❌ خطأ
متغير ص = جديد صندوق(42)

// ✅ الصحيح
متغير ص = جديد صندوق<عدد>(42)
```

### الحالة ٤: دالة معممة

```tarqeem
دالة أول<ن>(قائمة: مصفوفة<ن>) -> ن {
    أرجع قائمة[0]
}

// ✅ النوع يُستنتج من المعامل في معظم الحالات
متغير أرقام = [1، 2، 3]
متغير الأول = أول(أرقام)    // النوع يُستنتج كـ عدد

// ✅ أو حدده صراحةً
متغير الأول = أول<عدد>(أرقام)
```

### الحالة ٥: أنواع معممة متداخلة

```tarqeem
// ❌ خطأ: نقص في تحديد الأنواع
متغير معقد = جديد قائمة<قاموس>()

// ✅ الصحيح: تحديد كل الأنواع
متغير معقد = جديد قائمة<قاموس<نص، عدد>>()
```

## ملاحظات إضافية

- بعض الأنواع المعممة قد تستنتج معاملاتها من السياق
- المصفوفات الحرفية مثل `[1، 2، 3]` تستنتج نوعها تلقائياً
- عند الشك، حدد النوع صراحةً لتجنب الأخطاء

## الأنواع المعممة الشائعة

| النوع | معاملات النوع | مثال |
|-------|--------------|------|
| مصفوفة | `<ن>` | `مصفوفة<عدد>` |
| قائمة | `<ن>` | `قائمة<نص>` |
| قاموس | `<م، ق>` | `قاموس<نص، عدد>` |
| مجموعة | `<ن>` | `مجموعة<عدد>` |
| طابور | `<ن>` | `طابور<نص>` |
| مكدس | `<ن>` | `مكدس<عدد>` |
