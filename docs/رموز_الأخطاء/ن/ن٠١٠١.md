# ن٠١٠١: تحويل غير صحيح

## الوصف

هذا الخطأ يحدث عند محاولة تحويل قيمة من نوع إلى آخر بطريقة غير مدعومة. بعض التحويلات بين الأنواع غير ممكنة أو قد تؤدي إلى فقدان بيانات.

## سبب الخطأ

ليست كل الأنواع قابلة للتحويل بينها. على سبيل المثال:
- لا يمكن تحويل صنف إلى نوع بدائي مباشرةً
- بعض التحويلات قد تفقد دقة البيانات
- الأنواع غير المتوافقة لا يمكن تحويلها

## مثال الخطأ

```tarqeem
صنف شخص {
    اسم: نص
}

متغير ش = جديد شخص()
متغير س: عدد = ش    // ❌ خطأ: لا يمكن تحويل شخص إلى عدد
```

**الرسالة**:
```
خطأ[ن٠١٠١]: تحويل غير صحيح
  --> ملف.ترقيم:٦:١٨
   |
 ٦ | متغير س: عدد = ش
   |                 ^
   |
   = لا يمكن تحويل 'شخص' إلى 'عدد'
```

## الحل

استخدم طريقة تحويل صحيحة أو تأكد من توافق الأنواع:

```tarqeem
// ✅ استخدم خاصية من الصنف بدلاً من الصنف نفسه
صنف شخص {
    اسم: نص
    عمر: عدد
}

متغير ش = جديد شخص()
متغير العمر: عدد = ش.عمر    // صحيح: الوصول لخاصية بالنوع المطلوب
```

## حالات شائعة

### الحالة ١: تحويل نص إلى عدد

```tarqeem
// ❌ خطأ: التحويل المباشر غير مدعوم
متغير س: عدد = "123"

// ✅ الصحيح: استخدم دالة التحويل
متغير س: عدد = حول_لعدد("123")
```

### الحالة ٢: تحويل عدد_عشري إلى عدد (فقدان دقة)

```tarqeem
// ⚠️ تحذير: قد يفقد الجزء العشري
متغير س: عدد_عشري = 3.14
متغير ص: عدد = س    // يصبح 3

// ✅ الصحيح: استخدم دالة التقريب المناسبة
متغير ص: عدد = قرب(س)    // أو اقطع(س)
```

### الحالة ٣: تحويل منطقي إلى نص

```tarqeem
// ❌ خطأ في بعض السياقات
متغير م: منطقي = صحيح
متغير ن: نص = م

// ✅ الصحيح
متغير ن: نص = إذا (م) "نعم" وإلا "لا"
// أو
متغير ن: نص = حول_لنص(م)
```

### الحالة ٤: تحويل بين أصناف غير متوافقة

```tarqeem
صنف حيوان { }
صنف سيارة { }

// ❌ خطأ: أصناف غير متوافقة
متغير ح: حيوان = جديد حيوان()
متغير س: سيارة = ح

// ✅ الصحيح: استخدم أصناف ذات علاقة وراثية
صنف قط يرث حيوان { }
متغير ح: حيوان = جديد قط()    // صحيح: قط هو نوع من حيوان
```

## التحويلات المدعومة

| من | إلى | مدعوم |
|----|-----|-------|
| عدد | عدد_عشري | ✅ تلقائي |
| عدد_عشري | عدد | ⚠️ مع فقدان |
| عدد/عدد_عشري | نص | ✅ بدالة |
| نص | عدد/عدد_عشري | ✅ بدالة |
| صنف_فرعي | صنف_أب | ✅ تلقائي |
| صنف_أب | صنف_فرعي | ❌ يحتاج تحقق |
