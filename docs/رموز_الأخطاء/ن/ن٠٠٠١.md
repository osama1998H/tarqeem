# ن٠٠٠١: عدم تطابق الأنواع

## الوصف

هذا الخطأ يحدث عندما يكون نوع القيمة المُعطاة مختلفاً عن النوع المتوقع. يمكن أن يظهر في عدة سياقات مثل:

- تعيين قيمة لمتغير بنوع مختلف
- تمرير معامل بنوع خاطئ لدالة
- إرجاع قيمة بنوع مختلف عن نوع الإرجاع المُعلن
- عناصر مصفوفة بأنواع مختلفة

## سبب الخطأ

نظام الأنواع في ترقيم صارم (Static Typing)، مما يعني أن كل قيمة يجب أن تتطابق مع النوع المتوقع. هذا يساعد في اكتشاف الأخطاء مبكراً قبل تشغيل البرنامج.

## مثال الخطأ

### تعيين قيمة بنوع خاطئ

```tarqeem
متغير س: عدد = "نص"    // ❌ خطأ: متوقع عدد، وُجد نص
```

**الرسالة**:
```
خطأ[ن٠٠٠١]: عدم تطابق الأنواع
  --> ملف.ترقيم:١:١٨
   |
 ١ | متغير س: عدد = "نص"
   |                 ^^^^
   |
   = متوقع: عدد
   = وُجد: نص
```

### تمرير معامل بنوع خاطئ

```tarqeem
دالة جمع(أ: عدد، ب: عدد) -> عدد {
    أرجع أ + ب
}

متغير نتيجة = جمع(5، "عشرة")    // ❌ خطأ: المعامل الثاني يجب أن يكون عدد
```

## الحل

تأكد من أن نوع القيمة يتطابق مع النوع المتوقع:

```tarqeem
// ✅ صحيح: أنواع متطابقة
متغير س: عدد = 42
متغير اسم: نص = "أحمد"
متغير نشط: منطقي = صحيح

// ✅ صحيح: تمرير معاملات بالنوع الصحيح
متغير نتيجة = جمع(5، 10)
```

## حالات شائعة

### الحالة ١: الخلط بين عدد وعدد_عشري

```tarqeem
// ❌ خطأ
متغير س: عدد = 3.14

// ✅ الصحيح
متغير س: عدد_عشري = 3.14
// أو
متغير س: عدد = 3
```

### الحالة ٢: عناصر مصفوفة بأنواع مختلفة

```tarqeem
// ❌ خطأ: المصفوفة تحتوي أنواع مختلفة
متغير قائمة: مصفوفة<عدد> = [1، 2، "ثلاثة"]

// ✅ الصحيح
متغير قائمة: مصفوفة<عدد> = [1، 2، 3]
```

### الحالة ٣: نوع الإرجاع غير متطابق

```tarqeem
// ❌ خطأ
دالة احسب() -> عدد {
    أرجع "نتيجة"    // النوع المرجع نص، لكن المتوقع عدد
}

// ✅ الصحيح
دالة احسب() -> عدد {
    أرجع 42
}
```

### الحالة ٤: التحويل الضمني غير المدعوم

```tarqeem
// ❌ خطأ: لا يمكن تحويل نص إلى عدد تلقائياً
متغير س: عدد = "123"

// ✅ الصحيح: استخدم دالة التحويل
متغير س: عدد = حول_لعدد("123")
```

## ملاحظات إضافية

- التحويل من `عدد` إلى `عدد_عشري` يتم تلقائياً في بعض السياقات
- لا يتم التحويل التلقائي من `نص` إلى أنواع رقمية
- استخدم دوال التحويل المناسبة عند الحاجة
