# ب٠١٠١: متوقع فاصلة منقوطة

## الوصف

هذا الخطأ يحدث عندما يتوقع المحلل النحوي فاصلة منقوطة (`;` أو `؛`) لإنهاء جملة ولكنها غير موجودة.

## سبب الخطأ

بعض الجمل في ترقيم تتطلب فاصلة منقوطة في نهايتها:
- جمل التعريف: `متغير س = 5;`
- جمل الإرجاع: `أرجع نتيجة;`
- استدعاءات الدوال كجمل مستقلة: `اطبع("مرحباً");`
- جمل `أوقف` و`استمر`

## مثال الخطأ

### نسيان الفاصلة المنقوطة

```tarqeem
متغير س = 5
متغير ص = 10    // ❌ خطأ: الفاصلة المنقوطة مفقودة بعد السطر السابق
```

**الرسالة**:
```
خطأ[ب٠١٠١]: متوقع فاصلة منقوطة
  --> ملف.ترقيم:٢:١
   |
 ١ | متغير س = 5
   |            - هنا متوقع ';'
 ٢ | متغير ص = 10
   | ^
   |
   = أضف ';' أو '؛' بعد نهاية الجملة
```

## الحل

### الحل ١: إضافة الفاصلة المنقوطة

```tarqeem
// ❌ خطأ
متغير س = 5
متغير ص = 10

// ✅ صحيح - فاصلة منقوطة إنجليزية
متغير س = 5;
متغير ص = 10;

// ✅ صحيح - فاصلة منقوطة عربية
متغير س = 5؛
متغير ص = 10؛
```

### الحل ٢: استخدام أسطر جديدة

```tarqeem
// في بعض السياقات، السطر الجديد يكفي
دالة اختبار() {
    اطبع("سطر ١")
    اطبع("سطر ٢")
}
```

## حالات شائعة

### الحالة ١: جمل متعددة في سطر واحد

```tarqeem
// ❌ خطأ
متغير س = 5 متغير ص = 10

// ✅ صحيح
متغير س = 5; متغير ص = 10;

// ✅ أفضل - سطر منفصل لكل جملة
متغير س = 5;
متغير ص = 10;
```

### الحالة ٢: بعد جملة return

```tarqeem
// ❌ خطأ
دالة مربع(س: عدد) -> عدد {
    أرجع س * س
}

// ✅ صحيح (إذا كانت الفاصلة مطلوبة)
دالة مربع(س: عدد) -> عدد {
    أرجع س * س;
}
```

### الحالة ٣: داخل حلقة for

```tarqeem
// ❌ خطأ - فواصل منقوطة مفقودة
لكل (متغير ع = 0 ع < 10 ع++) { }

// ✅ صحيح
لكل (متغير ع = 0؛ ع < 10؛ ع++) { }
```

### الحالة ٤: بعد break/continue

```tarqeem
// ❌ خطأ
طالما (صحيح) {
    أوقف
}

// ✅ صحيح
طالما (صحيح) {
    أوقف;
}
```

### الحالة ٥: خلط بين الأقواس والفواصل

```tarqeem
// ❌ خطأ - نسيان الفاصلة المنقوطة
متغير س = (5 + 3)
متغير ص = 2

// ✅ صحيح
متغير س = (5 + 3);
متغير ص = 2;
```

## الفاصلة المنقوطة العربية والإنجليزية

ترقيم تقبل كلا الشكلين:

| الشكل | الرمز | اليونيكود |
|-------|-------|----------|
| إنجليزية | `;` | U+003B |
| عربية | `؛` | U+061B |

```tarqeem
// كلاهما صحيح
متغير س = 5;
متغير ص = 10؛
```

## السطر الجديد داخل الأقواس

السطر الجديد ينهي الجملة، **إلا داخل قوس مفتوح** (`(` أو `[`) — فهناك هو مسافة
بيضاء لا أكثر. لذلك تصح الأشكال الموزعة على أسطر:

```tarqeem
// ✅ قائمة معاملات موزعة
دالة اجمع(
    أ: عدد،
    ب: عدد
) -> عدد { أرجع أ + ب }

// ✅ استدعاء موزع
متغير مجموع = اجمع(
    ١،
    ٢
)

// ✅ شرط طويل بين قوسين
إذا (مجموع > ٢ &&
     مجموع < ١٠) { اطبع("نعم") }

// ✅ تعبير موزع داخل قوسين
أرجع (أ == ب &&
      ج == د)
```

وتبقى متابعة التعبير **خارج** الأقواس خطأً، لأن السطر الجديد أنهى الجملة:

```tarqeem
// ❌ خطأ
متغير س = ١ +
          ٢

// ✅ الحل: أحط التعبير بقوسين
متغير س = (١ +
           ٢)
```

> **قيد حالي**: التعليقات داخل قائمة معاملات موزعة غير مدعومة —
> `ف(\n ١، // ملاحظة\n ٢)` خطأ.

## متى لا تحتاج فاصلة منقوطة

بعض التركيبات لا تحتاج فاصلة منقوطة:

```tarqeem
// بعد كتلة { }
دالة اختبار() {
    // ...
}    // لا حاجة لفاصلة

// بعد if/else
إذا (شرط) {
    // ...
}    // لا حاجة لفاصلة

// بعد حلقات
طالما (شرط) {
    // ...
}    // لا حاجة لفاصلة
```

## نصائح للتجنب

1. **اكتب الفاصلة فوراً** - اعتد على كتابتها بعد كل جملة
2. **استخدم محرراً ذكياً** - يُظهر الفواصل المفقودة
3. **تحقق من الأسطر السابقة** - الخطأ قد يكون في السطر السابق
4. **راجع حلقات for** - تحتاج فواصل منقوطة بين أجزائها

## ملاحظات إضافية

- الفاصلة المنقوطة تفصل بين الجمل وليس التعبيرات
- في بعض الحالات، السطر الجديد يعمل كفاصل ضمني
- تأكد من استخدام الفاصلة المنقوطة وليس الفاصلة العادية
