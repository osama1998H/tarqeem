# ب٠٣٠١: متوقع اسم الدالة

## الوصف

هذا الخطأ يحدث عندما يتوقع المحلل النحوي اسم دالة (معرّف) بعد كلمة `دالة`، ولكنه يجد شيئاً آخر.

## سبب الخطأ

عند تعريف دالة، يجب أن يتبع الكلمة المفتاحية اسم صالح:

```tarqeem
دالة <اسم_الدالة>(<معاملات>) [-> <نوع>] {
    // جسم الدالة
}
```

الخطأ يحدث عندما:
1. ينقص اسم الدالة تماماً
2. يُستخدم رمز بدلاً من اسم
3. تُستخدم كلمة مفتاحية محجوزة كاسم
4. يبدأ القوس مباشرة بعد `دالة`

## مثال الخطأ

### نسيان اسم الدالة

```tarqeem
دالة () {    // ❌ خطأ: أين اسم الدالة؟
    اطبع("مرحباً")
}
```

**الرسالة**:
```
خطأ[ب٠٣٠١]: متوقع اسم الدالة
  --> ملف.ترقيم:١:٦
   |
 ١ | دالة () {
   |      ^
   |
   = متوقع معرّف بعد 'دالة'
```

### استخدام كلمة محجوزة

```tarqeem
دالة متغير() {    // ❌ خطأ: 'متغير' كلمة محجوزة
    // ...
}
```

**الرسالة**:
```
خطأ[ب٠٣٠١]: متوقع اسم الدالة
  --> ملف.ترقيم:١:٦
   |
 ١ | دالة متغير() {
   |      ^^^^^
   |
   = 'متغير' كلمة محجوزة، لا يمكن استخدامها كاسم دالة
```

## الحل

### الحل ١: إضافة اسم الدالة

```tarqeem
// ❌ خطأ
دالة () {
    اطبع("مرحباً")
}

// ✅ صحيح
دالة تحية() {
    اطبع("مرحباً")
}
```

### الحل ٢: اختيار اسم غير محجوز

```tarqeem
// ❌ خطأ - كلمات محجوزة
دالة إذا() { }
دالة صنف() { }
دالة أرجع() { }

// ✅ صحيح - أسماء بديلة
دالة تحقق_شرط() { }
دالة أنشئ_صنف() { }
دالة أعد_نتيجة() { }
```

### الحل ٣: تصحيح الصيغة

```tarqeem
// ❌ خطأ - صيغة خاطئة
دالة: تحية() { }
دالة = تحية() { }

// ✅ صحيح
دالة تحية() { }
```

## حالات شائعة

### الحالة ١: دالة سهمية بدون اسم

```tarqeem
// ❌ خطأ - محاولة تعريف دالة مجهولة بصيغة دالة
دالة () => س * 2

// ✅ صحيح - استخدم متغير للدوال المجهولة
متغير مربع = (س) => س * 2

// ✅ أو أعط الدالة اسماً
دالة مربع(س: عدد) -> عدد {
    أرجع س * 2
}
```

### الحالة ٢: قوس قبل الاسم

```tarqeem
// ❌ خطأ - القوس جاء أولاً
دالة (س: عدد) حساب { }

// ✅ صحيح - الاسم يأتي أولاً
دالة حساب(س: عدد) { }
```

### الحالة ٣: نسيان المسافة

```tarqeem
// ❌ خطأ - التصاق الاسم بالكلمة المفتاحية
دالةتحية() { }

// ✅ صحيح
دالة تحية() { }
```

### الحالة ٤: استخدام رمز خاص

```tarqeem
// ❌ خطأ
دالة @معالج() { }
دالة #خاص() { }

// ✅ صحيح
دالة معالج() { }
دالة _خاص() { }
```

### الحالة ٥: الخلط مع لغات أخرى

```tarqeem
// ❌ خطأ - صيغة JavaScript
function test() { }

// ❌ خطأ - صيغة Python
def test(): { }

// ✅ صحيح - صيغة ترقيم
دالة اختبار() { }
```

## قواعد تسمية الدوال

| القاعدة | مثال صحيح | مثال خاطئ |
|---------|----------|----------|
| يبدأ بحرف أو _ | `احسب`، `_داخلية` | `123دالة` |
| أحرف عربية | `احسب_المجموع` | - |
| فعل أمر (مُفضّل) | `احسب`، `أضف`، `احذف` | `الحساب` |
| شرطة سفلية للفصل | `احسب_الضريبة` | - |
| لا كلمات محجوزة | - | `دالة`، `إذا` |

## أنماط تسمية الدوال

```tarqeem
// دوال الفعل (actions)
دالة احسب() { }
دالة أضف_عنصر() { }
دالة احذف_من_القائمة() { }

// دوال الاستعلام (queries)
دالة هل_فارغ() -> منطقي { }
دالة احصل_على_طول() -> عدد { }

// دوال التحويل
دالة إلى_نص() -> نص { }
دالة من_نص() { }
```

## نصائح للتجنب

1. **اختر أسماء وصفية** - الاسم يوضح ما تفعله الدالة
2. **استخدم فعل الأمر** - للدوال التي تنفذ عملية
3. **تجنب الكلمات المحجوزة** - راجع قائمة الكلمات
4. **ابدأ بحرف** - لا تبدأ برقم أو رمز

## ملاحظات إضافية

- اسم الدالة يجب أن يكون معرّفاً صالحاً
- الدوال المجهولة (lambdas) لا تحتاج اسماً
- المنشئ `منشئ` لا يُعتبر اسم دالة عادية
