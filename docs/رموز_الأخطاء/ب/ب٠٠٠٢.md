# ب٠٠٠٢: رمز غير متوقع

## الوصف

هذا الخطأ يحدث عندما يواجه المحلل النحوي (Parser) رمزاً (Token) في موضع لا يتوقعه فيه.

## سبب الخطأ

كل موضع في الكود يتوقع أنواعاً معينة من الرموز:
- بعد `متغير`: يُتوقع معرّف (اسم المتغير)
- بعد `=`: يُتوقع تعبير
- بعد `دالة`: يُتوقع معرّف (اسم الدالة)
- بعد `(`: يُتوقع معاملات أو `)`

عندما يظهر رمز مختلف عما هو متوقع، يُصدر هذا الخطأ.

## مثال الخطأ

### رمز غير متوقع بعد كلمة مفتاحية

```tarqeem
متغير = 5    // ❌ خطأ: متوقع اسم المتغير، وُجد '='
```

**الرسالة**:
```
خطأ[ب٠٠٠٢]: رمز غير متوقع
  --> ملف.ترقيم:١:٨
   |
 ١ | متغير = 5
   |        ^
   |
   = متوقع معرّف، وُجد '='
```

### قوس إغلاق غير متوقع

```tarqeem
دالة اختبار( {    // ❌ خطأ: متوقع ')' أو معامل
```

**الرسالة**:
```
خطأ[ب٠٠٠٢]: رمز غير متوقع
  --> ملف.ترقيم:١:١٤
   |
 ١ | دالة اختبار( {
   |              ^
   |
   = متوقع ')' أو معامل، وُجد '{'
```

## الحل

### الحل ١: إضافة الرمز المفقود

```tarqeem
// ❌ خطأ
متغير = 5

// ✅ صحيح
متغير س = 5
```

### الحل ٢: إزالة الرمز الزائد

```tarqeem
// ❌ خطأ
متغير س = = 5

// ✅ صحيح
متغير س = 5
```

### الحل ٣: تصحيح ترتيب الرموز

```tarqeem
// ❌ خطأ
دالة (اختبار) { }

// ✅ صحيح
دالة اختبار() { }
```

## حالات شائعة

### الحالة ١: نسيان اسم المتغير

```tarqeem
// ❌ خطأ
متغير = "قيمة"
ثابت = 100

// ✅ صحيح
متغير اسم = "قيمة"
ثابت عدد = 100
```

### الحالة ٢: فاصلة زائدة

```tarqeem
// ❌ خطأ
دالة جمع(أ، ب،) { }    // فاصلة زائدة قبل )

// ✅ صحيح
دالة جمع(أ، ب) { }
```

### الحالة ٣: أقواس غير متطابقة

```tarqeem
// ❌ خطأ
إذا (س > 5] { }    // ] بدلاً من )

// ✅ صحيح
إذا (س > 5) { }
```

### الحالة ٤: كلمة مفتاحية في مكان معرّف

```tarqeem
// ❌ خطأ - استخدام كلمة مفتاحية كاسم
متغير إذا = 5

// ✅ صحيح - استخدام معرّف عادي
متغير شرط = 5
```

### الحالة ٥: عامل مكرر

```tarqeem
// ❌ خطأ
متغير س = 5 ++ 3    // عاملان متتاليان

// ✅ صحيح
متغير س = 5 + 3
```

### الحالة ٦: نسيان الفاصلة بين المعاملات

```tarqeem
// ❌ خطأ
دالة اختبار(أ ب) { }    // فاصلة مفقودة

// ✅ صحيح
دالة اختبار(أ، ب) { }
```

## الرسائل الشائعة

| الرسالة | المعنى |
|---------|--------|
| متوقع معرّف، وُجد X | مطلوب اسم (متغير/دالة/صنف) |
| متوقع ')'، وُجد X | قوس إغلاق مفقود |
| متوقع '}'، وُجد X | قوس معقوف إغلاق مفقود |
| متوقع تعبير، وُجد X | مطلوب قيمة أو تعبير |
| متوقع نوع، وُجد X | مطلوب نوع بيانات |

## نصائح للتجنب

1. **تحقق من الأقواس** - تأكد من تطابق كل قوس فتح مع قوس إغلاق
2. **راجع الفواصل** - تأكد من وجود فواصل بين المعاملات
3. **تجنب الكلمات المحجوزة** - لا تستخدم الكلمات المفتاحية كأسماء
4. **استخدم محرراً ذكياً** - المحررات الحديثة تُظهر الأخطاء فوراً
