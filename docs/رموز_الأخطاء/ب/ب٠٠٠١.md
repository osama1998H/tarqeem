# ب٠٠٠١: تعبير غير متوقع

## الوصف

هذا الخطأ يحدث عندما يواجه المحلل النحوي (Parser) تعبيراً في موضع لا يتوقع فيه تعبيراً.

## سبب الخطأ

المحلل النحوي يتوقع أنواعاً معينة من العناصر في مواضع محددة:
- بداية جملة: تعريف متغير، دالة، صنف، أو جملة تحكم
- بعد عامل: تعبير مُعامَل
- داخل قوس: تعبير أو معاملات

عندما يظهر تعبير في موضع غير متوقع، يُصدر هذا الخطأ.

## مثال الخطأ

### تعبير في بداية الملف

```tarqeem
5 + 3    // ❌ خطأ: تعبير بدون سياق
```

**الرسالة**:
```
خطأ[ب٠٠٠١]: تعبير غير متوقع
  --> ملف.ترقيم:١:١
   |
 ١ | 5 + 3
   | ^
   |
   = تعبير لا يمكن أن يكون جملة مستقلة
```

### تعبيران متتاليان بدون عامل

```tarqeem
متغير س = 5 10    // ❌ خطأ: تعبيران متجاوران
```

**الرسالة**:
```
خطأ[ب٠٠٠١]: تعبير غير متوقع
  --> ملف.ترقيم:١:١٣
   |
 ١ | متغير س = 5 10
   |             ^^
   |
   = تعبير غير متوقع بعد '5'
```

## الحل

### الحل ١: استخدام التعبير في جملة صحيحة

```tarqeem
// ❌ خطأ
5 + 3

// ✅ صحيح - تخزين النتيجة
متغير نتيجة = 5 + 3

// ✅ صحيح - طباعة النتيجة
اطبع(5 + 3)
```

### الحل ٢: إضافة عامل بين التعبيرات

```tarqeem
// ❌ خطأ
متغير س = 5 10

// ✅ صحيح - إضافة عامل
متغير س = 5 + 10
متغير ص = 5 * 10
```

### الحل ٣: فصل التعبيرات بفاصلة منقوطة

```tarqeem
// ❌ خطأ
اطبع("أ") اطبع("ب")

// ✅ صحيح - فصل الجمل
اطبع("أ")
اطبع("ب")
```

## حالات شائعة

### الحالة ١: نسيان العامل الرياضي

```tarqeem
// ❌ خطأ - نسيان علامة الضرب
متغير مساحة = طول عرض

// ✅ صحيح
متغير مساحة = طول * عرض
```

### الحالة ٢: خلط اللغات

```tarqeem
// ❌ خطأ - كلمة إنجليزية
متغير x = 5 result 10

// ✅ صحيح
متغير س = 5 + 10
```

### الحالة ٣: قوس مفقود في استدعاء دالة

```tarqeem
// ❌ خطأ - نسيان القوس
اطبع "مرحباً"

// ✅ صحيح
اطبع("مرحباً")
```

### الحالة ٤: تعبير بعد جملة return

```tarqeem
// ❌ خطأ - كود بعد return
دالة اختبار() -> عدد {
    أرجع 5
    اطبع("لن يُنفذ")    // تحذير: كود لا يمكن الوصول إليه
}

// ✅ صحيح
دالة اختبار() -> عدد {
    اطبع("قبل الإرجاع")
    أرجع 5
}
```

## ملاحظات إضافية

- بعض التعبيرات يمكن أن تكون جملاً مستقلة (مثل استدعاء الدوال)
- التعبيرات الحسابية وحدها ليست جملاً صحيحة
- تأكد من وجود عوامل بين جميع المُعامَلات
