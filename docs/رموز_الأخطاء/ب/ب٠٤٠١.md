# ب٠٤٠١: متوقع اسم الصنف

## الوصف

هذا الخطأ يحدث عندما يتوقع المحلل النحوي اسم صنف (معرّف) بعد كلمة `صنف`، ولكنه يجد شيئاً آخر.

## سبب الخطأ

عند تعريف صنف، يجب أن يتبع الكلمة المفتاحية اسم صالح:

```tarqeem
صنف <اسم_الصنف> [يرث <الأب>] [يلتزم <ميثاق>] {
    // جسم الصنف
}
```

الخطأ يحدث عندما:
1. ينقص اسم الصنف تماماً
2. يُستخدم رمز بدلاً من اسم
3. تُستخدم كلمة مفتاحية محجوزة كاسم
> **استثناء**: أسماء الأنماط (`عدد`، `عدد_عشري`، `نص`، `منطقي`، `مصفوفة`،
> `قاموس`، `أي`) و`احصل`/`عيّن`/`حالة` تصلح أسماءً في المواضع التي لا يأتي
> فيها غير اسم؛ و`صحيح`/`خطأ` تصلحان اسماً لحالة تعداد فقط. راجع «الكلمات
> المفتاحية كأسماء» في README.

4. تبدأ الكتلة `{` مباشرة بعد `صنف`

## مثال الخطأ

### نسيان اسم الصنف

```tarqeem
صنف {    // ❌ خطأ: أين اسم الصنف؟
    عام اسم: نص
}
```

**الرسالة**:
```
خطأ[ب٠٤٠١]: متوقع اسم الصنف
  --> ملف.ترقيم:١:٥
   |
 ١ | صنف {
   |     ^
   |
   = متوقع معرّف بعد 'صنف'
```

### استخدام كلمة محجوزة

```tarqeem
صنف دالة {    // ❌ خطأ: 'دالة' كلمة محجوزة
    // ...
}
```

**الرسالة**:
```
خطأ[ب٠٤٠١]: متوقع اسم الصنف
  --> ملف.ترقيم:١:٥
   |
 ١ | صنف دالة {
   |     ^^^^
   |
   = 'دالة' كلمة محجوزة، لا يمكن استخدامها كاسم صنف
```

## الحل

### الحل ١: إضافة اسم الصنف

```tarqeem
// ❌ خطأ
صنف {
    عام اسم: نص
}

// ✅ صحيح
صنف شخص {
    عام اسم: نص
}
```

### الحل ٢: اختيار اسم غير محجوز

```tarqeem
// ❌ خطأ - كلمات محجوزة
صنف متغير { }
صنف إذا { }
صنف صحيح { }      // ❌ حتى وإن صلحت «صحيح» اسماً لحالة تعداد

// ✅ صحيح - أسماء بديلة
صنف متغيرات { }
صنف شرط { }
صنف حالة_صحيحة { }
```

### الحل ٣: تصحيح الصيغة

```tarqeem
// ❌ خطأ - صيغة خاطئة
صنف: شخص { }
صنف = شخص { }

// ✅ صحيح
صنف شخص { }
```

## حالات شائعة

### الحالة ١: يرث بدون اسم

```tarqeem
// ❌ خطأ - يرث جاء قبل الاسم
صنف يرث حيوان {
    // ...
}

// ✅ صحيح
صنف قط يرث حيوان {
    // ...
}
```

### الحالة ٢: يلتزم بدون اسم

```tarqeem
// ❌ خطأ
صنف يلتزم قابل_للطباعة {
    // ...
}

// ✅ صحيح
صنف منتج يلتزم قابل_للطباعة {
    // ...
}
```

### الحالة ٣: نسيان المسافة

```tarqeem
// ❌ خطأ - التصاق الاسم بالكلمة المفتاحية
صنفشخص { }

// ✅ صحيح
صنف شخص { }
```

### الحالة ٤: استخدام رمز خاص

```tarqeem
// ❌ خطأ
صنف @مخصص { }
صنف #داخلي { }

// ✅ صحيح
صنف مخصص { }
صنف _داخلي { }
```

### الحالة ٥: الخلط مع لغات أخرى

```tarqeem
// ❌ خطأ - صيغة JavaScript/Java
class Person { }

// ❌ خطأ - صيغة Python
class Person: { }

// ✅ صحيح - صيغة ترقيم
صنف شخص { }
```

### الحالة ٦: صنف معمم بدون اسم

```tarqeem
// ❌ خطأ
صنف <ن> {
    عام قيمة: ن
}

// ✅ صحيح
صنف حاوية<ن> {
    عام قيمة: ن
}
```

## قواعد تسمية الأصناف

| القاعدة | مثال صحيح | مثال خاطئ |
|---------|----------|----------|
| يبدأ بحرف أو _ | `شخص`، `_داخلي` | `123صنف` |
| أحرف عربية | `مستخدم`، `طالب` | - |
| اسم (ليس فعل) | `سيارة`، `حساب` | `احسب` |
| بدون مسافات | `حساب_بنكي` | `حساب بنكي` |
| لا كلمات محجوزة | - | `صنف`، `دالة` |

## أنماط تسمية الأصناف

```tarqeem
// أسماء بسيطة
صنف شخص { }
صنف سيارة { }
صنف منتج { }

// أسماء مركبة
صنف حساب_بنكي { }
صنف طلب_شراء { }
صنف عنصر_قائمة { }

// أصناف معممة
صنف قائمة<ن> { }
صنف خريطة<م، ق> { }
صنف زوج<أ، ب> { }

// أصناف مع وراثة
صنف موظف يرث شخص { }
صنف مدير يرث موظف { }

// أصناف مع التزام
صنف تقرير يلتزم قابل_للطباعة { }
```

## الكلمات المحجوزة (لا يمكن استخدامها اسماً لصنف)

> **لماذا الصنف تحديداً؟** حالة التعداد تُقرأ عبر `::` دائماً
> (`النتيجة::خطأ`)، فلا لبس في `خطأ` هناك. أما اسم الصنف فلا سياج له:
> `جديد خطأ()` يقرأ المستدعى تعبيراً أولياً، فيصير القيمة المنطقية لا اسم نمط.


| الفئة | الكلمات |
|-------|---------|
| التعريف | متغير، ثابت، دالة، صنف، ميثاق |
| التحكم | إذا، وإلا، طالما، لكل |
| القيم | صحيح، خطأ، لا_شيء |
| الوصول | عام، خاص، محمي، مشترك |
| OOP | يرث، يلتزم، منشئ، هذا، الأصل، جديد |

## نصائح للتجنب

1. **استخدم أسماء واضحة** - الاسم يوضح ما يمثله الصنف
2. **استخدم صيغة الاسم** - وليس الفعل
3. **تجنب الكلمات المحجوزة** - راجع القائمة أعلاه
4. **ابدأ بحرف كبير (للاتينية)** - أو أي حرف عربي

## ملاحظات إضافية

- اسم الصنف يجب أن يكون معرّفاً صالحاً
- الأصناف المعممة تأخذ معاملات النوع بين `< >`
- كلمات الوراثة والالتزام تأتي بعد اسم الصنف
