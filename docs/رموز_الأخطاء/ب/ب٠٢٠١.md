# ب٠٢٠١: متوقع اسم المتغير

## الوصف

هذا الخطأ يحدث عندما يتوقع المحلل النحوي اسم متغير (معرّف) بعد كلمة `متغير` أو `ثابت`، ولكنه يجد شيئاً آخر.

## سبب الخطأ

عند تعريف متغير، يجب أن يتبع الكلمة المفتاحية اسم صالح:

```tarqeem
متغير <اسم_المتغير> = <قيمة>
ثابت <اسم_الثابت> = <قيمة>
```

الخطأ يحدث عندما:
1. ينقص الاسم تماماً
2. يُستخدم رمز بدلاً من اسم
3. تُستخدم كلمة مفتاحية محجوزة كاسم
4. يبدأ الاسم بحرف غير صالح

## مثال الخطأ

### نسيان اسم المتغير

```tarqeem
متغير = 5    // ❌ خطأ: أين اسم المتغير؟
```

**الرسالة**:
```
خطأ[ب٠٢٠١]: متوقع اسم المتغير
  --> ملف.ترقيم:١:٨
   |
 ١ | متغير = 5
   |        ^
   |
   = متوقع معرّف بعد 'متغير'
```

### استخدام كلمة محجوزة

```tarqeem
متغير إذا = 5    // ❌ خطأ: 'إذا' كلمة محجوزة
```

**الرسالة**:
```
خطأ[ب٠٢٠١]: متوقع اسم المتغير
  --> ملف.ترقيم:١:٨
   |
 ١ | متغير إذا = 5
   |        ^^^
   |
   = 'إذا' كلمة محجوزة، لا يمكن استخدامها كاسم متغير
```

## الحل

### الحل ١: إضافة اسم المتغير

```tarqeem
// ❌ خطأ
متغير = 5
ثابت = "نص"

// ✅ صحيح
متغير س = 5
ثابت رسالة = "نص"
```

### الحل ٢: اختيار اسم غير محجوز

```tarqeem
// ❌ خطأ - كلمات محجوزة
متغير إذا = 5
متغير دالة = 10
متغير صنف = "قيمة"

// ✅ صحيح - أسماء بديلة
متغير شرط = 5
متغير الدالة = 10
متغير نوع_الصنف = "قيمة"
```

### الحل ٣: تصحيح بداية الاسم

```tarqeem
// ❌ خطأ - اسم يبدأ برقم
متغير 123س = 5

// ✅ صحيح - اسم يبدأ بحرف
متغير س123 = 5
متغير _س = 5
```

## حالات شائعة

### الحالة ١: نسخ كود خاطئ

```tarqeem
// ❌ خطأ - نسخ بدون اسم
متغير  = المصدر.قيمة

// ✅ صحيح
متغير نتيجة = المصدر.قيمة
```

### الحالة ٢: خطأ مطبعي في الكلمة المفتاحية

```tarqeem
// ❌ خطأ - خطأ في 'متغير'
متغيير س = 5    // 'متغيير' ليست كلمة مفتاحية

// ✅ صحيح
متغير س = 5
```

### الحالة ٣: استخدام رمز بدلاً من اسم

```tarqeem
// ❌ خطأ
متغير @ = 5
متغير # = 10

// ✅ صحيح
متغير رمز = 5
متغير علامة = 10
```

### الحالة ٤: مسافة زائدة أو ناقصة

```tarqeem
// ❌ خطأ - لصق الاسم بالكلمة المفتاحية
متغيرس = 5

// ✅ صحيح - مسافة بين الكلمة والاسم
متغير س = 5
```

## الكلمات المحجوزة

هذه الكلمات لا يمكن استخدامها كأسماء متغيرات:

| الفئة | الكلمات |
|-------|---------|
| التعريف | متغير، ثابت، دالة، صنف، ميثاق |
| التحكم | إذا، وإلا، طالما، لكل، في، افعل |
| القيم | صحيح، خطأ، لا_شيء |
| الأصناف | عام، خاص، محمي، مشترك، منشئ، هذا، الأصل |
| الأخطاء | حاول، التقط، أخيراً، ارمِ |
| الوحدات | استورد، صدّر، من، كـ |
| أخرى | جديد، أرجع، أوقف، استمر |

## قواعد تسمية المتغيرات

| القاعدة | مثال صحيح | مثال خاطئ |
|---------|----------|----------|
| يبدأ بحرف أو _ | `اسم`، `_خاص` | `123س` |
| أحرف عربية مسموحة | `المستخدم` | - |
| شرطة سفلية مسموحة | `اسم_المستخدم` | - |
| أرقام بعد الحرف الأول | `س1`، `متغير2` | `1س` |
| لا رموز خاصة | - | `س@`، `ص#` |

## نصائح للتجنب

1. **اختر أسماء واضحة** - أسماء تصف الغرض من المتغير
2. **تجنب الكلمات المحجوزة** - راجع قائمة الكلمات أعلاه
3. **استخدم الشرطة السفلية** - لفصل الكلمات في الأسماء الطويلة
4. **ابدأ بحرف** - لا تبدأ برقم أو رمز

## ملاحظات إضافية

- اسم المتغير يجب أن يكون معرّفاً صالحاً
- ترقيم تدعم الأسماء العربية بالكامل
- الأسماء حساسة لحالة الأحرف (للأحرف اللاتينية)
