# ص٠٠٠١: صنف غير موجود

## الوصف

هذا الخطأ يحدث عندما يُشار إلى صنف غير معرّف في الكود. يمكن أن يظهر في عدة سياقات مثل:

- استخدام صنف كنوع لم يتم تعريفه
- الوراثة من صنف أب غير موجود
- إنشاء كائن من صنف غير معرف

## سبب الخطأ

ترقيم تتطلب أن يكون كل صنف مُعرّفاً قبل استخدامه. هذا يضمن أن المترجم يعرف هيكل الصنف وأعضائه قبل التعامل معه.

## مثال الخطأ

### استخدام صنف غير معرف

```tarqeem
متغير شخص: إنسان = جديد إنسان()    // ❌ خطأ: الصنف 'إنسان' غير معرف
```

**الرسالة**:
```
خطأ[ص٠٠٠١]: صنف غير موجود
  --> ملف.ترقيم:١:١٤
   |
 ١ | متغير شخص: إنسان = جديد إنسان()
   |             ^^^^^
   |
   = الصنف 'إنسان' غير معرّف
```

### الوراثة من صنف غير موجود

```tarqeem
صنف موظف يرث شخص {    // ❌ خطأ: الصنف الأب 'شخص' غير موجود
    خاص راتب: عدد
}
```

**الرسالة**:
```
خطأ[ص٠٠٠١]: صنف غير موجود
  --> ملف.ترقيم:١:١٤
   |
 ١ | صنف موظف يرث شخص {
   |              ^^^^
   |
   = الصنف الأب 'شخص' غير موجود
```

## الحل

تأكد من تعريف الصنف قبل استخدامه:

```tarqeem
// ✅ صحيح: عرّف الصنف أولاً
صنف شخص {
    عام اسم: نص
    عام عمر: عدد

    منشئ(اسم: نص، عمر: عدد) {
        هذا.اسم = اسم
        هذا.عمر = عمر
    }
}

// ✅ الآن يمكن الوراثة منه
صنف موظف يرث شخص {
    خاص راتب: عدد

    منشئ(اسم: نص، عمر: عدد، راتب: عدد) {
        الأصل(اسم، عمر)
        هذا.راتب = راتب
    }
}

// ✅ الآن يمكن إنشاء كائن منه
متغير موظف١ = جديد موظف("أحمد"، 30، 5000)
```

## حالات شائعة

### الحالة ١: خطأ إملائي في اسم الصنف

```tarqeem
صنف سيارة {
    عام لون: نص
}

// ❌ خطأ إملائي
متغير س: سياره = جديد سياره()

// ✅ الصحيح
متغير س: سيارة = جديد سيارة()
```

### الحالة ٢: نسيان استيراد الصنف

```tarqeem
// ❌ خطأ: الصنف موجود في وحدة أخرى لكن لم يتم استيراده
متغير قائمة: قائمة<عدد> = جديد قائمة<عدد>()

// ✅ الصحيح: استورد الصنف أولاً
استورد { قائمة } من "مجموعات"
متغير قائمة: قائمة<عدد> = جديد قائمة<عدد>()
```

### الحالة ٣: ترتيب التعريفات

```tarqeem
// ❌ خطأ: استخدام الصنف قبل تعريفه في نفس الملف
صنف أ يرث ب { }    // ب غير معرف بعد

صنف ب { }

// ✅ الصحيح: عرّف الصنف الأب أولاً
صنف ب { }

صنف أ يرث ب { }
```

## ملاحظات إضافية

- تأكد من صحة الإملاء (الهمزات والتشكيل)
- تحقق من أن الصنف مُصدَّر من الوحدة المصدر
- تأكد من ترتيب التعريفات في الملف
