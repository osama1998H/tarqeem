# ص٠٦٠٢: إعادة تعريف صنف الاستثناء الأساسي

## الوصف

هذا الخطأ يحدث عند تعريف صنف باسم `استثناء`. الاسم محجوز: الصنف معرَّف تلقائياً في كل برنامج، ولا حاجة لاستيراده ولا لإعادة كتابته.

## سبب الخطأ

`استثناء` هو الأصل الذي تقيس عليه `ارمِ` ما يصح رميه، والنمط الذي يأخذه معامل `التقط`. لو سُمح بتعريف صنف آخر بنفس الاسم لحلّ محلّه بصمت، فتصير الأصناف التي ورّثت الصنف الأصلي غير قابلة للرمي، ويصير `خ.رسالة` مرتبطاً بحقل قد لا يكون موجوداً أصلاً — وكل ذلك بلا رسالة خطأ واحدة.

منع التعريف يحوّل هذا التعارض الصامت إلى خطأ ترجمة واضح.

## مثال الخطأ

```tarqeem
بسم_الله
صنف استثناء {              // ❌ الاسم محجوز
    عام رسالة: نص
    منشئ(رسالة: نص) {
        هذا.رسالة = رسالة
    }
}
الحمد_لله
```

## الحل

### الحل ١: احذف التعريف واستعمل الصنف مباشرة

```tarqeem
بسم_الله
حاول {
    ارمِ جديد استثناء("حدث خطأ")    // ✅ 'استثناء' متاح بلا تعريف ولا استيراد
} التقط (خ) {
    اطبع(خ.رسالة)
}
الحمد_لله
```

### الحل ٢: ورِّثه باسم يصف حالتك

```tarqeem
بسم_الله
صنف استثناء_تحقق يرث استثناء {    // ✅ صحيح
    منشئ(الحقل: نص، رسالة: نص) {
        الأصل(الحقل + ": " + رسالة)
    }
}
الحمد_لله
```

> **قيد حالي**: معامل `التقط` نمطه دائماً `استثناء` (الصنف الأساسي)، فلا يمكن
> قراءة الحقول الإضافية التي يعرّفها الصنف الفرعي من داخل كتلة `التقط` — لذلك
> يمرّر المثال أعلاه المعلومة داخل `رسالة` بدلاً من حقل خاص. تضييق نمط المعامل
> إلى الصنف المرمي فعلياً ميزة مخطط لها.

## ما يوفّره الصنف الأساسي

```tarqeem
صنف استثناء {
    عام رسالة: نص

    منشئ(رسالة: نص) {
        هذا.رسالة = رسالة
    }
}
```

> **قيد حالي**: مواصفات اللغة (§١١.١) تذكر منشئاً ثانياً يأخذ رسالتين (`رسالة` و`رسالة_عربية`). ترقيم لا تدعم تعدد المنشئات بعد، فالمتاح حالياً هو المنشئ ذو المعامل الواحد.
