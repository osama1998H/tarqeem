# ص٠٤٠٢: الوصول لعضو محمي

## الوصف

هذا الخطأ يحدث عندما تحاول الوصول إلى عضو (خاصية أو دالة) مُعرّف بمحدد الوصول `محمي` من خارج الصنف الذي يحتويه أو أصنافه الأبناء.

## سبب الخطأ

الأعضاء المحمية (`محمي`) مصممة لتكون متاحة فقط:
1. داخل الصنف نفسه
2. داخل الأصناف التي ترث منه (الأبناء)

الوصول من أي مكان آخر (كود خارجي، أصناف غير وارثة) غير مسموح به.

## مثال الخطأ

### الوصول لخاصية محمية من خارج التسلسل الهرمي

```tarqeem
صنف كائن_حي {
    محمي عمر: عدد
    عام اسم: نص

    منشئ(اسم: نص) {
        هذا.اسم = اسم
        هذا.عمر = 0
    }
}

متغير كائن = جديد كائن_حي("نبات")
اطبع(كائن.عمر)    // ❌ خطأ: 'عمر' عضو محمي
```

**الرسالة**:
```
خطأ[ص٠٤٠٢]: الوصول لعضو محمي
  --> ملف.ترقيم:١٢:٧
   |
١٢ | اطبع(كائن.عمر)
   |       ^^^^^^^^^
   |
   = لا يمكن الوصول للعضو المحمي 'عمر' من خارج الصنف 'كائن_حي' أو أصنافه الأبناء
```

### استدعاء دالة محمية من خارج التسلسل الهرمي

```tarqeem
صنف آلة {
    محمي دالة صيانة_داخلية() {
        اطبع("جاري الصيانة...")
    }

    عام دالة تشغيل() {
        هذا.صيانة_داخلية()
        اطبع("تم التشغيل")
    }
}

متغير آ = جديد آلة()
آ.صيانة_داخلية()    // ❌ خطأ: دالة محمية
```

## الحل

### الحل ١: استخدم دالة عامة للوصول

```tarqeem
صنف كائن_حي {
    محمي عمر: عدد
    عام اسم: نص

    منشئ(اسم: نص) {
        هذا.اسم = اسم
        هذا.عمر = 0
    }

    // ✅ دالة عامة للقراءة
    عام دالة احصل_عمر() -> عدد {
        أرجع هذا.عمر
    }
}

متغير كائن = جديد كائن_حي("نبات")
اطبع(كائن.احصل_عمر())    // ✅ يعمل
```

### الحل ٢: الوصول من صنف ابن

```tarqeem
صنف كائن_حي {
    محمي عمر: عدد = 0
}

صنف حيوان يرث كائن_حي {
    عام دالة تقدم_بالعمر() {
        هذا.عمر = هذا.عمر + 1    // ✅ يمكن الوصول: نحن في صنف ابن
    }

    عام دالة اعرض_العمر() -> عدد {
        أرجع هذا.عمر    // ✅ يعمل
    }
}

متغير ح = جديد حيوان()
ح.تقدم_بالعمر()
اطبع(ح.اعرض_العمر())    // ✅ يطبع: 1
```

## حالات شائعة

### الحالة ١: الفرق بين خاص ومحمي

```tarqeem
صنف أ {
    خاص سري: نص = "سري جداً"
    محمي داخلي: نص = "للأبناء فقط"
    عام عام: نص = "للجميع"
}

صنف ب يرث أ {
    عام دالة اختبار() {
        // اطبع(هذا.سري)      // ❌ لا يمكن: خاص
        اطبع(هذا.داخلي)       // ✅ يمكن: محمي
        اطبع(هذا.عام)         // ✅ يمكن: عام
    }
}
```

### الحالة ٢: الوراثة متعددة المستويات

```tarqeem
صنف جد {
    محمي قيمة: عدد = 100
}

صنف أب يرث جد {
    عام دالة من_الأب() -> عدد {
        أرجع هذا.قيمة    // ✅ يعمل
    }
}

صنف ابن يرث أب {
    عام دالة من_الابن() -> عدد {
        أرجع هذا.قيمة    // ✅ يعمل أيضاً: المحمي يُورث
    }
}
```

### الحالة ٣: الوصول عبر كائن آخر من نفس الصنف

```tarqeem
صنف نقطة {
    محمي س: عدد
    محمي ص: عدد

    منشئ(س: عدد، ص: عدد) {
        هذا.س = س
        هذا.ص = ص
    }

    عام دالة المسافة_إلى(أخرى: نقطة) -> عدد_عشري {
        // ✅ يمكن الوصول لأعضاء كائن آخر من نفس الصنف
        متغير فرق_س = هذا.س - أخرى.س
        متغير فرق_ص = هذا.ص - أخرى.ص
        أرجع جذر(فرق_س * فرق_س + فرق_ص * فرق_ص)
    }
}
```

## ملاحظات إضافية

- `خاص`: الصنف نفسه فقط
- `محمي`: الصنف + أصنافه الأبناء
- `عام`: الجميع
- المحمي مفيد لمشاركة التفاصيل مع الأصناف الفرعية دون كشفها للعالم الخارجي
- استخدم المحمي عندما تريد السماح للأصناف الفرعية بالتخصيص
