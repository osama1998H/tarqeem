# ص٠٥٠١: الوصول لعضو غير مشترك عبر اسم الصنف

## الوصف

هذا الخطأ يحدث عندما تحاول الوصول إلى عضو (حقل أو دالة أو خاصية) **غير** معرَّف بالكلمة المفتاحية `مشترك`، باستخدام اسم الصنف مباشرة بدلاً من نسخة منه.

## سبب الخطأ

الأعضاء العادية (غير المشتركة) تنتمي إلى كل نسخة على حدة، ولا توجد نسخة واحدة مشتركة يمكن الوصول إليها عبر اسم الصنف. فقط الأعضاء المعرَّفة بـ `مشترك` (انظر [LANGUAGE_SPEC.md §٩.٥](../../../LANGUAGE_SPEC.md)) تُخزَّن مرة واحدة لكل الصنف وتُتاح عبر `اسم_الصنف.عضو`.

## مثال الخطأ

```tarqeem
صنف شخص {
    عام اسم: نص

    منشئ(اسم: نص) {
        هذا.اسم = اسم
    }
}

اطبع(شخص.اسم)    // ❌ خطأ: 'اسم' ليس عضواً مشتركاً
```

**الرسالة**:
```
خطأ[ص٠٥٠١]: لا يمكن الوصول للعضو 'اسم' عبر اسم الصنف؛ العضو ليس مشتركاً (مشترك)
  --> ملف.ترقيم:٨:١٢
```

## الحل

الوصول للأعضاء غير المشتركة يجب أن يكون عبر نسخة من الصنف:

```tarqeem
متغير ش = جديد شخص("أحمد")
اطبع(ش.اسم)    // ✅ صحيح
```

أو، إن كان القصد فعلاً عضواً مشتركاً بين كل النسخ، أضف `مشترك` لتعريفه:

```tarqeem
صنف عدادات {
    مشترك المجموع: عدد = 0
}

اطبع(عدادات.المجموع)    // ✅ صحيح: المجموع مشترك
```
