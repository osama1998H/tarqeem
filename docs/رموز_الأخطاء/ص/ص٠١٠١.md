# ص٠١٠١: وراثة دائرية

## الوصف

هذا الخطأ يحدث عندما يكون هناك سلسلة وراثة دائرية بين الأصناف، حيث يرث صنف من نفسه بشكل مباشر أو غير مباشر.

## سبب الخطأ

الوراثة الدائرية تخلق تبعية غير قابلة للحل:
- إذا كان أ يرث من ب، وب يرث من أ، فلا يمكن تحديد أيهما يُبنى أولاً
- هذا يمنع المترجم من تحديد هيكل الصنف بشكل صحيح

## مثال الخطأ

### وراثة دائرية مباشرة

```tarqeem
صنف أ يرث ب { }    // ❌ خطأ: ب يرث من أ أيضاً
صنف ب يرث أ { }
```

**الرسالة**:
```
خطأ[ص٠١٠١]: وراثة دائرية
  --> ملف.ترقيم:١:١
   |
 ١ | صنف أ يرث ب { }
   | ^^^^^^^^^^^^^^^
   |
   = وراثة دائرية مكتشفة للصنف 'أ'
   = سلسلة الوراثة: أ -> ب -> أ
```

### وراثة دائرية غير مباشرة

```tarqeem
صنف أ يرث ب { }
صنف ب يرث ج { }
صنف ج يرث أ { }    // ❌ خطأ: سلسلة دائرية أ -> ب -> ج -> أ
```

**الرسالة**:
```
خطأ[ص٠١٠١]: وراثة دائرية
  --> ملف.ترقيم:٣:١
   |
 ٣ | صنف ج يرث أ { }
   | ^^^^^^^^^^^^^^^
   |
   = وراثة دائرية مكتشفة للصنف 'ج'
   = سلسلة الوراثة: ج -> أ -> ب -> ج
```

## الحل

أعد تصميم هيكل الأصناف لإزالة الدائرية:

### الحل ١: استخدام المواثيق

```tarqeem
// ✅ استخدم ميثاقاً مشتركاً بدلاً من الوراثة الدائرية
ميثاق قابل_للعرض {
    دالة اعرض()
}

صنف أ يلتزم قابل_للعرض {
    عام دالة اعرض() {
        اطبع("أ")
    }
}

صنف ب يلتزم قابل_للعرض {
    عام دالة اعرض() {
        اطبع("ب")
    }
}
```

### الحل ٢: إعادة هيكلة التسلسل الهرمي

```tarqeem
// ✅ صنف أساسي مشترك
صنف أساس {
    // الوظائف المشتركة
}

صنف أ يرث أساس {
    // خصائص أ
}

صنف ب يرث أساس {
    // خصائص ب
}
```

### الحل ٣: استخدام التركيب بدلاً من الوراثة

```tarqeem
// ✅ التركيب (Composition) بدلاً من الوراثة
صنف أ {
    خاص مساعد: ب

    منشئ() {
        هذا.مساعد = جديد ب()
    }
}

صنف ب {
    // لا يرث من أ
}
```

## حالات شائعة

### الحالة ١: وراثة ذاتية

```tarqeem
// ❌ خطأ: صنف يرث من نفسه
صنف س يرث س { }

// ✅ الصحيح: أزل الوراثة الذاتية
صنف س { }
```

### الحالة ٢: تصميم معقد

```tarqeem
// ❌ تصميم خاطئ مع وراثة دائرية
صنف مدير يرث موظف { }
صنف موظف يرث مدير { }    // المدير موظف، لكن الموظف ليس مديراً!

// ✅ تصميم صحيح
صنف موظف {
    عام اسم: نص
}

صنف مدير يرث موظف {
    عام فريق: مصفوفة<موظف>
}
```

## ملاحظات إضافية

- الوراثة الدائرية دائماً خطأ في التصميم
- فكر في استخدام المواثيق أو التركيب كبدائل
- ارسم شجرة الوراثة للتأكد من عدم وجود دوائر
