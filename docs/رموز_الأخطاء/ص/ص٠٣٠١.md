# ص٠٣٠١: خاصية غير موجودة

## الوصف

هذا الخطأ يحدث عندما تحاول الوصول إلى خاصية (حقل) غير موجودة في صنف معين.

## سبب الخطأ

عند محاولة قراءة أو كتابة خاصية من كائن، يتحقق المترجم من وجود هذه الخاصية في تعريف الصنف. إذا لم تكن موجودة، يُصدر هذا الخطأ.

## مثال الخطأ

### قراءة خاصية غير موجودة

```tarqeem
صنف شخص {
    عام اسم: نص
    عام عمر: عدد
}

متغير ش = جديد شخص()
ش.اسم = "أحمد"
اطبع(ش.راتب)    // ❌ خطأ: 'راتب' غير موجودة في 'شخص'
```

**الرسالة**:
```
خطأ[ص٠٣٠١]: خاصية غير موجودة
  --> ملف.ترقيم:٨:٧
   |
 ٨ | اطبع(ش.راتب)
   |       ^^^^^^
   |
   = الخاصية 'راتب' غير موجودة في الصنف 'شخص'
```

### كتابة لخاصية غير موجودة

```tarqeem
صنف نقطة {
    عام س: عدد
    عام ص: عدد
}

متغير ن = جديد نقطة()
ن.ع = 10    // ❌ خطأ: 'ع' غير موجودة في 'نقطة'
```

## الحل

تأكد من أن الخاصية معرّفة في الصنف:

```tarqeem
// ✅ صحيح: استخدم خاصية موجودة
صنف شخص {
    عام اسم: نص
    عام عمر: عدد
    عام راتب: عدد    // أضف الخاصية إذا كنت تحتاجها
}

متغير ش = جديد شخص()
ش.اسم = "أحمد"
ش.راتب = 5000    // ✅ الآن يعمل
اطبع(ش.راتب)
```

## حالات شائعة

### الحالة ١: خطأ إملائي

```tarqeem
صنف سيارة {
    عام اللون: نص
    عام السرعة: عدد
}

متغير س = جديد سيارة()

// ❌ خطأ إملائي
اطبع(س.لون)        // يجب أن يكون 'اللون'
اطبع(س.السرعه)     // يجب أن يكون 'السرعة'

// ✅ الصحيح
اطبع(س.اللون)
اطبع(س.السرعة)
```

### الحالة ٢: الخلط بين صنف أب وصنف ابن

```tarqeem
صنف حيوان {
    عام اسم: نص
}

صنف طائر يرث حيوان {
    عام يطير: منطقي
}

متغير ح: حيوان = جديد طائر()
اطبع(ح.يطير)    // ❌ خطأ: 'يطير' غير موجودة في 'حيوان'

// ✅ الصحيح: استخدم النوع الصحيح
متغير ط: طائر = جديد طائر()
اطبع(ط.يطير)
```

### الحالة ٣: خاصية من ميثاق

```tarqeem
ميثاق قابل_للتسمية {
    // المواثيق تعرف دوال، لا خصائص
}

صنف عنصر يلتزم قابل_للتسمية {
    خاص _اسم: نص
}

// ❌ لا يمكن الوصول للخاصية عبر نوع الميثاق
متغير ع: قابل_للتسمية = جديد عنصر()
اطبع(ع._اسم)    // خطأ
```

### الحالة ٤: خاصية خاصة

```tarqeem
صنف حساب {
    خاص رصيد: عدد    // خاصة
    عام رقم: نص
}

متغير ح = جديد حساب()
اطبع(ح.رصيد)    // ❌ قد يظهر كـ "غير موجودة" أو "خاصة"

// ✅ استخدم دالة للوصول
صنف حساب {
    خاص رصيد: عدد

    عام دالة احصل_رصيد() -> عدد {
        أرجع هذا.رصيد
    }
}
```

## ملاحظات إضافية

- تحقق من الإملاء الصحيح (الهمزات، التشكيل، ال التعريف)
- تأكد من أنك تستخدم النوع الصحيح للمتغير
- الخصائص الخاصة لا يمكن الوصول إليها من خارج الصنف
- استخدم IDE مع دعم الإكمال التلقائي لتجنب الأخطاء الإملائية
