# ص٠٥٠٢: الوصول لعضو مشترك عبر نسخة

## الوصف

هذا الخطأ يحدث عندما تحاول الوصول إلى عضو (حقل أو دالة أو خاصية) معرَّف بالكلمة المفتاحية `مشترك` عبر نسخة من الصنف بدلاً من اسم الصنف نفسه.

## سبب الخطأ

الأعضاء المشتركة (`مشترك`) تخص الصنف بأكمله وليست جزءاً من أي نسخة بعينها. الوصول إليها عبر نسخة يوحي خطأً بأن لكل نسخة قيمتها الخاصة، بينما القيمة في الواقع مشتركة بين كل النسخ (انظر [LANGUAGE_SPEC.md §٩.٥](../../../LANGUAGE_SPEC.md)).

## مثال الخطأ

```tarqeem
صنف عدادات {
    مشترك المجموع: عدد = 0
    منشئ() {}
}

متغير ع = جديد عدادات()
اطبع(ع.المجموع)    // ❌ خطأ: 'المجموع' عضو مشترك
```

**الرسالة**:
```
خطأ[ص٠٥٠٢]: العضو 'المجموع' مشترك؛ يُستخدم عبر اسم الصنف مباشرة
  --> ملف.ترقيم:٧:١٠
```

## الحل

الوصول للأعضاء المشتركة يكون عبر اسم الصنف مباشرة:

```tarqeem
اطبع(عدادات.المجموع)    // ✅ صحيح
```
