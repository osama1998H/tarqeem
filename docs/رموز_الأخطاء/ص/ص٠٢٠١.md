# ص٠٢٠١: ميثاق غير منفذ

## الوصف

هذا الخطأ يحدث عندما يُعلن صنف التزامه بميثاق (Interface) لكنه لا يُنفذ جميع الدوال المطلوبة في ذلك الميثاق.

## سبب الخطأ

عندما يُعلن صنف `يلتزم ميثاق`، فإنه يعد بتوفير تنفيذ لجميع الدوال المُعرّفة في الميثاق. إذا لم يفِ بهذا الوعد، يُصدر المترجم هذا الخطأ.

## مثال الخطأ

### دالة مفقودة

```tarqeem
ميثاق قابل_للطباعة {
    دالة اطبع()
    دالة صيغة() -> نص
}

صنف كتاب يلتزم قابل_للطباعة {    // ❌ خطأ: لم تُنفذ 'صيغة'
    عام دالة اطبع() {
        اطبع("كتاب")
    }
    // صيغة() مفقودة!
}
```

**الرسالة**:
```
خطأ[ص٠٢٠١]: ميثاق غير منفذ
  --> ملف.ترقيم:٦:١
   |
 ٦ | صنف كتاب يلتزم قابل_للطباعة {
   | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
   |
   = الصنف 'كتاب' لا يُنفذ الدالة 'صيغة' من الميثاق 'قابل_للطباعة'
```

### عدد معاملات خاطئ

```tarqeem
ميثاق حاسب {
    دالة احسب(أ: عدد، ب: عدد) -> عدد
}

صنف آلة يلتزم حاسب {
    عام دالة احسب(أ: عدد) -> عدد {    // ❌ خطأ: معامل مفقود
        أرجع أ * 2
    }
}
```

**الرسالة**:
```
خطأ[ص٠٢٠١]: ميثاق غير منفذ
  --> ملف.ترقيم:٦:٥
   |
 ٦ |     عام دالة احسب(أ: عدد) -> عدد {
   |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^
   |
   = الدالة 'احسب' في الصنف 'آلة' لديها عدد خاطئ من المعاملات
   = متوقع: ٢، وُجد: ١
```

### نوع إرجاع خاطئ

```tarqeem
ميثاق محول {
    دالة حول() -> نص
}

صنف رقم يلتزم محول {
    عام دالة حول() -> عدد {    // ❌ خطأ: نوع الإرجاع خاطئ
        أرجع 42
    }
}
```

## الحل

تأكد من تنفيذ جميع دوال الميثاق بالتوقيع الصحيح:

```tarqeem
ميثاق قابل_للطباعة {
    دالة اطبع()
    دالة صيغة() -> نص
}

// ✅ صحيح: جميع الدوال منفذة
صنف كتاب يلتزم قابل_للطباعة {
    خاص عنوان: نص

    منشئ(عنوان: نص) {
        هذا.عنوان = عنوان
    }

    عام دالة اطبع() {
        اطبع(هذا.صيغة())
    }

    عام دالة صيغة() -> نص {
        أرجع "كتاب: " + هذا.عنوان
    }
}
```

## حالات شائعة

### الحالة ١: التزام بعدة مواثيق

```tarqeem
ميثاق أ {
    دالة دالة_أ()
}

ميثاق ب {
    دالة دالة_ب()
}

// ❌ خطأ: يجب تنفيذ دوال كلا الميثاقين
صنف س يلتزم أ، ب {
    عام دالة دالة_أ() { }
    // دالة_ب() مفقودة!
}

// ✅ الصحيح
صنف س يلتزم أ، ب {
    عام دالة دالة_أ() { }
    عام دالة دالة_ب() { }
}
```

### الحالة ٢: توقيع دالة غير مطابق

```tarqeem
ميثاق مقارن {
    دالة قارن(آخر: أي) -> عدد
}

// ❌ خطأ: نوع المعامل مختلف
صنف رقم يلتزم مقارن {
    عام دالة قارن(آخر: رقم) -> عدد {    // يجب أن يكون 'أي'
        أرجع 0
    }
}

// ✅ الصحيح
صنف رقم يلتزم مقارن {
    عام دالة قارن(آخر: أي) -> عدد {
        أرجع 0
    }
}
```

### الحالة ٣: الرؤية

```tarqeem
ميثاق عام_الدوال {
    دالة نفذ()
}

// ❌ خطأ: الدالة يجب أن تكون عامة
صنف س يلتزم عام_الدوال {
    خاص دالة نفذ() { }    // خاصة، لكن الميثاق يتطلب عامة
}

// ✅ الصحيح
صنف س يلتزم عام_الدوال {
    عام دالة نفذ() { }
}
```

## ملاحظات إضافية

- تأكد من تطابق اسم الدالة تماماً (بما في ذلك الهمزات)
- تأكد من تطابق عدد المعاملات وأنواعها
- تأكد من تطابق نوع الإرجاع
- دوال الميثاق يجب أن تكون عامة في الصنف المنفذ
