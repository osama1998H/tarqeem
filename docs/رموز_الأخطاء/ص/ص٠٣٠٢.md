# ص٠٣٠٢: دالة غير موجودة في الصنف

## الوصف

هذا الخطأ يحدث عندما تحاول استدعاء دالة (method) غير معرّفة في صنف معين أو أي من أصنافه الأب.

## سبب الخطأ

عند استدعاء دالة على كائن، يبحث المترجم عن الدالة في:
1. الصنف نفسه
2. الأصناف الأب (عبر سلسلة الوراثة)
3. المواثيق المُلتزم بها

إذا لم يجد الدالة في أي منها، يُصدر هذا الخطأ.

## مثال الخطأ

### استدعاء دالة غير موجودة

```tarqeem
صنف حاسبة {
    عام دالة جمع(أ: عدد، ب: عدد) -> عدد {
        أرجع أ + ب
    }
}

متغير ح = جديد حاسبة()
متغير نتيجة = ح.ضرب(5، 3)    // ❌ خطأ: 'ضرب' غير موجودة
```

**الرسالة**:
```
خطأ[ص٠٣٠٢]: دالة غير موجودة في الصنف
  --> ملف.ترقيم:٨:١٨
   |
 ٨ | متغير نتيجة = ح.ضرب(5، 3)
   |                  ^^^^
   |
   = الدالة 'ضرب' غير موجودة في النوع 'حاسبة'
```

### استدعاء دالة الأصل غير الموجودة

```tarqeem
صنف أ {
    عام دالة تحية() {
        اطبع("مرحباً")
    }
}

صنف ب يرث أ {
    عام دالة تحية() {
        الأصل.وداع()    // ❌ خطأ: 'وداع' غير موجودة في الصنف الأب
    }
}
```

## الحل

تأكد من وجود الدالة في الصنف:

```tarqeem
// ✅ صحيح: أضف الدالة المطلوبة
صنف حاسبة {
    عام دالة جمع(أ: عدد، ب: عدد) -> عدد {
        أرجع أ + ب
    }

    عام دالة ضرب(أ: عدد، ب: عدد) -> عدد {
        أرجع أ * ب
    }
}

متغير ح = جديد حاسبة()
متغير نتيجة = ح.ضرب(5، 3)    // ✅ يعمل الآن
```

## حالات شائعة

### الحالة ١: خطأ إملائي في اسم الدالة

```tarqeem
صنف نص_مساعد {
    عام دالة أحرف_كبيرة() -> نص {
        // ...
    }
}

متغير م = جديد نص_مساعد()

// ❌ خطأ إملائي
م.احرف_كبيرة()    // بدون همزة

// ✅ الصحيح
م.أحرف_كبيرة()    // مع همزة
```

### الحالة ٢: الخلط بين الدالة والخاصية

```tarqeem
صنف مستطيل {
    عام عرض: عدد
    عام ارتفاع: عدد

    عام دالة المساحة() -> عدد {
        أرجع هذا.عرض * هذا.ارتفاع
    }
}

متغير م = جديد مستطيل()

// ❌ خطأ: المساحة دالة وليست خاصية
اطبع(م.المساحة)

// ✅ الصحيح: استدعِ الدالة
اطبع(م.المساحة())
```

### الحالة ٣: الدالة في صنف ابن وليس الأب

```tarqeem
صنف شكل {
    عام دالة ارسم() { }
}

صنف دائرة يرث شكل {
    عام دالة نصف_القطر() -> عدد {
        أرجع 10
    }
}

متغير ش: شكل = جديد دائرة()
ش.نصف_القطر()    // ❌ خطأ: 'نصف_القطر' غير موجودة في 'شكل'

// ✅ الصحيح: استخدم النوع المناسب
متغير د: دائرة = جديد دائرة()
د.نصف_القطر()    // يعمل
```

### الحالة ٤: دالة مشتركة (static)

```tarqeem
صنف رياضيات {
    مشترك دالة جذر(س: عدد_عشري) -> عدد_عشري {
        // ...
    }
}

متغير ر = جديد رياضيات()
ر.جذر(16.0)    // ❌ قد لا يعمل: الدالة مشتركة

// ✅ الصحيح: استدعِ على الصنف مباشرة
رياضيات.جذر(16.0)
```

### الحالة ٥: دالة خاصة

```tarqeem
صنف معالج {
    خاص دالة معالجة_داخلية() {
        // ...
    }

    عام دالة نفذ() {
        هذا.معالجة_داخلية()
    }
}

متغير م = جديد معالج()
م.معالجة_داخلية()    // ❌ قد يظهر كـ "غير موجودة" أو "خاصة"

// ✅ الصحيح: استخدم الدالة العامة
م.نفذ()
```

## ملاحظات إضافية

- تحقق من الإملاء الصحيح (الهمزات والتشكيل)
- تأكد من أنك تستدعي دالة وليس خاصية (أضف الأقواس)
- تأكد من أن نوع المتغير يحتوي الدالة
- الدوال الخاصة لا يمكن استدعاؤها من خارج الصنف
- الدوال المشتركة تُستدعى على الصنف لا على الكائن
