# ص٠٤٠١: الوصول لعضو خاص

## الوصف

هذا الخطأ يحدث عندما تحاول الوصول إلى عضو (خاصية أو دالة) مُعرّف بمحدد الوصول `خاص` من خارج الصنف الذي يحتويه.

## سبب الخطأ

الأعضاء الخاصة (`خاص`) مصممة لتكون متاحة فقط داخل الصنف نفسه. هذا جزء من مبدأ التغليف (Encapsulation) الذي يحمي البيانات الداخلية من الوصول غير المصرح به.

## مثال الخطأ

### الوصول لخاصية خاصة

```tarqeem
صنف حساب_بنكي {
    خاص رصيد: عدد
    عام رقم_الحساب: نص

    منشئ(رصيد_ابتدائي: عدد) {
        هذا.رصيد = رصيد_ابتدائي
    }
}

متغير حساب = جديد حساب_بنكي(1000)
اطبع(حساب.رصيد)    // ❌ خطأ: 'رصيد' عضو خاص
```

**الرسالة**:
```
خطأ[ص٠٤٠١]: الوصول لعضو خاص
  --> ملف.ترقيم:١١:٧
   |
١١ | اطبع(حساب.رصيد)
   |       ^^^^^^^^^^
   |
   = لا يمكن الوصول للعضو الخاص 'رصيد' من خارج الصنف 'حساب_بنكي'
```

### استدعاء دالة خاصة

```tarqeem
صنف معالج_بيانات {
    خاص دالة تحقق_داخلي() -> منطقي {
        أرجع صحيح
    }

    عام دالة معالجة() {
        إذا (هذا.تحقق_داخلي()) {
            // ...
        }
    }
}

متغير م = جديد معالج_بيانات()
م.تحقق_داخلي()    // ❌ خطأ: دالة خاصة
```

### تجاوز دالة خاصة بشكل خاطئ

```tarqeem
صنف أ {
    عام دالة نفذ() {
        اطبع("أ")
    }
}

صنف ب يرث أ {
    خاص دالة نفذ() {    // ❌ خطأ: لا يمكن تجاوز دالة عامة بخاصة
        اطبع("ب")
    }
}
```

## الحل

استخدم دوال الوصول (Getters/Setters) للوصول للبيانات الخاصة:

```tarqeem
صنف حساب_بنكي {
    خاص رصيد: عدد
    عام رقم_الحساب: نص

    منشئ(رصيد_ابتدائي: عدد) {
        هذا.رصيد = رصيد_ابتدائي
    }

    // ✅ دالة عامة للقراءة
    عام دالة احصل_رصيد() -> عدد {
        أرجع هذا.رصيد
    }

    // ✅ دالة عامة للتعديل مع تحقق
    عام دالة أودع(مبلغ: عدد) {
        إذا (مبلغ > 0) {
            هذا.رصيد = هذا.رصيد + مبلغ
        }
    }

    عام دالة اسحب(مبلغ: عدد) -> منطقي {
        إذا (مبلغ > 0 و هذا.رصيد >= مبلغ) {
            هذا.رصيد = هذا.رصيد - مبلغ
            أرجع صحيح
        }
        أرجع خطأ
    }
}

متغير حساب = جديد حساب_بنكي(1000)
اطبع(حساب.احصل_رصيد())    // ✅ يعمل: 1000
حساب.أودع(500)
اطبع(حساب.احصل_رصيد())    // ✅ يعمل: 1500
```

## حالات شائعة

### الحالة ١: استخدام خاصية (Property) بدلاً من حقل خاص

```tarqeem
صنف شخص {
    خاص _عمر: عدد

    // ✅ استخدم خاصية للوصول المحكوم
    خاصية عمر: عدد {
        احصل {
            أرجع هذا._عمر
        }
        عيّن(قيمة) {
            إذا (قيمة >= 0) {
                هذا._عمر = قيمة
            }
        }
    }
}

متغير ش = جديد شخص()
ش.عمر = 25         // ✅ يستخدم عيّن
اطبع(ش.عمر)       // ✅ يستخدم احصل
```

### الحالة ٢: الوصول من صنف ابن

```tarqeem
صنف أ {
    خاص سر: نص = "سري"
    محمي معلومة: نص = "محمية"
}

صنف ب يرث أ {
    عام دالة اعرض() {
        // اطبع(هذا.سر)        // ❌ خطأ: لا يمكن الوصول لعضو خاص
        اطبع(هذا.معلومة)      // ✅ يمكن الوصول للعضو المحمي
    }
}
```

### الحالة ٣: الوصول في نفس الملف لكن خارج الصنف

```tarqeem
صنف بيانات {
    خاص قيمة: عدد = 42
}

// حتى في نفس الملف، لا يمكن الوصول
متغير ب = جديد بيانات()
// اطبع(ب.قيمة)    // ❌ خطأ: الخاص يعني داخل الصنف فقط
```

## ملاحظات إضافية

- `خاص`: متاح فقط داخل الصنف نفسه
- `محمي`: متاح داخل الصنف وأصنافه الأبناء
- `عام`: متاح من أي مكان
- استخدم التغليف لحماية حالة الكائن الداخلية
- قدّم واجهة عامة واضحة عبر دوال الوصول
