# و٠٠٠٢: عنصر غير مُصدَّر

## الوصف

هذا الخطأ يحدث عند محاولة استيراد عنصر (دالة، صنف، متغير) من وحدة، لكن هذا العنصر غير مُصدَّر من تلك الوحدة.

في ترقيم، يجب تصدير العناصر صراحة باستخدام `صدّر` لتكون متاحة للاستيراد من وحدات أخرى.

## سبب الخطأ

الأسباب الشائعة:

1. **نسيان تصدير العنصر**: العنصر معرّف لكن غير مُصدَّر
2. **خطأ في اسم العنصر**: الاسم المستورد مختلف عن الاسم المُصدَّر
3. **تصدير خاص**: العنصر خاص بالوحدة ولا يُراد تصديره

## مثال الخطأ

**ملف: رياضيات.ترقيم**
```tarqeem
بسم_الله

// هذه الدالة مُصدَّرة
صدّر دالة جمع(أ: عدد، ب: عدد) -> عدد {
    أرجع أ + ب
}

// هذه الدالة غير مُصدَّرة (خاصة بالوحدة)
دالة ضرب(أ: عدد، ب: عدد) -> عدد {
    أرجع أ * ب
}

الحمد_لله
```

**ملف: رئيسي.ترقيم**
```tarqeem
بسم_الله

// محاولة استيراد دالة غير مُصدَّرة
استورد { جمع، ضرب } من "./رياضيات"

الحمد_لله
```

**الرسالة**:
```
خطأ[و٠٠٠٢]: العنصر 'ضرب' غير مُصدَّر من الوحدة './رياضيات'
  --> رئيسي.ترقيم:4:15
  |
4 | استورد { جمع، ضرب } من "./رياضيات"
  |               ^^^
  |
  = العنصر موجود لكنه غير مُصدَّر
  = أضف 'صدّر' قبل تعريف العنصر في الوحدة المصدر
```

## الحل

### الحل ١: تصدير العنصر المطلوب

أضف `صدّر` قبل تعريف العنصر في الوحدة المصدر:

```tarqeem
بسم_الله

صدّر دالة جمع(أ: عدد، ب: عدد) -> عدد {
    أرجع أ + ب
}

// ✅ أصبحت مُصدَّرة الآن
صدّر دالة ضرب(أ: عدد، ب: عدد) -> عدد {
    أرجع أ * ب
}

الحمد_لله
```

### الحل ٢: التحقق من اسم العنصر

تأكد من تطابق الاسم المستورد مع الاسم المُصدَّر:

```tarqeem
// في الوحدة المصدر
صدّر دالة احسب_المجموع(أ: عدد، ب: عدد) -> عدد { ... }

// ❌ خطأ: اسم مختلف
استورد { جمع } من "./رياضيات"

// ✅ صحيح: نفس الاسم
استورد { احسب_المجموع } من "./رياضيات"

// ✅ صحيح: استخدام اسم مستعار
استورد { احسب_المجموع كـ جمع } من "./رياضيات"
```

### الحل ٣: استيراد الكل

إذا كنت غير متأكد من الأسماء، استورد كل شيء:

```tarqeem
// استيراد كل العناصر المُصدَّرة
استورد * كـ رياضيات من "./رياضيات"

// استخدام
متغير نتيجة = رياضيات.جمع(5، 3)
```

## أنواع العناصر القابلة للتصدير

```tarqeem
// تصدير دالة
صدّر دالة اسم_الدالة() { ... }

// تصدير صنف
صدّر صنف اسم_الصنف { ... }

// تصدير ميثاق
صدّر ميثاق اسم_الميثاق { ... }

// تصدير ثابت
صدّر ثابت اسم_الثابت = قيمة

// تصدير متغير (غير شائع)
صدّر متغير اسم_المتغير = قيمة
```

## التصدير مع إعادة التسمية

```tarqeem
// في الوحدة المصدر
دالة _دالة_داخلية() { ... }

// تصدير باسم مختلف (مخطط للتنفيذ)
صدّر { _دالة_داخلية كـ دالة_عامة }
```

## أخطاء شائعة

### ١. تصدير من داخل دالة

```tarqeem
// ❌ خطأ: لا يمكن التصدير من داخل دالة
دالة إعداد() {
    صدّر دالة مساعدة() { }
}

// ✅ صحيح: التصدير في المستوى العلوي
صدّر دالة مساعدة() { }
```

### ٢. نسيان التصدير عند إضافة دوال جديدة

```tarqeem
// عند إضافة دالة جديدة، لا تنس تصديرها
صدّر دالة دالة_جديدة() {
    // ...
}
```
