# و٠١٠١: تصدير مكرر

## الوصف

هذا الخطأ يحدث عند محاولة تصدير عنصرين أو أكثر بنفس الاسم من نفس الوحدة.

كل عنصر مُصدَّر يجب أن يكون له اسم فريد داخل الوحدة لتجنب الغموض عند الاستيراد.

## سبب الخطأ

الأسباب الشائعة:

1. **تصدير دالتين بنفس الاسم**: تعريف دالتين مُصدَّرتين بنفس الاسم
2. **تصدير دالة وصنف بنفس الاسم**: تعارض بين أنواع مختلفة
3. **تصدير متكرر بالخطأ**: نسخ كود ونسيان تغيير الاسم

## مثال الخطأ

```tarqeem
بسم_الله

// أول تصدير باسم "حساب"
صدّر دالة حساب(س: عدد) -> عدد {
    أرجع س * 2
}

// تصدير ثانٍ بنفس الاسم - خطأ!
صدّر دالة حساب(س: عدد، ص: عدد) -> عدد {
    أرجع س + ص
}

الحمد_لله
```

**الرسالة**:
```
خطأ[و٠١٠١]: تصدير مكرر للعنصر 'حساب'
  --> ملف.ترقيم:9:14
  |
4 | صدّر دالة حساب(س: عدد) -> عدد {
  |           ----- أول تعريف هنا
  |
9 | صدّر دالة حساب(س: عدد، ص: عدد) -> عدد {
  |           ^^^^^ تصدير مكرر
  |
  = أعد تسمية أحد العنصرين لتجنب التعارض
```

## الحل

### الحل ١: إعادة تسمية أحد العنصرين

أعطِ كل عنصر اسماً فريداً يصف وظيفته:

```tarqeem
بسم_الله

// ✅ أسماء مختلفة توضح الفرق
صدّر دالة ضاعف(س: عدد) -> عدد {
    أرجع س * 2
}

صدّر دالة اجمع(س: عدد، ص: عدد) -> عدد {
    أرجع س + ص
}

الحمد_لله
```

### الحل ٢: دمج الدوال المتشابهة

إذا كانت الدوال متشابهة، يمكن دمجها:

```tarqeem
بسم_الله

// ✅ دالة واحدة بمعاملات افتراضية (مخطط للتنفيذ)
صدّر دالة حساب(س: عدد، ص: عدد = 0) -> عدد {
    إذا (ص == 0) {
        أرجع س * 2
    } وإلا {
        أرجع س + ص
    }
}

الحمد_لله
```

### الحل ٣: استخدام صنف لتجميع الدوال

```tarqeem
بسم_الله

صدّر صنف حاسبة {
    مشترك دالة ضاعف(س: عدد) -> عدد {
        أرجع س * 2
    }

    مشترك دالة اجمع(س: عدد، ص: عدد) -> عدد {
        أرجع س + ص
    }
}

الحمد_لله
```

```tarqeem
// الاستخدام
استورد { حاسبة } من "./رياضيات"

متغير أ = حاسبة.ضاعف(5)      // 10
متغير ب = حاسبة.اجمع(5، 3)   // 8
```

## حالات خاصة

### تعارض بين دالة وصنف

```tarqeem
// ❌ خطأ: تعارض بين دالة وصنف بنفس الاسم
صدّر دالة شخص() { }
صدّر صنف شخص { }

// ✅ صحيح: أسماء مختلفة
صدّر دالة انشئ_شخص() { }
صدّر صنف شخص { }
```

### تصدير من ملفات متعددة

في حالة إعادة التصدير من وحدات فرعية:

```tarqeem
// ❌ خطأ: تصدير نفس الاسم من وحدتين
استورد { مساعد } من "./أدوات١"
استورد { مساعد } من "./أدوات٢"
صدّر { مساعد }  // أي واحد؟

// ✅ صحيح: إعادة التسمية عند التصدير
استورد { مساعد كـ مساعد١ } من "./أدوات١"
استورد { مساعد كـ مساعد٢ } من "./أدوات٢"
صدّر { مساعد١، مساعد٢ }
```

## أفضل الممارسات

1. **استخدم أسماء وصفية**: بدلاً من `حساب`، استخدم `حساب_المساحة` أو `حساب_الراتب`
2. **تجنب الأسماء العامة**: أسماء مثل `معالج`، `بيانات`، `قيمة` سهلة التكرار
3. **راجع قبل التصدير**: تأكد من عدم وجود تصدير سابق بنفس الاسم
