# و٠٠٠١: وحدة غير موجودة

## الوصف

هذا الخطأ يحدث عند محاولة استيراد وحدة (ملف) غير موجودة في المسار المحدد.

المترجم لا يستطيع إيجاد الملف المطلوب استيراده، سواء كان مساراً نسبياً أو مساراً مطلقاً.

## سبب الخطأ

الأسباب الشائعة لهذا الخطأ:

1. **خطأ في كتابة اسم الملف**: الاسم مكتوب بشكل خاطئ
2. **مسار غير صحيح**: المسار النسبي لا يشير للمكان الصحيح
3. **الملف غير موجود**: الملف لم يُنشأ بعد أو تم حذفه
4. **امتداد خاطئ**: الملف لا يحمل امتداد `.ترقيم`

## مثال الخطأ

```tarqeem
بسم_الله

// محاولة استيراد وحدة غير موجودة
استورد { دالة_مساعدة } من "./مساعدات"

اطبع(دالة_مساعدة())

الحمد_لله
```

**الرسالة**:
```
خطأ[و٠٠٠١]: الوحدة './مساعدات' غير موجودة
  --> ملف.ترقيم:4:29
  |
4 | استورد { دالة_مساعدة } من "./مساعدات"
  |                             ^^^^^^^^^^
  |
  = تأكد من صحة المسار ووجود الملف
```

## الحل

### الحل ١: التحقق من صحة المسار

تأكد من أن المسار النسبي صحيح:

```
المشروع/
├── رئيسي.ترقيم       // ← الملف الحالي
├── مساعدات.ترقيم     // ← الملف المطلوب
└── أدوات/
    └── تحويل.ترقيم
```

```tarqeem
// ✅ استيراد من نفس المجلد
استورد { دالة_مساعدة } من "./مساعدات"

// ✅ استيراد من مجلد فرعي
استورد { تحويل_نص } من "./أدوات/تحويل"

// ✅ استيراد من مجلد أعلى
استورد { مشترك } من "../مشترك"
```

### الحل ٢: إنشاء الملف المطلوب

إذا كان الملف غير موجود، أنشئه:

**ملف: مساعدات.ترقيم**
```tarqeem
بسم_الله

صدّر دالة دالة_مساعدة() -> نص {
    أرجع "مرحباً من المساعدات"
}

الحمد_لله
```

### الحل ٣: التحقق من الامتداد

تأكد من أن الملف يحمل الامتداد الصحيح:

```tarqeem
// ❌ خطأ: الامتداد غير مطلوب في الاستيراد
استورد { أ } من "./ملف.ترقيم"

// ✅ صحيح: بدون امتداد
استورد { أ } من "./ملف"
```

## المسارات في ترقيم

### المسارات النسبية

| المسار | المعنى |
|--------|--------|
| `"./ملف"` | ملف في نفس المجلد |
| `"./مجلد/ملف"` | ملف في مجلد فرعي |
| `"../ملف"` | ملف في المجلد الأب |
| `"../../ملف"` | ملف في مجلدين للأعلى |

### المكتبة القياسية

```tarqeem
// استيراد من المكتبة القياسية (بدون ./)
استورد { قائمة } من "مجموعات"
استورد { جذر } من "رياضيات"
استورد { اقرأ_ملف } من "ملفات"
```

## أخطاء شائعة

### ١. نسيان النقطة والشرطة المائلة

```tarqeem
// ❌ خطأ: يبحث في المكتبة القياسية
استورد { أ } من "مساعدات"

// ✅ صحيح: مسار نسبي
استورد { أ } من "./مساعدات"
```

### ٢. مسار خاطئ بعد إعادة الهيكلة

عند نقل الملفات، تحقق من تحديث جميع الاستيرادات:

```tarqeem
// قبل: الملف كان في ./أدوات/مساعدات
استورد { أ } من "./أدوات/مساعدات"

// بعد النقل: الملف الآن في ./مشترك/مساعدات
استورد { أ } من "./مشترك/مساعدات"
```
