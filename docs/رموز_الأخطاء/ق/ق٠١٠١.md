# ق٠١٠١: صيغة عدد غير صحيحة

## الوصف

هذا الخطأ يحدث عندما يواجه المحلل اللغوي عدداً بصيغة غير صالحة.

## سبب الخطأ

الأعداد في ترقيم يجب أن تتبع صيغاً محددة:
- أعداد صحيحة: `123` أو `١٢٣`
- أعداد عشرية: `3.14` أو `٣.١٤`
- أعداد عشرية بصيغة أُسية: `2.5e10` أو `1.0E-5`
- أعداد سداسية عشرية: `0x1A2B`
- أعداد ثنائية: `0b1010`
- أعداد ثمانية: `0o755`

## مثال الخطأ

### فاصلة عشرية متعددة

```tarqeem
متغير س = 3.14.15    // ❌ خطأ: أكثر من فاصلة عشرية
```

**الرسالة**:
```
خطأ[ق٠١٠١]: صيغة عدد غير صحيحة
  --> ملف.ترقيم:١:١١
   |
 ١ | متغير س = 3.14.15
   |           ^^^^^^^
   |
   = صيغة عدد عشري غير صحيحة: نقطة عشرية متعددة
```

### أُس بلا أرقام

```tarqeem
متغير س = 2.5e      // ❌ خطأ: علامة الأُس بلا أرقام بعدها
```

**الرسالة**:
```
خطأ[ق٠١٠١]: الأس بلا أرقام
  --> ملف.ترقيم:١:١١
   |
 ١ | متغير س = 2.5e
   |           ^^^^
   |
   = الشرح: بعد `e` أو `E` يجب أن يأتي رقم واحد على الأقل، مع إشارة اختيارية
```

> **ملاحظة**: قبل معالجة هذه الحالة كان `2.5e` يُقرأ بصمت على أنه `2.5`، لأن
> أُساً فارغاً كان يُحسَب `10^0`.

### عدد سداسي عشري غير صحيح

```tarqeem
متغير لون = 0xGHI    // ❌ خطأ: حروف غير صالحة في عدد سداسي عشري
```

**الرسالة**:
```
خطأ[ق٠١٠١]: صيغة عدد غير صحيحة
  --> ملف.ترقيم:١:١٣
   |
 ١ | متغير لون = 0xGHI
   |             ^^^^^
   |
   = حروف غير صالحة في عدد سداسي عشري
```

## الحل

### الحل ١: تصحيح الأعداد العشرية

```tarqeem
// ❌ خطأ
متغير س = 3.14.15
متغير ص = .5
متغير ع = 5.

// ✅ صحيح
متغير س = 3.1415
متغير ص = 0.5
متغير ع = 5.0
```

### الحل ٢: إكمال الأُس

```tarqeem
// ❌ خطأ
متغير س = 2.5e
متغير ص = 1.0E+

// ✅ صحيح
متغير س = 2.5e10
متغير ص = 1.0E-5
متغير ع = 2.220446049250313e-16
```

### الحل ٣: تصحيح الأعداد السداسية العشرية

```tarqeem
// ❌ خطأ
متغير لون = 0xGHI

// ✅ صحيح - استخدم 0-9 و A-F فقط
متغير لون = 0xFF00FF
```

### الحل ٤: تصحيح الأعداد الثنائية

```tarqeem
// ❌ خطأ - 2 ليس رقماً ثنائياً
متغير قناع = 0b1012

// ✅ صحيح - استخدم 0 و 1 فقط
متغير قناع = 0b1010
```

## حالات شائعة

### الحالة ١: عدد يبدأ بصفر

```tarqeem
// ⚠️ قد يُفسر كعدد ثماني
متغير رقم = 0123

// ✅ إذا أردت عدداً عشرياً عادياً
متغير رقم = 123

// ✅ إذا أردت عدداً ثمانياً صريحاً
متغير رقم = 0o123
```

### الحالة ٢: فاصل آلاف

```tarqeem
// ❌ خطأ - الفاصلة غير مدعومة في الأعداد
متغير مبلغ = 1,000,000

// ✅ صحيح - اكتب العدد بدون فواصل
متغير مبلغ = 1000000
```

> **ملاحظة**: الشرطة السفلية كفاصل آلاف (`1_000_000`) غير مدعومة أيضاً.

### الحالة ٣: أرقام عربية وهندية مختلطة

```tarqeem
// ❌ خطأ - خلط أنظمة الأرقام
متغير س = ١23

// ✅ صحيح - استخدم نظاماً واحداً
متغير س = 123
متغير ص = ١٢٣
```

### الحالة ٤: عدد عشري بدون جزء صحيح

```tarqeem
// ❌ قد يسبب خطأ
متغير س = .5

// ✅ صحيح - أضف الصفر
متغير س = 0.5
```

## الصيغ المدعومة

| النوع | الصيغة | مثال |
|-------|--------|------|
| عدد صحيح | `[0-9]+` | `123` |
| عدد صحيح عربي | `[٠-٩]+` | `١٢٣` |
| عدد عشري | `[0-9]+.[0-9]+` | `3.14` |
| عدد عشري أُسي | `[0-9]+(.[0-9]+)?[eE][+-]?[0-9]+` | `2.5e10`، `1.0E-5` |
| سداسي عشري | `0x[0-9A-Fa-f]+` | `0xFF` |
| ثنائي | `0b[01]+` | `0b1010` |
| ثماني | `0o[0-7]+` | `0o755` |

## ملاحظات إضافية

- الأرقام العربية (0-9) والهندية (٠-٩) كلاهما مدعوم
- لا تخلط بين نظامي الأرقام في نفس العدد
- الأعداد السداسية العشرية تستخدم الحروف الإنجليزية A-F
- علامة الأُس `e`/`E` مسموحة داخل العدد وحدها؛ هي جزء من القيمة الحرفية
  ولا تُعَد معرِّفاً لاتينياً (انظر [ق٠٠٠١](ق٠٠٠١.md))
- الأرقام الهندية مسموحة في الأُس أيضاً: `٢.٥e١٠`
- أُس ضخم يفيض عن مدى العدد العشري يعطي «ما لا نهاية» ولا يُنتج خطأ
