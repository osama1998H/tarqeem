# ق٠٢٠١: نص غير مغلق

## الوصف

هذا الخطأ يحدث عندما يبدأ نص (سلسلة نصية) بعلامة تنصيص ولكن لا يُغلق بعلامة تنصيص مطابقة قبل نهاية السطر أو الملف.

## سبب الخطأ

النصوص في ترقيم يجب أن تُحاط بعلامات تنصيص متطابقة:
- علامات تنصيص مزدوجة: `"نص"`
- علامات تنصيص مفردة: `'نص'`

الخطأ يحدث عندما:
1. تُفتح علامة تنصيص ولا تُغلق
2. ينتهي السطر قبل إغلاق النص
3. ينتهي الملف قبل إغلاق النص

## مثال الخطأ

### نص بدون إغلاق

```tarqeem
متغير رسالة = "مرحباً بالعالم
// ❌ خطأ: النص لم يُغلق
```

**الرسالة**:
```
خطأ[ق٠٢٠١]: نص غير مغلق
  --> ملف.ترقيم:١:١٦
   |
 ١ | متغير رسالة = "مرحباً بالعالم
   |                ^
   |
   = النص بدأ هنا ولم يُغلق
```

### علامة تنصيص غير متطابقة

```tarqeem
متغير اسم = "أحمد'    // ❌ خطأ: علامات التنصيص غير متطابقة
```

**الرسالة**:
```
خطأ[ق٠٢٠١]: نص غير مغلق
  --> ملف.ترقيم:١:١٣
   |
 ١ | متغير اسم = "أحمد'
   |              ^
   |
   = متوقع " لإغلاق النص
```

## الحل

### الحل ١: إغلاق النص بعلامة تنصيص مطابقة

```tarqeem
// ❌ خطأ
متغير رسالة = "مرحباً بالعالم

// ✅ صحيح
متغير رسالة = "مرحباً بالعالم"
```

### الحل ٢: استخدام علامات تنصيص متطابقة

```tarqeem
// ❌ خطأ
متغير اسم = "أحمد'

// ✅ صحيح
متغير اسم = "أحمد"
// أو
متغير اسم = 'أحمد'
```

### الحل ٣: استخدام رموز الهروب للنصوص الطويلة

```tarqeem
// ❌ خطأ - نص متعدد الأسطر بدون إغلاق
متغير قصيدة = "السطر الأول
السطر الثاني

// ✅ صحيح - استخدم \n للأسطر الجديدة
متغير قصيدة = "السطر الأول\nالسطر الثاني"
```

## حالات شائعة

### الحالة ١: نسيان علامة التنصيص الختامية

```tarqeem
// ❌ خطأ
اطبع("مرحباً)

// ✅ صحيح
اطبع("مرحباً")
```

### الحالة ٢: علامة تنصيص داخل النص

```tarqeem
// ❌ خطأ - علامة التنصيص تُنهي النص مبكراً
متغير جملة = "قال: "مرحباً""

// ✅ صحيح - استخدم رمز الهروب
متغير جملة = "قال: \"مرحباً\""

// ✅ أو استخدم علامات تنصيص مختلفة
متغير جملة = 'قال: "مرحباً"'
```

### الحالة ٣: مسار ملف

```tarqeem
// ❌ خطأ - الشرطة المائلة العكسية قد تسبب مشاكل
متغير مسار = "C:\ملفات\مستند

// ✅ صحيح
متغير مسار = "C:\\ملفات\\مستند"
```

### الحالة ٤: نص فارغ

```tarqeem
// ❌ خطأ - علامة واحدة فقط
متغير فارغ = "

// ✅ صحيح - علامتان متتاليتان
متغير فارغ = ""
```

## رموز الهروب المدعومة

| الرمز | المعنى |
|-------|--------|
| `\"` | علامة تنصيص مزدوجة |
| `\'` | علامة تنصيص مفردة |
| `\\` | شرطة مائلة عكسية |
| `\n` | سطر جديد |
| `\t` | مسافة جدولة |
| `\r` | رجوع للبداية |

## نصائح للتجنب

1. **استخدم محرراً يدعم تمييز النصوص** - يظهر النصوص غير المغلقة بلون مختلف
2. **تحقق من الأقواس والعلامات** - تأكد من إغلاق كل علامة تنصيص
3. **استخدم الإكمال التلقائي** - المحررات الحديثة تُغلق العلامات تلقائياً

## ملاحظات إضافية

- النصوص في ترقيم لا تمتد على أسطر متعددة بشكل افتراضي
- استخدم `\n` لإدراج أسطر جديدة داخل النص
- علامات التنصيص المزدوجة والمفردة متكافئة في ترقيم
