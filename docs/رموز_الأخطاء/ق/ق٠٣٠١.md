# ق٠٣٠١: تعليق غير مغلق

## الوصف

هذا الخطأ يحدث عندما يبدأ تعليق متعدد الأسطر (`/*`) ولا يُغلق بـ (`*/`) قبل نهاية الملف.

## سبب الخطأ

التعليقات في ترقيم نوعان:
1. **تعليق سطر واحد**: يبدأ بـ `//` وينتهي بنهاية السطر
2. **تعليق متعدد الأسطر**: يبدأ بـ `/*` ويجب أن ينتهي بـ `*/`

الخطأ يحدث فقط مع التعليقات متعددة الأسطر عندما:
- يُفتح التعليق بـ `/*` ولا يُغلق
- ينتهي الملف قبل العثور على `*/`

## مثال الخطأ

### تعليق بدون إغلاق

```tarqeem
/* هذا تعليق طويل
   يمتد على عدة أسطر
   ولكنه لم يُغلق

دالة رئيسية() {
    اطبع("مرحباً")
}
// ❌ خطأ: التعليق لم يُغلق
```

**الرسالة**:
```
خطأ[ق٠٣٠١]: تعليق غير مغلق
  --> ملف.ترقيم:١:١
   |
 ١ | /* هذا تعليق طويل
   | ^^
   |
   = التعليق بدأ هنا ولم يُغلق بـ */
```

### نسيان النجمة في الإغلاق

```tarqeem
/* ملاحظة مهمة /    // ❌ خطأ: نسيان النجمة
```

**الرسالة**:
```
خطأ[ق٠٣٠١]: تعليق غير مغلق
  --> ملف.ترقيم:١:١
   |
 ١ | /* ملاحظة مهمة /
   | ^^
   |
   = التعليق بدأ هنا، متوقع */ للإغلاق
```

## حالات شائعة

### الحالة ١: تعليقات متداخلة

```tarqeem
// ❌ خطأ - التعليقات المتداخلة غير مدعومة
/* تعليق خارجي
   /* تعليق داخلي */
*/

// ✅ صحيح - استخدم تعليقات سطر واحد بالداخل
/* تعليق خارجي
   // تعليق داخلي
*/
```

### الحالة ٢: تعليق توثيقي

```tarqeem
// ❌ خطأ - نسيان الإغلاق
/**
 * دالة تحسب المجموع
 * @معامل أ العدد الأول
 * @معامل ب العدد الثاني

// ✅ صحيح
/**
 * دالة تحسب المجموع
 * @معامل أ العدد الأول
 * @معامل ب العدد الثاني
 */
```

### الحالة ٣: كود معلق مؤقتاً

```tarqeem
// ❌ خطأ - نسيان إغلاق الكود المعلق
/*
دالة قديمة() {
    // كود قديم
}

// ✅ صحيح
/*
دالة قديمة() {
    // كود قديم
}
*/
```

### الحالة ٤: تعليق في نهاية الملف

```tarqeem
دالة رئيسية() {
    اطبع("مرحباً")
}

/* ملاحظات:
   - هذا البرنامج للاختبار
   - يجب تحسينه لاحقاً
// ❌ خطأ - الملف انتهى بدون إغلاق التعليق
```

## نصائح للتجنب

1. **اكتب `*/` فوراً بعد `/*`** - ثم أضف المحتوى بينهما
2. **استخدم محرراً يدعم الإكمال التلقائي** - يُغلق التعليقات تلقائياً
3. **تجنب التعليقات المتداخلة** - استخدم `//` داخل `/* */`
4. **راجع نهاية الملف** - تأكد من إغلاق جميع التعليقات

## الفرق بين أنواع التعليقات

| النوع | البداية | النهاية | متعدد الأسطر |
|-------|---------|---------|--------------|
| تعليق سطر | `//` | نهاية السطر | لا |
| تعليق كتلة | `/*` | `*/` | نعم |

## ملاحظات إضافية

- التعليقات المتداخلة غير مدعومة في ترقيم
- تعليقات السطر الواحد (`//`) لا تسبب هذا الخطأ أبداً
- التعليق `*/` بدون `/*` سابق يُعتبر خطأً منفصلاً
