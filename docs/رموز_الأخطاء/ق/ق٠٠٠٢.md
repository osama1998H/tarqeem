# ق٠٠٠٢: نهاية ملف غير متوقعة

## الوصف

هذا الخطأ يحدث عندما ينتهي الملف بشكل مفاجئ بينما المحلل اللغوي يتوقع المزيد من المحتوى.

## سبب الخطأ

المحلل يتوقع استمرار الكود في الحالات التالية:
1. نص أو تعليق لم يُغلق
2. قوس أو كتلة لم تُغلق
3. تعبير غير مكتمل

## مثال الخطأ

### نص غير مكتمل

```tarqeem
متغير رسالة = "مرحباً
// ❌ انتهى الملف هنا بدون إغلاق علامة التنصيص
```

**الرسالة**:
```
خطأ[ق٠٠٠٢]: نهاية ملف غير متوقعة
  --> ملف.ترقيم:١:١٨
   |
 ١ | متغير رسالة = "مرحباً
   |                       ^
   |
   = انتهى الملف أثناء قراءة نص
```

### كتلة غير مغلقة

```tarqeem
دالة رئيسية() {
    اطبع("مرحباً")
// ❌ الملف انتهى بدون إغلاق الكتلة
```

**الرسالة**:
```
خطأ[ق٠٠٠٢]: نهاية ملف غير متوقعة
  --> ملف.ترقيم:٣:٠
   |
 ١ | دالة رئيسية() {
   |                - الكتلة بدأت هنا
   |
   = متوقع '}' لإغلاق الكتلة
```

## حالات شائعة

### الحالة ١: نسيان إغلاق التعليق

```tarqeem
// ❌ خطأ
/* هذا تعليق طويل
   يمتد على عدة أسطر

// ✅ صحيح
/* هذا تعليق طويل
   يمتد على عدة أسطر */
```

### الحالة ٢: أقواس غير متوازنة

```tarqeem
// ❌ خطأ
دالة حساب(أ: عدد، ب: عدد -> عدد {
    أرجع أ + ب
}

// ✅ صحيح - أغلق القوس
دالة حساب(أ: عدد، ب: عدد) -> عدد {
    أرجع أ + ب
}
```

### الحالة ٣: ملف مقطوع

```tarqeem
// ❌ خطأ - الملف مقطوع في المنتصف
صنف شخص {
    عام اسم: نص
    عام عمر: ع

// ✅ صحيح - الملف مكتمل
صنف شخص {
    عام اسم: نص
    عام عمر: عدد
}
```

## نصائح للتجنب

1. **استخدم محرراً يدعم الإكمال التلقائي** - يظهر الأقواس غير المغلقة
2. **تحقق من المسافة البادئة** - تساعد في رؤية الكتل المفتوحة
3. **احفظ الملف بانتظام** - تجنب فقدان البيانات

## ملاحظات إضافية

- هذا الخطأ يحدث في مرحلة التحليل اللغوي (Lexing)
- تأكد من أن الملف محفوظ بالكامل
- بعض المحررات قد تقطع الملف عند الحفظ إذا كان هناك مشكلة في الترميز
