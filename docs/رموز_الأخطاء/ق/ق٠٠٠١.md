# ق٠٠٠١: حرف غير معروف

## الوصف

هذا الخطأ يحدث عندما يواجه المحلل اللغوي (Lexer) حرفاً لا يمكنه التعرف عليه كجزء من بناء اللغة.

## سبب الخطأ

المحلل اللغوي يتعرف فقط على:
- الحروف العربية للمعرفات
- الأرقام (العربية والهندية)
- علامات الترقيم المعتمدة
- العوامل الرياضية والمنطقية

أي حرف خارج هذه المجموعة يُعتبر غير معروف.

## مثال الخطأ

### حرف خاص غير مدعوم

```tarqeem
متغير س = 5 @ 3    // ❌ خطأ: الحرف '@' غير معروف
```

**الرسالة**:
```
خطأ[ق٠٠٠١]: حرف غير معروف
  --> ملف.ترقيم:١:١٣
   |
 ١ | متغير س = 5 @ 3
   |             ^
   |
   = حرف غير معروف: @
```

### استخدام حروف إنجليزية كمعرفات

```tarqeem
متغير name = "أحمد"    // ❌ خطأ: الحروف الإنجليزية غير مدعومة كمعرفات
```

**الرسالة**:
```
خطأ[ق٠٠٠١]: حرف غير معروف
  --> ملف.ترقيم:١:٧
   |
 ١ | متغير name = "أحمد"
   |       ^^^^
   |
   = المعرفات الإنجليزية غير مسموح بها في ترقيم
```

## الحل

### الحل ١: إزالة الحرف غير المدعوم

```tarqeem
// ❌ خطأ
متغير س = 5 @ 3

// ✅ صحيح - استخدم عامل مدعوم
متغير س = 5 * 3
```

### الحل ٢: استخدام معرفات عربية

```tarqeem
// ❌ خطأ
متغير name = "أحمد"

// ✅ صحيح - استخدم اسم عربي
متغير اسم = "أحمد"
```

## حالات شائعة

### الحالة ١: نسخ كود من لغة أخرى

```tarqeem
// ❌ خطأ - هذا كود JavaScript
let x = 5;
console.log(x);

// ✅ صحيح - الترجمة لترقيم
متغير س = 5
اطبع(س)
```

### الحالة ٢: استخدام رموز Unicode غير مدعومة

```tarqeem
// ❌ خطأ - رموز غير مدعومة
متغير قيمة = 5 → 10

// ✅ صحيح - استخدم عامل مدعوم
متغير قيمة = 10
```

### الحالة ٣: خلط الحروف العربية والإنجليزية

```tarqeem
// ❌ خطأ - خلط في المعرف
متغير userاسم = "أحمد"

// ✅ صحيح - معرف عربي بالكامل
متغير اسم_المستخدم = "أحمد"
```

## الحروف المدعومة

### المعرفات
- جميع الحروف العربية (ا-ي، ء-ئ)
- الشرطة السفلية `_`
- الأرقام (بعد الحرف الأول)

### الأرقام
- الأرقام العربية: 0-9
- الأرقام الهندية: ٠-٩

### العوامل
- الرياضية: `+` `-` `*` `/` `%` `**`
- المقارنة: `==` `!=` `<` `>` `<=` `>=`
- المنطقية: `&&` `||` `!` `و` `أو` `ليس`
- التعيين: `=` `+=` `-=` `*=` `/=`

### علامات الترقيم
- الفاصلة: `,` أو `،`
- الفاصلة المنقوطة: `;` أو `؛`
- الأقواس: `()` `{}` `[]`
- النقطتان: `:`
- السهم: `->`

## ملاحظات إضافية

- ترقيم لغة برمجة عربية بالكامل
- المعرفات الإنجليزية غير مدعومة عمداً
- استخدم محرر نصوص يدعم Unicode بشكل كامل
