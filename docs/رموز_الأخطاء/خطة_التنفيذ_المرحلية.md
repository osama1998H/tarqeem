## نظرة عامة

هذه الخطة تحدد المراحل التدريجية لتنفيذ نظام رموز الأخطاء العربية في ترقيم.

### الهدف النهائي

- جميع أخطاء المترجم لها رموز عربية موثقة
- كل رمز له ملف توثيق تفصيلي
- أمر `tarqeem اشرح [رمز]` يعمل لجميع الأخطاء

- [x] إضافة روابط للتوثيق (documentation links) - `code_description`
- [x] Code actions لإصلاح الأخطاء الشائعة باستخدام رموز الأخطاء

### الملفات المعدلة

- `src/lsp/handlers/diagnostics.rs`:
  - إضافة `error_code_url()` لتوليد روابط التوثيق
  - إضافة `code_description` مع رابط `tarqeem://explain/<category>/<code>`

- `src/lsp/handlers/code_actions.rs`:
  - استيراد رموز الأخطاء (`ERR_UNDEFINED_VARIABLE`, `ERR_CONST_ASSIGNMENT`, `WARN_UNUSED_VARIABLE`)
  - مطابقة على `diagnostic.code` بدلاً من نص الرسالة
  - إضافة إجراء لإضافة بادئة `_` للمتغيرات غير المستخدمة
  - احتفاظ بالمطابقة النصية كخيار احتياطي للتوافق

### رموز الأخطاء المدعومة للإصلاح السريع

| الرمز | الإجراء |
|-------|---------|
| د٠٠٠١ | إضافة تعريف للمتغير |
| د٠١٠٢ | تحويل إلى متغير قابل للتعديل |
